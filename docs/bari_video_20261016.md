# バリ式動画：EMA25方式の機械近似検証

**結論：今回のEMA25機械近似は不採用。** 独立再計算はALL_MATCH。主条件RR1の通常費用では734取引、勝率48.50%、PF0.801、平均−0.0800R。3期間すべて赤字だった。動画原法全体・裁量トレードの勝率を否定する検証ではない。

## 一次資料と検証範囲

指定動画：[バリFX「新手法『バリ式』の全貌大公開」](https://www.youtube.com/watch?v=jbl2DALIEWw)、2025-02-10公開、23:20。
説明欄の[本人の解説資料](https://www.canva.com/design/DAGeXQBv7M4/aLDCyS1_WRgIa1UkeMthUQ/edit)と日本語自動字幕を照合。原資料の対応表は [source.md](quant_organization/experiments/bari_video_20261016/source.md)。

今回扱ったのは、H1の方向確認→M15転換→後続M5転換→M5 EMA25を順・逆・順に越える方式。M5転換と最初の真のEMA交差が同じ足の場合は、動画15:31–15:37の実例に合わせて数える。残る交差は別の足で待つ。

裁量を数値化する追加仮定：左右2本確定ピボット、H1ピボット方向とEMA25位置・傾きの一致、終値交差、M15ピボット外の代理SL、96本の待機取消、48本の最大保有、実Entryからの固定RR。H4は参考で同方向を強制しない。動画のライン・チャネル選別、三尊、シナリオ別の裁量TP/SLを完全には再現していない。三角持合い方式は別系統として未検証。

## 入力・固定条件

- 保存済みForex Tester履歴のUSDJPY・EURUSD・GBPUSD、M5全1,365,021行。3入力のSHA一致・OHLC/時刻品質検査済み。H1/M15/H4は同じM5から完全足を保持して集約。
- 2019年12月を初期化、2020–2022/2023–2024/2025を全件固定の記述評価。全期間が既閲覧で、未知holdoutではない。区分ごとにシナリオと建玉を初期化し、全区分を報告。
- 主案EMA待機と、同じH1/M15/M5転換条件でEMA待機だけ省くdirect対照。RR1が主、RR1.5/2は固定参考診断。損益を見て良いRRへ後選抜していない。
- 次の連続M5の実始値でEntry。Entry足が後で完全だったかを始値判定に使わない。SL/TP同足はSL優先、不利gapは実始値、有利gapはTPを上限。未決済末端はOPEN_MARKとして勝率から分離。
- 通常往復費用はUSDJPY1.6/EURUSD1.5/GBPUSD1.8pipsという仮定。費用なし・通常・2倍を全出力。実測変動spread/約定slippage/個別手数料/swapの再現ではない。

## 主結果：RR1・通常費用

|期間|取引数|勝率|PF|平均損益|累積損益|
|---|---:|---:|---:|---:|---:|
|2020–2022|369|49.59%|0.880|−0.0455R|−16.78R|
|2023–2024|238|45.80%|0.669|−0.1436R|−34.17R|
|2025|127|50.39%|0.850|−0.0612R|−7.77R|
|合計|734|48.50%|0.801|−0.0800R|−58.72R|

1Rは各取引の当初SL距離に対応するリスク。異なる通貨のRを等重み集計した研究値で、同時運用口座の円損益ではない。合計は3区分の固定明細の合算であり、連続口座診断と別。
勝率のWilson95%区間は期間順に44.52–54.67%、39.59–52.14%、41.82–58.95%、合計44.90–52.12%。取引間の独立性を保証する区間ではない。

通常PFはUSDJPY0.767、EURUSD0.822、GBPUSD0.813で、3通貨とも赤字。EMA待機の平均Rは全3期間でdirect対照より良かったが、正にはならなかった。

この固定明細では費用前に小さな利益があっても、通常費用を控除すると3RRすべて赤字。目標RRは実現した平均利益/平均損失比と同じではない。時間切れ・欠損清算・gapも含む。

2025だけならRR1.5/2は通常PF1.092/1.094だが、費用2倍では0.839/0.852へ下がる。前2区分も赤字であり、後から2025の良い設定だけ採用しない。

## 資金100万円・元金損失10万円の診断

USDJPYだけで2020–2025を資金リセットせず連続計算。費用込み0.5%risk、1000通貨刻み、25倍の数量上限、90万円floorを戦略SLより厳しい側の追加stopとして再現。gapでは超過損失を切り捨てない。

主RR1・通常費用は212決済、**1,000,000円→900,036円、−99,964円**。停止フラグ自体はfalseだが、残り36円では最小数量を満たせないため数量不足の見送りが28回あった。停止しなかったことを安全性の証拠にはしない。ピークからの閉鎖資産DDは118,746円で、初期元金からの10万円floorとは別の尺度。

費用2倍では900,020円、数量不足見送り110回。全ケースのOPEN_MARKは今回0件。末端未決済の分離処理は境界テストで確認した範囲。

## 独立検証・判定

1. 研究・独立の合成境界テスト19件成功。先読み、ピボット遅延、同時交差、欠損始値、年度境界、SL優先、費用一回、floor/gap、未決済分離を確認。
2. 14個の仕様・実装・証拠SHAとprotocolを2026-10-15T23:59:44.438278Zに固定。研究開始23:59:58.468720Z、終了2026-10-16T00:00:19.140202Z、exit0。
3. 独立した状態・約定会計実装で162ケースと12口座、9つの未来切断、全信号・明細・集計・gateが一致、exit0、ALL_MATCH。延べ32,697取引観測はRR・費用・口座の重複を含み、独立サンプル数ではない。
4. 監査担当の別計算でも会計一致。主RR1は全3区分で研究基準に不合格。頻度は基準を満たしたが、通常PF・平均R・費用耐性・黒字通貨数が不足。実運用採用の根拠にはしない。

元時計zone/DST・価格Bid/Askの未確認、裁量部分の置換、同足順序の保守近似、既閲覧期間、EMA/pivot/取消期限等の感度未検証を残す。動画の本人主張はFT5の100回平均・71–83%/平均約77%で、期間や明細が未提示。今回の結果から本人の全トレードの正否は断定できない。
