# 5分足スキャルピングにおける形状の市場環境検証

## 結論

5分足へ変更して15種類の市場環境を再計算したが、採用条件を満たした環境は0だった。
基準の形状群は15分足より悪化し、最も良かった環境でも全期間でマイナス期待値だった。
そのためTradingViewの実運用ロジックには追加しない。

## 前提

- Forex Tester実履歴の14銘柄、2010年1月から2026年7月31日まで。
- 5分足で形状を検出し、確定した次の5分足始値でエントリー。
- 形状パラメータは15分足研究で選定した値を固定し、5分足のバー数として使用。
- 利確と損切りは同距離、厳格なRR 1:1全量決済。
- スプレッドを含み、同じバーでTPとSLに触れた場合は損失扱い。
- 2010–2018年を学習、2019–2022年を検証、2023–2024年をホールドアウト、
  2025–2026年を最新未使用期間とした。
- 環境判定の実時間幅は15分足検証と揃えるため、5分足では参照本数を3倍にした。
- 採用には学習500件・検証200件以上、4期間すべてでプラス期待値を要求した。

## 読み取れる傾向

- 高ボラティリティ、ボラ拡大、ロンドン時間、理論に沿った反転環境は損失幅を縮小した。
- 低ボラティリティと東京時間は明確に悪化したため、この形状群との相性が悪い。
- 通貨強弱差の拡大も5分足では改善せず、短期ノイズや遅行の影響が疑われる。
- 改善条件でも勝率は50%へ届かず、RR 1:1で必要な損益分岐点を超えなかった。

## 「スキャルピング」としての注意

フィルターなしの最新平均保有は約99分、最良の反転環境は約153分だった。
したがって、これは5分足エントリーの短期デイトレードであり、数分から数十分で
完結する超短期スキャルピングとは異なる。時間決済を追加すれば別戦略になるため、
RR 1:1を保った今回の比較には混ぜていない。

また固定スプレッドは含むが、可変スプレッド、スリッページ、約定拒否は含まない。
5分足ではこれらの影響が相対的に大きいため、実運用成績はバックテストより悪くなる
可能性がある。
