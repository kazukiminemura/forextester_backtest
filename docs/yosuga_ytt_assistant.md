# よすが式 分析補助（YTT公開機能の近似）

通貨横断で候補を探す場合は [FX候補スキャナー](yosuga_ytt_fx_scanner.md) を追加する。8通貨を別パネルで表示し、この分析補助のチャート描画・設定は保持する。

状態: **TV_VERIFIED_LIMITED_UTILITY**。2026-10-09。Pine v6インジケーター。日足では週足＋月足へ自動切替し、月足・週足・日足と突破候補の状態を表示。SMR日足の高安・チャネル描画修正も維持。収益性は未検証です。

`scripts/tradingview/yosuga_ytt_assistant.pine` をTradingViewへ貼り付けて使う分析補助です。YTT内部コード・完全仕様は公開資料で確認できていないため、公式YTTの完全再現や同一判断を保証するものではありません。売買戦略、発注、BUY/SELL推奨、勝率・PF・収益実績の計算は含みません。

## 導入

1. TradingViewで通常の時間足ローソク足を開く。まず5分足または15分足を使う。
2. 個人スクリプト「よすが式 分析補助（YTT公開機能の近似）」をチャートへ追加する。別環境ではPineエディタへ `.pine` 全文を貼り付け、保存し「チャートに追加」。最終ファイルの実コンパイル・描画と保存本文の一致を確認済み。
3. 初回の価格選択でEntryの価格と時刻、SL価格を選ぶ。`confirm=true` のため手動シナリオOFFでも初回入力が表示される。分析だけなら任意点を選び、シナリオOFFのまま使用する。
4. シナリオを使う場合は設定でON、Long/Short、Entry、SL、起点を指定。資金・換算係数・数量刻みを入力すると理論数量を表示する。
5. 突破候補の通知は「上位足合意・買い候補成立」「上位足合意・売り候補成立」を選び、バー終値ごとにアラートを作る。既存の「確定足の水平線接触」「確定足の方向変化」も利用可能。

## 公開情報と実装の対応

### 状態の読み方：突破済みは新規エントリーの許可ではありません

15分足なら右下の突破候補を次のように読みます。

|状態|意味|この表示で確認すること|
|---|---|---|
|買い待ち／売り待ち|上位足が合意し、未突破の水準を監視中|突破価格と方向を確認。ヒゲだけの接触は成立しない|
|成立|その足の終値で初回の突破候補が成立|条件を満たした時刻と価格の記録。発注許可や利益保証ではない|
|突破済み|その水準は確定終値で既に突破され、使用済み|次の確定高値／安値を待つ。今の価格で追随する条件は実装していない|
|見送り|上位2足の方向が一致していない|候補を表示しない|
|データ不足／時間足設定を確認|必要な確定高安がない、または上位足の設定が不正|確定高安を待つ、または異なる2上位足に設定する|

例：日足/週足が上昇で合意し、買い待ち価格が158.000なら、15分足の前終値が158.000以下、次の終値が158.000より上になった時だけ買い候補成立です。158.000に一瞬触れる、終値が同値で止まる場合は成立しません。その後158.200で「突破済み」と表示されても、いつでも買ってよいという判定ではありません。

「突破済み」は上位足が合意する前の突破でも起こります。従って、突破済みの表示だけでは過去に上位足合意の候補成立があったことも証明しません。同じ水準へ戻って再突破しても候補を出さず、新しいピボットが確定してから監視を再開します。

チャート上に残る「買い候補成立／売り候補成立」のラベルは過去の記録です。「成立」は次の足で「突破済み」へ変わることがあるため、成立時刻を見逃さない用途ではインジケーターの対応アラートを「バー終値ごと」に設定します。現在の価格でのエントリー可否、押し目・戻り目エントリー、損切り・利確の妥当性は、この候補表示では自動判定していません。

2026-10-09に候補へ次足始値・反対ピボットSL・RR1決済を付けた固定2条件の研究を実走しました。現在の上位足合意あり近似ルールは費用後赤字で、月300万円目標は未達です。これは公式YTTそのものの成績ではありません。[固定研究の結果と限界](quant_organization/experiments/ytt_profit_feasibility_20261009/report.md)を参照してください。候補表示を収益性合格のエントリー指示として使わないでください。

### 上位足が合意した方向の突破候補

ユーザー指定の独自分析フィルターです。日足では週足＋月足を自動使用し、日足以外の既定は日足＋週足です。両方が上昇なら現チャート足の直近確定高値に「買い候補: 終値で価格超え」、両方が下降なら直近確定安値に「売り候補: 終値で価格割れ」を太線と価格付き名称で表示します。合意しない場合は見送りです。この2足合意は原典の必須条件として確認したものではなく、YTT公式のエントリー条件・売買推奨・研究合格した戦略とは扱いません。

1. 「日足では週足＋月足を自動使用」は既定ON。日足へ切り替えるだけで週足＋月足の候補状態を確認できます。左下のM/W/D行は月足/週足/日足の確定方向です。指定した上位足を日足でも使う場合は自動使用をOFFにしてください。日足以外では設定の上位足1/2を使用し、既定は日足＋週足。既存入力は保持される場合があります。2足とも現足より厳密に長く、異なる必要があります。週足チャートは自動切替対象外です。
2. 右下の小さな表に合意対象・状態・突破価格を表示します。判定は現足の終値確定です。ヒゲだけの突破、形成中の終値、形成中の上位足は候補成立に使いません。
3. 成立判定はその足の更新前から確定していた高値/安値に対して行います。買いは `close > 事前高値` かつ `close[1] <= 事前高値`、売りは逆です。同時に新しいピボットが確定しても、成立価格を新ピボットへ置き換えません。成立した足の終了時刻に価格付きラベルを残し、最大20件で古いものから削除します。
4. 上位方向が合意する前を含め、確定終値ですでに突破した同じピボットは監視候補に戻しません。「突破済・次の高値（安値）待ち」として、新しい確定ピボットを待ちます。新ピボットが同じ価格でも別の確定極値として扱います。
5. 通知は「上位足合意・買い候補成立」「上位足合意・売り候補成立」をTradingViewで設定します。候補成立は自動発注・約定・即時注文の条件ではありません。SL/TPと数量は既存の手動シナリオで別に指定します。

監視線は現在バーの次の列から右へ延長し、過去の極値へ遡って候補を描きません。価格は確定済みの値だけを使います。月足の確定高安が足りなければ「データ不足」、方向が揃わなければ「見送り」です。新機能の実機検証状況は本書の検証状態および実機確認記録で別に管理します。

|要素|原典・公開情報の位置付け|この実装の明示的近似|
|---|---|---|
|水平線|目立つ髭先高安、反発集中価格を重視|左右各2本を既定とする `ta.pivothigh/low`。集中帯・目立ち度は判定しない|
|方向|直前高安の突破を転換判断に使う|既存の直近確定高値を終値が厳密に上抜けたら上昇、安値を下抜けたら下降。同値は突破なし。方向は次の反対突破まで継続|
|高安構造|高安の切上げ・切下げ|直近2高値と2安値を比較。HH/HL=切上げ、LH/LL=切下げ、EH/EL=同値、?=不足|
|平行チャネル|高安と平行線を使う|上昇方向なら直近2安値、下降なら2高値。間にある直近の反対極値を通る平行線。方向と傾きが一致し幅が正の場合のみ描画|
|時間足別情報|上位足と下位足の全体認識|W/D/H4/H1/M15の確定した方向・高安構造・価格を表示|
|手動シナリオ|ユーザーの価格計画を補助|手入力方向・Entry・SLからTPを計算。RR既定1。自動判定で方向や価格を選ばない|

資料の原則は [原典照合](quant_organization/experiments/yosuga_channel_20261003/source_inventory.md)、[YTT公式紹介](https://fx-space.com/trade/)を参照。固定ピボット、終値突破、時刻ベースの直線、RR既定1は本実装の選択です。原典の2026年説明はRR>=1で、全ての取引で1R全決済とする仕様ではありません。過去の不採用研究を合格扱いして移植したものではありません。

## 確定と履歴

左右2本なら極値は2本後の終値で初めて確定します。水平線の開始位置は検出足の終了時刻、ツールチップに「極値時刻」と「検出確定時刻」を銘柄タイムゾーンで別表示します。その検出足より前の接触通知を作りません。新しい水平線の接触判定は次の足からです。

時間足テーブルは左下に小さな文字で表示し、右側のEntry/TP/SL価格ラベルと分離します。上位足の各値を `[1]` でずらし `lookahead_on` と組み合わせ、最後に確定した上位足を次の上位足期間から表示します。週の途中で形成中の週足を判定に混ぜません。同じ時間足の行は現在足が確定した時だけ更新。チャートより短い時間足の行は「— / 下位足は対象外」と表示し、下位足サンプリングを使いません。15分足以下なら5行すべて利用可能です。非標準チャートはエラーになります。

既存水平線に `low <= 水準 <= high` が成立した確定足ごとに接触通知を出します。連続する接触足でも通知対象になります。終値突破した線は既定で削除。削除OFFでは突破時で線を止め、破線と「突破済」名称を残し、その後の接触対象から外します。水平線・価格ラベルは設定件数（既定12、最大120）まで保持し古いものから削除します。

チャネルは最新1組だけです。新しい極値または方向変更時に再構築し、条件を満たさなくなれば消します。線は検出確定時点から右へ描き、基準点間の過去へ後付けしません。傾きは実時刻の差で計算するため、休日などの無取引時間を含みます。ローソク足の本数ベースの傾きとは異なります。

手動Entry/TP/SLは到達後も表示を残します。保持するのは現設定の1シナリオです。入力の変更は再計算になり、以前のシナリオを自動保存しません。複数案を残す場合はインジケーターを別インスタンスで追加してください。起点を過去へ置いても、そこでその価格を知っていたことや約定したことの証拠にはなりません。

## 手動価格と数量

EntryとSLは銘柄の最小tickに丸めます。Longは `SL < Entry`、Shortは `SL > Entry`、価格は正、SL距離は1tick以上、起点は指定済みである必要があります。不正なら描画・数量算定を止めテーブルに表示します。

`距離 = round(abs(Entry - SL) / 最小tick) × 最小tick`、Longの `TP = Entry + 距離 × RR`、Shortの `TP = Entry - 距離 × RR`。整列済み価格の差を整数tick数へ戻すことで、浮動小数点の減算誤差によってLongとShortの数量が1刻みずれることを避けます。数量の切下げに無条件のepsilonは加えません。TPもtickへ丸め、テーブルには丸め後の実効RRを表示します。非整数RRは丸めで指定RRから僅かにずれることがあります。既定RR1なら同じtick距離です。

`許容損失 = 口座資金 × risk% / 100`

`1数量当たりSL損失 = 整数tick数から求めた距離 × 換算係数`

`数量 = floor(許容損失 / 1数量当たりSL損失 / 数量刻み) × 数量刻み`

`予定SL損失 = 数量 × 1数量当たりSL損失`

換算係数は「価格が1動いたとき、数量1で口座通貨がいくら動くか」です。銘柄の契約仕様・口座通貨換算を利用者が確認して入力します。資金または係数が0なら算定しません。数量1とFXの1lotは同一と仮定していません。数量刻み未満なら「最小数量未満・算定不可」と表示します。

スプレッド、手数料、スリッページ、資金調達費用、証拠金・レバレッジ・取引所上限は計算に含めません。表示は費用なし理論値で、実際の損失上限や発注可能数量を保証しません。
