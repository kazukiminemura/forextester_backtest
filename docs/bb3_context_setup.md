# BB ±3σ 準備・見送り・裁量候補

TradingView Pine Editorへscripts/tradingview/bb3_context_setup.pineの全文を貼り付け、USDJPYの通常ローソク足5分足に追加する。
これはインジケーターで、自動売買・建玉管理・損切り・PF計算は行わない。WEMOFの公式仕様の完全再現ではない。

- 黄色の「準備」: 確定足で±3σタッチ。まだエントリーではない。
- 灰色の「見送り」: 指標除外時間、勢いを伴う高安/節目突破、裁量停止、準備期限切れなど。
- BUY/SELL「候補」: 準備の次足以降、初期設定ではバンド内に終値が戻り、中央線到達前で除外条件に当たらない場面。最終判断は手動。
- オレンジ線: BB中央線。決済判断の目安であり、触れれば必ず利益になる線ではない。

## 仮定した条件

BB20・母標準偏差±3倍。直近高安は現在足を除く12本、節目は0.5円間隔。
「勢い」は現在のTrue Rangeが直前ATR14の1.5倍以上、かつ終値で高安/節目の外へ出たこと。
タッチ足だけでなく、その直前の突破も記憶する。初期設定では突破足とその後3本（5分足なら最大15分後）を見送り対象にする。
終値が記憶した突破水準に戻る/内側へ入る、期限を超える、欠損足をまたぐとその勢い判定を解除する。新しい勢いある突破が出れば水準と期限を更新する。
例: 高値を大きな足で上抜け → 次足で+3σタッチ → SELL準備にせず見送り。下抜けから−3σタッチはBUYを見送る。
高安突破の上/下と節目突破の上/下を別々に記憶する。「突破後の勢いを見送る本数」を0にすると元の突破足のみの判定になる。
買い準備では下方向、売り準備では上方向の突破を除外。どの数値もユーザー提示の公式条件ではなく変更可能な代理条件。
準備期限はタッチの次足から3本。次足以降でバンド内へ終値回帰する条件も今回の補助仮定で、設定から解除できる。
タッチ時と候補化前の両方で除外を確認する。反対側タッチ、中央線到達済み、欠損足/週末ギャップで準備を取消。
候補化後はポジションを追跡しないため、実際に保有中でも新しい準備が表示され得る。

## 経済指標と裁量

重要指標の自動取得は未実装。3つまで日時を手入力し、各チェックを有効化する。初期値は発表15分前〜30分後を除外。
日時のタイムゾーン表示を確認して正しい絶対日時を入力する。日々の指標を自動更新する機能でも、3年分を網羅する機能でもない。
「裁量見送り：候補を全停止」は入力設定のため履歴全体へ適用される。過去の特定バーを個別承認する機能ではない。
除外条件が見つからないことは「説明のつかない動き」の証明ではない。突発ニュースや未登録指標などは手動確認が必要。
アラートは一度だけ/バー確定時を選ぶ。候補アラートをそのまま実注文に接続しない。

## 確認状態

ローカルの構造チェックのみ。TradingViewでのコンパイル・表示・アラート動作は未確認（TV_UNVERIFIED）。
確定足に限定したシグナルであり、進行中のタッチへの即時判定ではない。ストラテジーの過去結果と同一とは扱わない。
