## ステータスの配置（最新版）

シンプル表示を既定ONにした。YTT一覧は「通貨・タイミング・突破価格」の3列、新規成立を先頭、その次に突破待ち。上位足の詳細表・突破済・見送り・古いデータは非表示。詳細に戻す場合は統合表示の「シンプル表示」をOFF。BB一覧に切り替えた場合は従来のBB一覧を使用する。

シンプル表示では過去のYTT/BB候補成立ラベルを隠す。高安・チャネル・BBバンド・現在の突破待ちラインは保持。古い/欠損データしかない場合は「更新待ち」と示し、候補なしと混同しない。

通知を受けるには、設定の「新しい候補成立を通知対象にする」をONにしてからTradingViewのアラートを作成し、条件「Any alert() function call」を選び、アプリ通知を有効にする。既存アラートは古いスクリプト/入力のコピーを使うため、更新後は作り直す。通知実受信は未確認。通知は分析候補であり自動注文ではない。

「買い：終値で超え待ち」「売り：終値で割れ待ち」ではエントリーしない。「候補・直近確定」が出た足の時刻と銘柄を確認する。成立後の追いかけ買い/売りを許可する表示ではない。判断足の確定後に表示するので、足の途中で価格に触れただけでは成立しない。

## BB3σ反転の使い方

1. 最新 `scripts/tradingview/yosuga_ytt_combined.pine` 全文を貼り付けて保存し、旧統合版に代えて1本だけチャートに追加する。
2. 設定 → 統合表示 → 通貨一覧を「BB3σ反転」に変更すると、下段で同じ8通貨の反転状態・突破基準・取消水準・中央線幅を比較できる。「YTT」に戻すと従来一覧に切り替わる。
3. 価格チャートにはBB中央線/±3σ、準備・陽線/陰線回帰確認・突破基準・候補ラベルを描く。YTT水平線・チャネル・現在銘柄の状態は保持する。

BBは現在のチャート時間足で判定する。既定で「5分足に限定」はOFF。元の限定を使う場合は設定ONで5分足へ切り替える。15分表示は15分での収益検証や合格を意味しない。YTT一覧は別の判定足入力を使う。

BBはタッチ足で準備し、後続足の陽線/陰線とバンド内回帰で反転確認、さらに次足以降の高値/安値の厳密突破で候補を確定足終了後に示す。終値が突破価格を維持する条件は元BBにない。YTTの厳密な終値突破条件と混同しない。取消水準の更新と突破が同じ足に起きた場合は取消を優先する。

BB通知は統合表示の「BB3σ反転の確定候補を通知対象にする」をONにしてから作成する。既定OFF。YTTとの方向AND条件は追加していない。

BB仮想RR1は元計算を維持し、右上の仮想勝率表示は既定OFF。表示する場合は「右上にBB仮想勝率を表示」をON。これはコストを仮定した読み込み履歴の参考集計で、実約定・実収益ではない。履歴BBラベルは直近300件で保持する。

通貨スキャナーだけへの貼り替えで高安・チャネル描画がなくなる問題を解消する、1本で追加できる統合版。

1. `scripts/tradingview/yosuga_ytt_combined.pine` をPineエディターに全文貼り付けて保存し、チャートに追加する。
2. 元の「FX候補一覧」と「分析補助」が入っている場合はチャートから外す。統合版のみで両機能を表示する。
3. 通常のFX15分足を開く。価格チャートに高安・チャネル・現在銘柄の状態、下段に8通貨の一覧を表示する。

売買条件を変更せず、2つの分析インジケーターを合成。両方のピボット本数は共通設定。手動シナリオは既定OFFで、追加時の価格・時刻クリック入力は求めない。必要時は設定から入力できる。

水平線は検出された確定高安を描く。既定では終値で突破した線も保持件数内に点線で残す。「終値で突破した水平線を削除」をONにすると削除する。

チャネルの生成条件は維持している。方向に沿う2つの確定ピボットと、その区間内の反対側ピボットから有効な幅を計算する。極値の時刻を接続して描き、右側余白がなくても過去部分を確認できる。次の生成条件が未成立の場合は前回の有効線を灰色点線・「前回チャネル（参考）」として残す。一度も条件成立していない場合は表示されない。「直近の平行チャネル（近似）」をONにして使用する。過去部分も作成時に初めて判明する参考線で、過去の売買シグナルではない。

日足の現在銘柄分析は週足＋月足の自動条件を維持する。8通貨一覧の既定判定は15分足で、チャート足がそれより大きい場合は一覧に「設定不正」と表示する。日足で一覧も使う場合は一覧の判定足を日足・上位足を週足/月足などに設定する。

生成: `python scripts/build_ytt_combined_pine.py`。元の `yosuga_ytt_assistant.pine` と `yosuga_ytt_fx_scanner.pine` を保持し、宣言・表示先・衝突する名前だけを変更して合成する。生成後はTradingView確認が必要。

表示先の根拠: [TradingView公式 force_overlay](https://www.tradingview.com/pine-script-docs/visuals/overview/)。確定候補・通知・収益性の制約は [FXスキャナーの使い方](yosuga_ytt_fx_scanner.md) を参照。
