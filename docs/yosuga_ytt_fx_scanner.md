**水平線・チャネルも使う場合は [YTT統合版](yosuga_ytt_combined.md) を1本だけ追加する。** この専用スキャナー単体には高安・チャネルの描画機能がない。従来2本を同時利用する手順は下記に残す。

8通貨のYTT近似条件を別パネルで比較する分析補助。既定は15分足での突破、上位条件は日足・週足の確定した方向一致。公式YTTの完全再現ではなく、利益検証で採用された戦略でもない。

## 導入

1. TradingViewでOANDA:USDJPYなどの通常のFXローソク足を15分足で開く。
2. `scripts/tradingview/yosuga_ytt_fx_scanner.pine` 全文を新規Pineインジケーターに貼り付け、保存してチャートに追加する。
3. 下段の通貨一覧で「買い待ち」「売り待ち」の方向と突破価格を確認し、その通貨のチャートを開く。

従来の分析補助とは別のインジケーター。既存の高安・チャネルとステータス表は保持される。監視通貨は設定の銘柄欄から変更できる。日足・週足の方向は形成中の足を使わない。

## 状態の読み方

|表示|意味|
|---|---|
|買い待ち / 売り待ち|上位足の方向が一致し、未突破の確定ピボット価格を監視中。表示価格を終値で超える/割る条件を待つ|
|買い成立 / 売り成立|表示された確定足で初回の厳密な終値突破が成立。確認対象の足と時刻を見る|
|突破済|そのピボットは消費済み。いつでもエントリーできる意味ではない。次の確定ピボットを待つ|
|見送り / データ不足|方向不一致または未判定、必要な高安が不足。新規候補を表示しない|
|設定不正 / 古いデータ|時間足の組合せまたは更新状況を確認する。新しい成立として扱わない|

判定価格は監視対象銘柄の価格刻みに合わせる。銘柄ごとの確定時刻は日本時間で表示する。一覧はホストFXチャートの更新で計算されるので、常時バックグラウンドで自律的にスキャンする外部サービスではない。休場・更新停止・異なる取引セッションの場合は時刻を確認する。

## 確定足と通知

監視足のデータは1本前の確定値を取得する。成立は次の監視足の開始後、ホストチャートが更新した際に表示される。判定足より大きいチャート時間足は対象外。15分判定なら15分以下のFXチャートを使う。

アラートを使う場合は設定の「新しい候補成立を通知対象にする」をONにし、本インジケーターの `Any alert() function call` を選択する。アラート作成直後の既存成立を再送せず、新しい確定足の成立を通知する。価格の一瞬の接触、同値終値、消費済みピボットの再突破は新規成立にしない。

過去リプレイでは現在時刻からの経過時間により「更新待ち」となる。成立の古さを誤認しないための仕様で、リプレイ研究用スキャナーではない。

この表は条件の監視用で、発注・ロット・利益確率を計算しない。月利5%の裏付けは得られていない。既存の不採用結果は `docs/quant_organization/experiments/ytt_monthly5_fx_20261009/report.md` を参照。
