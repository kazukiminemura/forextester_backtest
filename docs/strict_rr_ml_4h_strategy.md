# 4H順張り・15分足共有ML RR1 改善版

## 結論

よすが式のエントリーへ曜日・時間帯・初動などの条件を追加する方法は、576候補を
検証しても学習期間と検証期間を同時にプラスにできなかった。そこで、4時間足の
確定ダウ方向は維持し、15分足の発火判定だけを固定11通貨共通の共有MLへ置き換えた。

TradingViewのコンパイル上限へ収めるため、20本・最大15葉のコンパクトモデルを使う。
確率しきい値0.485は2010～2022年だけで選び、2023年以降は選定に使用していない。
RRは1:1の全量決済、スプレッド込みである。

## エントリールール

1. AUDUSD、EURUSD、GBPUSD、NZDUSD、USDCHF、USDJPY、AUDJPY、CHFJPY、
   EURCHF、GBPCHF、GBPJPYの11通貨へ同じモデルを使用する。
2. 15分足の毎時00分開始バーが確定した時点で判定する。
3. 確定済み4時間足ピボットの高値・安値がともに切り上がっていれば買いだけ、
   ともに切り下がっていれば売りだけを許可する。未確定4時間足は使わない。
4. 16特徴量の共有モデルで買い・売り確率を計算し、高い側が0.485以上なら候補とする。
5. 次の15分足始値で入り、シグナル終値から2 ATRを基準にSLを置く。
6. 実際の約定価格からSLまでと同じ距離へTPを置き、1Rで100%決済する。
7. 同一足でTPとSLへ触れた場合は損切りを優先し、保有中の追加注文はしない。

特徴量は過去1・4・16・64本の値動き、EMA、RSI、ローソク足、ATR、スプレッド、
時刻、曜日だけである。将来の高値安値、取引結果、通貨ペア名は入力していない。

## TradingView版

`scripts/tradingview/strict_rr_ml_15m_strategy_2026.pine`は注文を出さない
インジケーターであり、15分足へ追加して使用する。
白がEntry、赤がSL、緑がTP 1Rである。右側の表には確定4H方向、買い・売り確率、
採用しきい値、現在のチャートで決済した取引の勝率を表示する。

BUY/SELL確定後、次の15分足始値から内部で仮想取引を追跡する。同一足でSLとTPの
両方へ触れた場合は損切りとして集計する。TradingViewへ売買注文は送信しない。

右下の11通貨一覧は、`BUY`・`SELL`を完全候補、`買い監視`・`売り監視`を
4H方向だけ成立した準備状態として表示する。完全候補は直近の正時判定から2本以内に
限定し、古いシグナルを残さない。`ML値`列は4H方向側のモデル出力であり、
過去トレードの勝率ではない。48.5%以上かつ反対方向以上で完全候補となる。
`Entry`列は完全候補だけに表示し、次足がまだ始まっていなければ`次足始値`、
始まった後は実際の始値を表示する。監視状態には固定Entry価格がないため`--`となる。
初期値はOANDA銘柄だが、設定の「通貨ペア・チャンス一覧」でブローカー銘柄を変更できる。
一覧計算のEMAは軽量なTradingView標準EMAなので、実際のエントリーは対象通貨チャートを
開き、メイン判定とEntry・SL・TPを確認してから扱う。

このPineは2026年モデルを固定した2026年専用品である。2025年以前へ同じモデルを
当てる表示や、2027年以降に更新せず使うことはウォークフォワード検証の再現に
ならない。2027年は2026年末までに決着したデータで再学習・再生成が必要である。

利益は保証されない。実運用前に、利用ブローカーのスプレッド価格差を入力し、
対象通貨ごとにTradingViewの注文約定とForex Testerの結果差を確認すること。
