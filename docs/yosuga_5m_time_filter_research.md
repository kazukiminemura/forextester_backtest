# よすが式5分足：時間帯・曜日・当日取引回数フィルター検証

## 結論

勝率50%以上かつ利益率0%以上を、学習期間と検証期間の両方で満たした区分はありませんでした。

- 採用時間（JST）: なし
- 採用曜日（JST）: なし
- 採用できる当日取引回数: 0回
- 時間・曜日・回数を組み合わせた採用候補: なし

そのため、現時点ではインジケーターへ時間・曜日・回数制限を追加していません。指定ルールをそのまま適用すると、全エントリーを停止することになるためです。「最もましな時間帯」だけを後から選ぶことも、検証結果への過剰適合を避けるため行っていません。

## 検証条件

- 対象: XAUUSDを含む14銘柄
- エントリー足: 5分足
- 環境認識: 確定4時間足の壁・トレンド、確定15分足スイング
- トリガー: 5分足のプライスアクションと直近高値・安値ブレイク
- 決済: 全量を1Rで利確、全量を1Rで損切り
- コスト: スプレッド込み
- 集計時刻: 日本時間（JST、UTC+9固定）
- 採用判定: 学習期間と検証期間の双方で、勝率50%以上かつ利益率0%以上
- 最低標本数: 時間別 50/20件、曜日別 100/40件、回数別 30/15件（学習/検証）

採用判定には2010–2018年と2019–2022年だけを使用し、2023年以降は判定後の確認用として分離しました。

## 利益率の定義

このレポートの利益率は、`純損益R ÷ 取引数 × 100` です。口座残高に対する複利収益率ではありません。固定RR 1:1のため、勝率50%で損益0R、50%未満ならコスト控除前でもマイナスになります。

## 判断

時間帯の厳選以前に、元の5分足エントリー条件自体がすべての独立期間で負けています。時間・曜日・回数フィルターで救済する段階ではなく、エントリー条件を作り直した後に同じ手順で再集計する必要があります。
