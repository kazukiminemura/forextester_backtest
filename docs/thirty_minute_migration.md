# エントリー30分足への切替

## 変更内容

2週間程度シグナルが発生しなかったため、4時間足のダウ方向判定とRR 1:1を維持し、
エントリー判定を1時間足から30分足へ切り替えました。

- TradingViewの対象チャート: 30分足固定
- 通貨ペアスキャナー: 確定30分足を使用
- Python CLI: `--entry-timeframe 30m`が既定
- レンジ: 直前3本、実時間3時間から90分へ短縮
- 押し・戻り探索: 12本、実時間12時間から6時間へ短縮
- 待機期限: 8本、実時間8時間から4時間へ短縮
- 上位足: 4時間足のまま
- 決済: SLと同距離の1Rで100%決済
- 三角持ち合い: 探索・最小期間・ブレイク後保持の本数を2倍にし、従来と同じ実時間を維持
