# 画像の18銘柄監視

価格描画は統合版またはAを使用する。B単体は監視一覧専用。水平線は確定検出バーから描き、突破済みも既定で点線として最大保持件数内に残す。チャネルは確定した2つの極値の時刻を接続して右へ延長するため、右側の余白がなくても過去部分を確認できる。チャネルの過去部分は作成時に初めて判明する参考図で、過去のエントリーサインではない。次のチャネル条件が未成立の間は、前回の有効チャネルを灰色点線・「前回チャネル（参考）」として残す。有効なチャネルが一度も成立していない場合は描かない。

## 1本の統合版

`scripts/tradingview/yosuga_ytt_watchlist_unified.pine` に18銘柄と価格描画を統合した。監視範囲を全18/A9/B9から選ぶ。全18は54監視request＋最大9価格request=最大63のため、64件対応プランが必要。実機で確認したBasicでは40件が上限で、1本で全18を同条件のまま監視できない。

既定はA9で、監視タイトルに「9/18銘柄」と明示する。全18を選び、64件対応チェックをOFFのままにすると監視を停止し理由を表示する。対応チェックはプランを変更する機能ではない。40件プランでONにすると実行上限に達するためONにしない。全18同時をBasicで継続する場合は下記のA/B2本構成を使用する。

統合版の全18モードはBasicでは実走できず、同条件の9銘柄モード・上限ガードの実機確認と構造テストで引渡す。64件プランでの全18実走は別途必要。

同じチャートに監視AとBを各1本追加する。Aは価格チャートの高安・チャネル・BBと前半9銘柄、Bは後半9銘柄の一覧。旧統合版を重ねる必要はない。元のソースと個人スクリプトは保持する。

- A: XAUUSD、EURUSD、GBPUSD、USDJPY、EURJPY、GBPJPY、NZDJPY、CADJPY、AUDJPY。
- B: USDCHF、USDCAD、NZDUSD、EURAUD、EURCHF、GBPCHF、AUDNZD、EURGBP、AUDUSD。

すべてOANDAを既定配信元にする。画像では各銘柄の配信元まで読めないため、銘柄設定で実際の配信元に合わせられる。XAUUSDは金であり通貨ペアではない。

既定条件は15分確定足・日足/週足の終値突破方向一致。新規成立を先頭、未消費の突破待ちを次に示す。古いデータ・突破済み・見送りはチャンス行に出さない。「待ち」では入らず、候補の確定時刻を確認する。BB反転はAの現在チャート描画だけを維持し、18銘柄のBBスキャンではない。

通常40件のrequest上限に対し、Bは9×3=27、Aは27＋価格用上位足最大8＋BB現在銘柄1=最大36。AはBB多通貨スキャナーへの切替を無効にする。Basicの2本上限内で18銘柄と価格描画を両立する。公式上限: https://www.tradingview.com/pine-script-docs/writing/limitations/

通知は各監視版の「新しい候補成立を通知対象にする」をONにしたうえで、各スクリプトのAny alert() function callにアラートを作成する。既存アラートは更新後に作り直す。アラート数は利用プランの上限に従う。チャートを閉じても動く監視にはTradingView側でアラートを作成する必要がある。AIがチャット終了後に常駐する仕組みではない。

再生成: `python scripts/build_ytt_watchlist_pine.py`。元の確定snapshot・通知gate・YTT近似ルールを再利用。単なるウォッチリストの現在値から売買チャンスは判断しない。採用済み収益戦略・自動注文ではない。
