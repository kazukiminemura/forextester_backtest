# XAUUSD 専用条件の検証

探索324候補、件数基準通過141、条件作成・選択の両期間でPF1.2以上・平均損益プラス0候補。

選択条件：60分足、ADX≥25、方向別RSI≤100、EMAからの方向別距離≤100ATR、保存時刻06〜16時未満。

2026年は7月17日まで。XAUUSDの履歴は2013年5月開始。勝率は時間決済を含めコスト後の損益がプラスだった割合。

採用判定：未達・不採用。Pineの売買条件は変更していない。

2010〜2018年で条件作成、2019〜2022年で条件選択。単一銘柄の必要件数を順に250・100件とし、両期間PF1.2以上の候補を優先、両期間の勝率の低い方が最大の候補を選択。2023〜2024年と2025〜2026年は選択後に評価し、結果による選び直しはしない。採用には全4期間で勝率68%以上、PF1.2以上、平均Rプラス、後半各期間50件以上も必要。

12銘柄共通条件から金専用条件へ探索対象を変更した追加調査。後半期間の集計は既に見ているため完全な未見データではない。金を含む既存の監査済み候補データを再利用し、そのSHA-256をJSONに保存。

利確3ATR・損切り1.5ATR、最長4時間決済、次足始値で約定。固定スプレッドと不利な成行スリッページを含む。データ欠損による決済遅延も損益に含める。取引時刻は保存時刻であり、日本時間とは断定しない。
