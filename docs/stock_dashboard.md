# 株式検証ダッシュボード

開く: [http://127.0.0.1:8769](http://127.0.0.1:8769)

保存済みの日本株日足検証を、このPCのブラウザーで確認する画面。
Python標準ライブラリとHTML/SVGで動作し、外部ライブラリや外部通信は不要。

## 起動

プロジェクト直下から実行する。

```powershell
python scripts/stock_dashboard.py
```

サーバーを止めた後やPCを再起動した後は、このコマンドで再開する。
ポートが使用中の場合は `--port 8770` など別番号を指定できる。停止は起動した端末でCtrl+C。
自動起動・インターネット公開は設定していない。127.0.0.1だけで待ち受ける。

## できること

- 第3研究の6仮説と段階別成績、固定比較案の9年追跡、費用損益分岐・利益集中・PF区間を表示。未実施と0取引、固定比較と採用候補を区別する。更新は `python scripts/export_stock_deep_dashboard.py` で保存済み結果から生成。

- 追加研究3案の2017–2019比較とJev評価状態を上部に表示。初回実験の期間/費用フィルターとは独立。APIを画面から呼ばず保存記録のみを読む。

- 9年連続 / 各3年間、通常費用 / 費用2倍、全10株 / 9株 / 7株の切り替え。
- 合計または1銘柄の損益、勝率、PF、最大DD、資金推移、年別損益の確認。
- 買い持ち曲線との比較。保有割合の違いを併記。
- 銘柄名から個別成績へ切り替え。
- 取引明細の利益 / 損失表示、ページ送り、CSV保存。
- 取引の「チャート」で日足ローソク、買付・決済日、買値 / TP / SLの価格表示。
- 元データの出典・補正・研究上の制約を確認。

「保存結果を再読込」はファイルの再読込。株価再取得・バックテスト再実行・注文は行わない。
CSVは上部の期間・費用・対象銘柄条件に対応する全明細で、明細表の利益 / 損失表示フィルターは適用しない。
年別値は表示区間の残高差で、区間初年度は初期資金からの差。3年区間は独立リセット、9年連続は年越し持ち越し。
初回実験の採用基準表示は全10株・通常費用に対する実験全体の判定で、画面で絞り込んだ銘柄への採用判定ではない。

## 保存ファイル

- 株価: `data/stocks/yahoo/jp_largecap10_20260926/`
- 結果: `agent_runs/tamukai_stocks_daily_cached_replay/results/`
- 元の実験報告: [tamukai_stocks_daily.md](tamukai_stocks_daily.md)
- データ保管方針: [data/stocks/README.md](../data/stocks/README.md)

サーバーは元JSON/CSVのSHA256を起動時に確認し、結果が参照するCSVのSHA256も照合する。
データが合わない場合は表示を停止し、再ダウンロードや上書き補修はしない。
同じ形式の別結果を確認する場合は `--results <結果フォルダー> --data-dir <株価フォルダー>`。
この初期版の銘柄一覧と期間・品質区分は今回の実験用に固定されている。

## 確認

```powershell
python -m unittest discover -s tests -p test_stock_dashboard.py -v
```

保存集計との一致、年別残高差、条件切替、HTTP/CSV/株価応答と不正パス拒否を確認。
実ブラウザーでも期間・費用・銘柄・除外区分の切替、買い持ち表示、取引詳細、損失フィルター、CSVダウンロードを確認した。
