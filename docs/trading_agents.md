# トレード研究エージェント

## 計画と対象

既存のForex Tester読込・田向式バックテストを再利用する小規模な研究基盤。
研究担当、機械判定担当、監査担当を分離し、LLM接続は交換可能なProtocol経由とする。
自律的に候補作成→複数銘柄・3期間検証→判定→レポートを実行する。
証券口座接続、発注、リアルタイム監視、定期実行はまだ含まない。

## 実行

リポジトリのルートで実行する。Python標準ライブラリのみ使用。

```powershell
$env:PYTHONPATH='src'
python -m forextester_backtest.agents --symbols USDJPY EURUSD --boundaries 2021-01-01 2022-01-01 2023-01-01 2024-01-01
```

デフォルトはAPI通信なしの固定3候補。これはLLM推論ではなく、配線・検証用モード。
AIによる候補作成と結果監査を使う場合は、環境変数 `OPENAI_API_KEY` を安全に設定し、
利用可能なモデルIDを `--model` に指定する。キーをチャットや設定ファイルへ貼らない。
モデル指定時は最大2回のResponses API呼出しが発生し、候補仕様と集計結果を送信する。
履歴ファイル、取引一覧、APIキーはプロンプトへ送信しない。

```powershell
python -m forextester_backtest.agents --model YOUR_MODEL_ID --symbols USDJPY EURUSD --boundaries 2021-01-01 2022-01-01 2023-01-01 2024-01-01
```

`agent_runs` 配下に実行別ディレクトリを作成する。
`protocol.json` は実験前の候補と基準、`events.jsonl` は進捗・失敗記録、
`results.json` は全判定、`report.md` は日本語レポート。
失敗時は非ゼロ終了する。レポート完成をもって実行完了とする。

## 判定と制約

- 4H/15m、RR1で全決済を固定。AIは方向とレンジ幅だけ提案できる。
- 2〜11銘柄、最大3候補。全候補を検証前に確定し、結果による自動再調整なし。
- 各銘柄・各期間で30取引以上、PF1.2以上、純利益正、DD10%以下。
  これは初期の研究用基準であり、統計的有意性や実運用可否を保証しない。
- PF不明・非有限値・取引不足は不採用。全件不採用も正常終了。
- 各期間は開始を含み終了を含まない。90日のウォームアップ。端の7日超欠損を拒否。
  内部欠損・価格異常・履歴修正の包括的監査は未実装。
- 読込バーのSHA256と銘柄メタデータを記録。履歴そのものの保管は別途必要。
- 固定0.1lot、初期資金10000（銘柄のクオート通貨単位）。異通貨損益は合算しない。
- スリッページ・スワップ・口座通貨換算等は既存エンジンの未実装事項。
- 同じholdoutを繰り返し見れば未使用期間ではなくなる。閲覧済み期間の横断管理、
  候補選択後の一度限りの確認試験、ウォークフォワード検証は今後必要。
- 監視担当は研究結果の監査のみ。緊急停止、リスクゲート、実口座監視は未実装。
- APIエラー時に機械判定を変更しない。監査APIだけ失敗した場合も集計結果を保存。

API実装は https://developers.openai.com/api/docs/guides/text を参照。
