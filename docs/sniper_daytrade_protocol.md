# SNIPER デイトレード改善の検証条件

目的は、再構成版のシグナルを厳選し、コスト控除後の勝率を約70%に近づけること。原作者の非公開ロジックの検証ではない。

## 選択前に固定した条件

- データ：Forex Tester ローカル履歴、既存の12銘柄。2010年〜2026年7月17日（XAUUSDは履歴開始以降）。
- 時間足：5分・15分・30分・1時間。
- シグナル：既存Pineの `f_engine()` を直接変換して利用。確定足のみ。
- 発注：シグナル直後の足の始値。直後の足が欠損していた場合は発注しない。
- 利確：エントリー約定価格から3ATR、損切り：1.5ATR。TP3で全決済。距離はシグナル時ATRで固定。
- エントリー：保存時刻の06:00以上16:00未満。保存時刻のタイムゾーンは断定しない。
- 保有：最長4時間を予定し、期限以降の最初の足の始値で決済。欠損による遅延は結果に含め、件数を別記する。
- 銘柄ごとに1ポジション、同じ足での決済後再エントリーなし、エントリー間隔は最低5本。同時に複数銘柄を持つ場合の資金配分は未モデル化。
- OHLCをBidとして扱い、Askは銘柄メタデータの固定スプレッドを加算。成行エントリー・損切り・時間決済には片道スプレッドの10%の不利なスリッページを加算。実測の変動スプレッドや実約定ではない。
- 買いはAskで入りBidで出る。売りはBidで入りAskで出る。同じ足でTPとSLに到達したらSL優先。損切りを飛び越えた場合は不利な始値で約定。TPは指値どおり。
- 各銘柄の設定手数料が0であることを実行時に確認。スワップと最小価格単位への丸めは未モデル化。

## 条件探索と評価

ADX下限（18 / 25 / 35）、方向別RSI上限（65 / 75 / 100、売りは100−RSI）、方向別EMA距離上限（1 / 2 / 100 ATR）、開始時間帯（06–16 / 08–12 / 12–16）を組み合わせる。4種類の時間足×81条件＝324候補。100は実質的に上限フィルターなし。通貨ペアを選別しない。

2010〜2018年を条件作成、2019〜2022年を条件選択に使う。前者500件以上、後者200件以上、後者で20件以上ある銘柄が6銘柄以上の候補を対象とする。両期間ともPF1.2以上・平均損益プラスの候補を優先し、両期間の勝率の低い方が最大になる候補を1つ選ぶ。該当がなければ件数基準を満たす候補の中で同じ順位付けをし、未達を明記する。

選択した1候補だけを2023〜2024年、2025〜2026年7月に適用する。評価結果に応じた再選択は行わない。ただし後半期間の既存ロジック集計は以前の調査で見ているため、完全に未見のデータとは呼ばない。

期間の所属は決済年で判定する。これにより、年末の欠損をまたいで確定した損益が、条件選択に使う年のデータへ混入することを防ぐ。

採用の必要条件：4期間すべてで勝率68%以上・PF1.2以上・平均損益プラス、取引件数が順に500 / 200 / 100 / 100以上。条件未達なら元のPineに採用しない。探索した候補数が多いため、通過したとしても将来の勝率の保証にはならない。

勝率は時間決済を含めたコスト控除後の損益が正だった取引の割合。TP3到達率とは異なる。PFは利益合計÷損失絶対値合計をR単位で計算し、1Rは各取引の1.5ATR。各取引を同じリスク額とみなす比較値であり、実口座の収益率ではない。
