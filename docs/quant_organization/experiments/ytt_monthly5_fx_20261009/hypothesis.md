# FX月利5%：日足・週足の方向一致を使う固定研究

元金100万円、元金から実現・含み損合計10万円減少で停止。初月の5%は5万円。以降の月利5%は各月期首純資産を分母とする。毎月5%以上、幾何平均月利5%以上、算術平均月利5%以上、毎月固定5万円は異なる条件として全て表示する。資金追加・月初リセット・後期からの口座再開は行わない。

## 結果前に固定する仮説

1. A `dw_m15`：日足と週足で確定pivot突破の方向が一致した期間は、より長い資金フローが短期変動の順方向継続を支える。M15の新規確定pivot突破で順張りする。現在のYTT分析補助のD/W設定に対応する独自近似で、公式YTTの完全再現とは呼ばない。
2. B `dw_h1`：同じD/W方向一致の下、H1の価格構造はM15より短期の往復変動を減らし、SL幅に対する固定費用の割合を下げる。H1の新規確定pivot突破で順張りする。
3. C `no_htf_h1`：Bの単純比較。H1の同じ突破からD/W条件だけを外す。採用候補はA/Bの2件、実走条件は比較対象を含め3件で終了する。

方向判定が遅れて高値・安値を追う局面、長期トレンド終盤、レンジ、広いSLで日次清算までに1Rへ届かない局面で仮説が崩れる。H1/H4・M15の旧不採用結果を見てパラメータを最適化しない。旧M15 noHTF成績はAの比較に参照し、新たな候補探索に使用しない。利確・損切りの価格距離はRR1、全決済を維持。

## source-clock、D/W、利用可能時刻

旧監査済みM5 OHLCとcomplete_m5、原M1の実際の最初の観測時刻を使用。source-clock timezoneは未確定で、TradingViewのD/W境界との一致は主張しない。日足はsource00:00、週足はsource月曜00:00を境界として、その期間に実際に観測されたOHLCを集計する。期間全体が終了してから次の期間で参照可能となる。土日を含む7日間全てのM1やM5が存在する条件は課さない。

D/Wの観測M5数、complete_m5数と割合、観測暦日数、曜日、観測された同一暦日の最初と最後のM5間の欠落数を診断として保存する。暦日にデータがないことを自動で真の欠損とも休日とも断定しない。市場休場・祝日・実際の欠損を完全分類できないため、D/Wは終了済み観測足の近似である。診断値を見て閾値を追加しない。

M15/H1は必要な完全M5が全て揃った足だけでpivot計算。D/Wは終了済み観測足で計算。左右2本pivot、高値は左以上・右より大、安値は左以下・右より小。同値のPine内部実装一致は未確認。方向は新pivot登録前の高安を終値が跨いだ方向を保持する。A/BはD/Wとも非ゼロ方向と高安2点が存在し、方向が一致した場合だけ許可する。開始時に不足している高安を将来足で補完しない。2019年12月からの利用可能データでウォームアップし、足りない期間の取引は0件とする。

上位足を参照する基準はエントリー判断足の開始時刻。例えばH1の10:00開始足が11:00で確定しても、10:00時点で利用可能だったD/Wの前足状態を使う。消費済pivot突破は再利用せず、合意不成立の間でも消費を進め、新pivot登録時にリセットする。欠損を挟んだ完全足の状態は観測順で保持し、古い状態の期限は設けない。

## 注文・価格経路・口座

判断足の終値で新規閾値突破が確定した後、次の判断足の連続する始値でエントリーする。原M1の最初の時刻が予定始値と一致することが必要。不完全M5のbucketラベルを実際の始値時刻と扱わない。SLは判断足開始前に既知だった反対pivotの1tick外側。次足始値とのSL距離が正でなければ注文なし。TPは次足始値からSLと同じ価格距離の1R。

価格経路は3条件とも同じM15 OHLCで処理し、同一足SL/TP両到達はSL優先。SL gapは不利な実観測始値、TP gapはTPまで。1通貨1ポジション、保有中signalは破棄。source23:45開始M15の終値で日次全決済、上限96本。欠損は次の原M1観測始値で清算、不完全M15はSL/TP処理後に利用可能終値で清算。期末は最終観測価格による評価清算で、最終観測足を事前に知る実注文とは扱わない。

費用はUSDJPY1.2/EURUSD1.1/GBPUSD1.4pipsのspreadと片道0.2pipのslippage、往復費用を価格損益から控除する近似。両者2倍のstressも固定。手数料0仮定・スワップ未算入。source日次決済がNYロールオーバー回避を保証するわけではない。

円口座はUSDJPYだけ。2020年初の100万円から2025年末まで継続し、1取引の予定SL損失は費用込み現在資産0.5%以内、1000通貨刻み切下げ、名目額25倍以内。0.5%は研究仮定で推奨ではない。費用込みの純資産90万円の境界を不利側OHLCで監視し清算・以降再開しない。gapでは10万円以上の損失となり得る。元金損失とピークからの最大DDは別表示する。後期別成績は同じ継続口座の部分曲線から計算し、各後期で100万円へ戻さない。

## 期間・月別指標・事前gate

2020–2022/2023–2024/2025は全て既閲覧。2025は最新記述期間で真の未使用最終確認ではない。全72月をゼロ取引月・停止後の月も含めて保存。月末MTM、月損益円、月次収益率、幾何/算術平均、中央値、最悪月、5%達成月率、固定5万円達成月率、最良月を1つ除いた幾何平均を出す。月末終値清算は旧月、月初open/gap決済は新月。
