# FX月利5%目標の有限検証

2026-10-09。ユーザー指定対象FX、元金100万円、元金から10万円損失で停止。月利5%は初月5万円。税引前・利益引出しなしの研究仮定とし、各月の月初MTMに対する5%と固定5万円を別表示する。

## 必要性と範囲

YTT表示は損益評価を含まない。旧H1/H4・M15突破は独立検証済み赤字で、目標額変更だけでは改善しない。現在表示のD/W合意と、より遅いH1で費用比率を下げる仮説を有限に評価する。結果に合わせた閾値調整はしない。

1. data担当: 既存3通貨の原履歴とcache識別子・制約を読取確認。data_inventory.mdのみ所有。
2. researcher: D/W M15、D/W H1、H1 noHTF比較の固定3case、protocol/hypothesis、専用runner/tests、結果フォルダを所有。主のfreeze前に実走しない。
3. validator: protocol事前確認と独立参照再実装、validation.md/verify script所有。研究コードをimportしない。
4. 主: ゲート決定・freeze記録・board/report。データ工程終了後、品質監査担当へ別工程を渡す。合格証拠がなければPine売買条件へ移植しない。

## 主の結果前ゲート

期間は2020–22開発記述、2023–24後期記述、2025最新記述。全て既閲覧、真の未使用検証はない。候補の事後追加なし。

USDJPY円口座: 初期100万円、費用込み予定SL0.5%以下、1000通貨刻み、名目額25倍以下、含み損込み90万円停止、追加入金/再開なし。0.5%は試算仮定。費用通常/2倍、RR1全決済、M15執行経路、日末清算を固定。

各後期の円評価は2020年からの同じ継続口座の該当部分曲線を使い、月幾何率5%以上・費用後JPY-PF1.2以上・100取引以上・純利益正・月次中央値正・停止なし。早期停止時は後期のゼロ月をそのまま評価する。2020–25全継続口座も停止なし・月幾何率5%以上。倍費用の各後期USDJPYは利益正・停止なし。通貨横断は各後期3通貨中2通貨以上で通常PF_R1.2以上・平均R正・各100取引以上。A/Bは対応する同時間足のnoHTF比較に通常平均Rで劣らないこと。Cは比較用だが月別・口座ゲートも保存。

『毎月5%』は全月r_m>=5%の別判定。幾何/算術平均・中央値・最悪月・達成月比・連続未達月・固定5万円達成比・最良月除外幾何率を保存。停止後ゼロ月を除外しない。PF_RとJPY-PFや他通貨のR合計を円口座利益と混同しない。

全通過しても既閲覧・時計/価格side・境界/欠損・スワップ未再現によりNEEDS_EVIDENCE。実運用承認や毎月利益保証とはしない。不合格の証拠も完了成果物として保存。

法律/口座上限の参照: [金融庁 FXの説明](https://www.fsa.go.jp/ordinary/iwagai/)（2026-10-09確認）。元本・利益は保証されず、gapでは10万円停止額を超える場合がある。
