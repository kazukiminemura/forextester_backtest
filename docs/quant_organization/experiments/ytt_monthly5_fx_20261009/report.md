## ユーザー条件と固定研究

対象FX（USDJPYなど）、資金100万円、元金から実現・含み損合計10万円で停止。初月5%は5万円。月初資産に対する5%・固定5万円・幾何平均5%・毎月5%を区別し、税引前/引出しなしとして評価した。

候補A=日足＋週足合意/M15確定高安突破、候補B=同条件/H1突破、比較C=H1突破で上位足条件なし。左右2本の確定ピボット、事前の反対ピボット外側SL、次足の実M1始値、価格距離RR1全決済、M15経路SL優先、保存時計の日末清算を固定。結果後の条件追加・変更なし。

USDJPY円口座は2020–2025を同じ100万円から連続運用し、費用込み予定SLリスク0.5%以下、1000通貨刻み、25倍上限、90万円純資産で清算・停止。追加入金・月初/後期リセットなし。EURUSD/GBPUSDは費用後R/pipの横断評価であり、円口座と合算しない。0.5%は検証仮定、実運用の推奨ロットではない。

通常費用、全72か月（停止後のゼロ月も含む）。PFはJPY金額の利得/損失比率。

3方式とも全72月の幾何月率は約−0.1462%、固定5万円達成も0/72月。停止の早い方式のゼロ月を除外していないため、この平均だけで稼働中の損失速度を比較してはいけない。Bの最悪月は−3.1651%、中央値−0.0462%。Bは2020–2022に+30,101円だったが、2023–2024は−96,175円、2025は−33,926円で停止。後期の実現損益と月末MTM差額は異なる（2023–2024実現損益−96,989円）。

元金からの最終損失10万円と、ピークからの最大DDは別。終値評価の最大DDはA104,774円/B147,959円/C160,445円。停止基準は元金90万円であり、ピークから10万円下落したら停止する定義ではない。実運用のgapでは停止額超過もあり得る。

費用2倍でも全3口座が停止、5%達成0/72月。A停止2020-06-25、B2022-02-04、C2020-12-21。通常/増加費用の全6口座で目標未達。
