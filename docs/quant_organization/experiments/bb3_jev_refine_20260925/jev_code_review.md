# Jevの用途：コード開発・検証の補助

ユーザー指示により、Jevをエントリー・見送り・利確・損切りには使わない。今回の売買経路は明示的なルールのみ。

Jevに渡すのは新しい研究用コードとテストのソースだけで、個々の市場局面・売買候補・APIキーは入力に含めない。限定した3つの主張を、コードが「支持する／矛盾する／情報不足」で評価させる。

1. 候補判定は候補確定時以前の情報のみを参照し、約定時の利幅判定と混同していない。
2. 2023年の結果のみで条件を選択し、選択結果を保存してから後年を検証している。
3. 売買処理はAI出力や過去のJev応答を読まない。

これは静的レビューの補助であり、コンパイル・テスト実行・収益保証ではない。Jevの回答に関係なく、開発担当以外の検証者が別計算を行う。低確信・情報不足・矛盾は追加確認事項とし、回答をそのまま取引条件へ変換しない。

再実行は同一要求のキャッシュを使う。最大3試行、各試行の最大文脈費用を送信前に台帳へ記録し、前回分と合計2.30 USDを超えない。確率合計には小数2桁の丸め誤差を許容するが、最大確率と選択結果の不一致は無効とする。前回の売買実験の検証条件・結果は書き換えない。

要求・応答・ソースハッシュ・usageは `agent_runs/bb3_jev_refine_20260925/code_review_*.json`、引当は `code_review_reservations.jsonl` に保存。実際の呼び出し・結果は完了後に追記する。

## 実行結果

Jev 1.13.0へのコードレビューを1回実行した。要求hashは `d362089a85ad76d2c6342213b1065a3666ae43257142ad71d320b830b97632e1`。

| 確認する主張 | Jevの回答 | confidence |
|---|---|---:|
| 候補判定の因果性・約定判定との分離 | supports | 0.85 |
| 学習期間だけで選択し保存後に後年を計算 | supports | 0.58 |
| 売買処理にAI応答・キャッシュが入らない | supports | 0.96 |

確率・confidenceは正しさの証明ではない。特に選択順序のconfidence 0.58は自動承認に用いず、独立担当のソース確認と、後年シミュレーション前にselection.jsonが存在することを検査する実行テストで補った。売買条件は回答によって変更していない。

入力6,360token、公式単価に基づく追加概算0.00026712 USD（200円/USDで約0.053円）。1回の最大文脈引当0.002752512 USD。初回実験を含む概算は約7.19円、最大文脈引当は約447.01円。税・換算手数料などを含む最終請求はサービス明細による。

## 保存処理修正後の2回目

最初のバックテストは2023年・5通貨目の途中で、Windowsの一時的な読取りロックによる `progress.json` の置換失敗で停止した。`*.failed1.json` に進捗・途中集計・manifestを保存。条件選択ファイルはまだ作成されておらず、2024/2025の成績計算前だった。

売買仕様・選抜仕様は変更せず、PermissionErrorの場合だけ50ms間隔で最大10回置換を試す処理を加えた。継続失敗は握り潰さず停止する。一時失敗と継続失敗のテストを追加後、新しいソースで2回目のレビューを実施した。

要求hash `f275c55332bec83ea671cad98e4efd1315e6d3f2517d2e3cef4bd147f574fe7d`。3主張ともsupports、confidenceは順に0.84／0.58／0.97。入力6,730token。選抜手順は引き続き独立したコード確認と実行順序テストで検証する。Jevの入力にはimport先の売買エンジン全体を含めていないため、「Jevが全コードの正しさを検証した」とは扱わない。

レビュー2回の入力合計13,090token、追加概算は200円/USDで約0.110円。旧実験込みの概算は **約7.25円**、最大文脈引当は **約447.56円**。同じ固定条件で再計算を開始した。

設計参考：[TypeSafeの主張と根拠を照合する例](https://docs.typesafe.ai/cookbooks/citation_check)、[Confidenceの意味](https://docs.typesafe.ai/confidence)。
