# 反転確認ロジックの追加変更

前回は固定1pipコスト後で全体が赤字。今回は次の3段階を各RR1/1.3/1.5、計9案で一度だけ比べる。ユーザーの明示指示によりJevを売買判断に用いない。最初の18案計画は実行前に取り下げた。

1. **終値維持**：高安をヒゲで越えただけでは不十分とし、終値が突破方向に残り、その足の実体も売買方向へ向くことを要求。
2. **終値維持＋利幅**：約定時に中央線まで5pips以上を要求。仮定1pipコストの比率を利幅の20%以下にする。以前の表示設定3pipsは変更せず、今回の研究比較だけで5pipsを再評価する。
3. **上記＋減速**：中央線の直近3本傾きがその前3本より取引方向に改善し、候補足のTRが直前ATRの1.5倍以下であることを要求する。

条件が増えるほど件数が減るため、勝率だけでなく件数・コスト後R期待値・PF・DDを判定する。RRを増やす案では中央線TPを動かさずSLを近づける。約定は全案で次の連続足始値。売買経路にAI出力・推論待機は含めない。

Jevはコードが仕様を満たすか、検証に漏れがないかという限定的なレビューに最大3回だけ用いる。レビュー結果も独立再計算・テストの代用にはしない。前回の引当446.46円を含め460円相当以内に抑え、ご指定500円を守る。売買用APIの再実行はない。

2023年で選んだ1案のみを後年の採用判断へ進めるが、すべて既閲覧履歴なので過学習を排除できない。全通貨・全期間の数字を保存し、全不合格もそのまま報告する。現行Pine・通知・表示は変更しない。
