# 田向式を参考にした日本大型株・日足押し目買い

これは原典の完全再現ではなく、ダウの高安切上げ・21日移動平均・押し目後の再上昇を機械化した単一派生仮説である。確定した高値と安値が切り上がる局面では買い需要が持続し、平均価格への押しの後に短期高値を超えれば上昇再開を捉えられる、という反証可能な仮説。持合い、トレンド転換、決算等の窓開けでは崩れうる。買持ち対照を置き、複雑なフィルタ・AI判断・候補最適化は加えない。

## 結果を見る前の凍結

候補は1つ。日足ロングのみ、上位足なし。左右2本に対して厳密に中央高値が高い/安値が低いピボットを2営業日後の引けで認識。同値不成立。各系列の直近2個が高値・安値とも切上がり、当日終値>SMA21かつSMA21が2営業日前より上なら上昇トレンド。

直前3本の少なくとも1本の安値がその日のSMA21以下、かつ当日終値が直前3本高値の最大より高ければ当日引けで買い信号。翌観測営業日始値で買い、直前3本安値の最小（信号足は除外）を固定SLとする。始値<=SLは見送り。TP=始値+(始値-SL)、全決済RR1:1。SMA21と2本差に必要な23本以上、ピボット各2個が揃うまで発注しない。

1銘柄1保有。保有中信号は無視。決済日引けの信号は翌営業日に有効。エントリー当日からSL/TP適用。寄付がSL以下なら寄付でSL、TP以上なら寄付でTP、そうでなく両方到達ならSL優先。保有期限なし、評価区間最終日終値で強制清算。窓開け・費用・期末清算により実現損益は正確な±1Rにならない。

各片道コストは売買代金の0.1%、ストレス0.2%。手数料と滑りの包括仮定。初期100万円を10銘柄へ各10万円、銘柄間移動なし。各取引で手数料込み全残高を投じる。端株・連続分割調整株数を許容する研究モデルで、日本株の100株単位注文は再現しない。配当・税金・金利なし、非レバレッジ。買持ちも同じ区間・資金配分・費用で初日寄付から最終日終値。

2016-07-12以降を初期ウォームアップに使う。2017–2019、2020–2022、2023–2025を各々資金・保有リセットし、区間開始以前の信号を持込まない。指標には過去情報を使う。別途2017–2025連続評価を保存し、その日次MTM曲線差から年別損益を算出。年末保有には年末費用を仮計上しない（清算する最終日除く）。DDは初期資金をピーク候補に含める引けMTMであり日中DDではない。保有割合はエントリーまたは保有があった銘柄日/全銘柄日。

rev2は損益実走前のデータ品質訂正。2015-12-25/2016-07-11の元データ欠損判明により開始を変更した。Yahooの後方調整OHLCでSonyの2025スピンオフ調整も混入しており、10銘柄の主解析はDATA_LIMITED参考価格損益、配当非再投資である。8306.T/8035.Tの2022-05-17の2件はhigh=max(H,O,C)/low=min(L,O,C)で包絡拡張、原値/派生値をデータmanifestへ保存。既存sleeveの集約だけでSony除外9銘柄90万円、既知調整問題3銘柄除外7銘柄70万円の診断も保存する。新候補ではなく、残りのデータに調整問題がないことも主張しない。

固定銘柄はprotocol参照。現在の大型株を過去に遡って評価する選択/生存バイアスがある。Yahoo後方調整OHLCを使用する（上記調整問題を含む）。過去の当該価格閲覧状況は不明で、真の未使用期間を主張しない。単一候補の記述評価として全区間を公開し、結果による再調整はしない。

観察基準は検証・最終各100取引以上/PF>=1.1/純益>0/DD<=20%、最終黒字6銘柄以上/ストレス最終純益>0。満たしても独立確認前に採用とはしない。不成立も保存して終了。
