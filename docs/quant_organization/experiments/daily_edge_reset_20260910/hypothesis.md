# 日足FX: 異なる期待値仮説を比較する有限研究

目的は勝率ではなく、費用控除後の正の期待値が複数通貨・複数期間で再現するかを検証すること。ユーザーの方針変更を受け3x3、Double Repo、ダウ転換、固定RR1を解除する。研究開発者は採用承認しない。

## 仮説と反証

1. 中期トレンド: 経済政策・資本移動の持続と市場参加者の段階的反応により、過去レンジを終値で抜けた動きが継続する。20/55/100日ブレイクの3候補。横ばいの往復・突然の政策反転で崩れる。大きな利益を残すため固定TPを置かず追尾する。
2. 順張り押戻り: 長期方向が一致する市場で短期逆行が解消した後、長期方向への注文が再開する。SMA20から0.5/1/1.5 ATRの乖離回復の3候補。トレンド終了局面、窓開け、継続的逆行で崩れる。
3. レンジ反転: 長期均衡の変化が小さい市場では短期の価格乖離が縮小する。SMA20から1.5/2/2.5 ATRの乖離回復の3候補。新たなトレンド発生、ボラティリティ急拡大で崩れる。

比較は単純SMA200クロス1つ。合計10ルール、採用対象9。通貨ごとの後付け選択、検証後の微調整、失敗後の追加探索はしない。複雑な機械学習やフィルター積層の必要性を示す証拠はないので使わない。

参考: https://www.aqr.com/insights/research/journal-article/time-series-momentum は通貨を含む中期モメンタムの研究。この先物等の研究からFXスポット日足にも持続があり得るという仮説を立てた推論であり、同論文の再現または今回ルールの収益の証拠ではない。

## 共通仕様

15通貨に同一規則を適用。保存された時刻基準の日足、日曜を翌月曜へ統合、休日を補間しない。上位時間足なし。全て確定終値で判断し次の観測日足始値で約定。一通貨一ポジション、exit日には再発注しない。指標は当日終値までを利用し、過去チャネルは当日足を除外する。全候補とも250観測足の共通ウォームアップ。SMAは単純算術平均、ATR20は最初20TR平均からWilder再帰、TR初足はhigh-low。未来ピボット不使用。

初期SLは実エントリー始値から逆方向へ2×シグナル日のATR20。Rはこの初期価格リスク。手数料でSL価格を動かさない。取引日の始値がSLを越えれば始値損切り、TPを越えればTP上限。SL/TP両到達はSL優先。前日終値で予約された指標/期限決済もSL窓開けの後に判定する。日中のSLは終日OHLCで判定する。追尾SLは当日終値で更新し翌日から有効。

トレンド候補: close>直前N日のhigh最大で買い、close<low最小で売り（N=20/55/100）。ロング保有中はentry以後の最高close−3×当日ATR、ショートは最低close＋3×ATRへSLを有利方向だけ更新。closeが直前M日の反対側チャネルを抜けたら翌始値決済（M=10/20/50）。最大120観測足保有した終値で翌始値決済を予約。TPなし。

押戻り候補: close>SMA200かつSMA200>SMA200[20]で買い方向（売りは逆）。前日close<=前日SMA20−kATRかつ当日close>当日SMA20−kATRなら買い（売りは対称、k=0.5/1/1.5）。SL固定2ATR、TPは実エントリーから3R、最大30観測足。

レンジ候補: abs(SMA100−SMA100[20])<0.5ATR。前日close<=SMA20−kATRかつ当日close>SMA20−kATRなら買い（売りは対称、k=1.5/2/2.5）。SL固定2ATR、当日closeが当日SMA20へ到達/通過したら翌始値決済。TP価格注文なし、最大15観測足。

baseline: closeがSMA200を交差した方向へ次始値、初期SL2ATR、トレンドと同じ追尾3ATR、反対SMAクロスで翌始値決済、最大120観測足。選抜対象外。

保有本数はentry足=1。予定決済前の同一足日中にSL/TPへ触れれば先に決済。期間の最終観測足はclose強制清算し、翌期間へ持ち越さない。この境界注文は研究上の精算であり実取引の一般的決済ではない。強制清算を除くPF/損益も診断する。

最大120/30/15本目closeで期限決済を予約し121/31/16本目openで約定。追尾更新後のSLが当日closeを越えていても当日high/lowへ遡及適用せず、翌始値でSL越えを判定する。

## コスト、評価、既閲覧

往復固定1.8pips、metadata spread+往復slippage0.4pipsの二条件。primaryは両方へ保有0.2pip/暦日を加算。保有0/1pip日も感度分析。元OHLCのbid/askは未確認、往復費用を別控除するモデル。SL/TP等の日中出口はその日の保存raw最終時刻+60秒まで、始値出口はraw最初時刻まで、境界closeはraw最終+60秒までのentry時刻差をceilして課金。短期でも日中保有は最低1日となる。これは実ブローカーの通貨別スワップ・三倍日を再現しない。

等初期R加算の研究尺度であり口座通貨収益・複利ではない。日次closeの含み損益（全往復費用およびその日末までの保有費用を含む）を通貨間で日付整列・前方保持してMTM DDを計算。日中DDは不明。

15通貨は共通の構成通貨を持ち相関するため15独立市場の証拠とは扱わない。同familyの事前3設定をパラメータ感度として並記し、選ばれた設定だけの成功を強調しない。学習3区分のexit年帰属損益に加え、各区分末のMTM増分と含みRを示す。

train 2010–2018、validation 2019–2022、final 2023–2026-08-31未満。全期間は他の研究で閲覧済みで真の未使用データではない。今回ルールの設計・選抜はtrainのみ。train両費用基準を満たす中から最悪費用PF最大、最悪平均R最大、最大MTM DD最小、ID順で1候補を凍結。validation不通過で停止し代替候補は見ない。finalも同様。基準はprotocol.jsonに固定。最終合格があっても独立検証前に採用宣言しない。
