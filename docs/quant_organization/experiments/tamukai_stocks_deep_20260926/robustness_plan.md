# 頑健性診断の固定計画

2026-09-26、診断実走前に主担当・独立検証担当で固定。成績に応じた対象・閾値・再標本条件の変更はしない。候補の採用gateへ事後追加しない。

1. 対象は6候補の2017–2019全案、比較no_dowの訓練/2020–2022/2023–2025/2017–2025連続。訓練を通過し既に検証した候補のvalidationも、不合格であっても含める。最終選抜候補が存在すれば、その算出済み期間も含める。後期を未計算の候補は診断のために新しく計算しない。

   対象文言の補足：訓練/validationの成績確認後、頑健性診断の結果閲覧前に、不適格validationも同じ診断に含むことを明確化した。都合の良い期間だけを診断対象に選ばず、計算済みの全候補経路を含める。ブロック長・回数・seed・診断式は変更しない。
2. 月次終値MTMリターンと決済月の純利益正/負の金額を使用。全10銘柄を同期した同じ月indexで抽出。連続3か月moving-block bootstrapと事前感度6か月、各2,000回、seed=20260926。平均月次リターン・純PFの95%percentile区間を保存。定義・percentile法・端点処理は実装にも残す。
3. これは既存経路の条件付き再標本であり、再売買シミュレーションではない。長期依存、全相場分布、将来の利益確率を保証しない。複数候補探索への多重比較補正は未実施であり、有意なedge発見/運用合格と呼ばない。
4. 銘柄集中は黒字銘柄の利益合計に対する最大1銘柄・上位3銘柄の寄与比率とHHI。赤字銘柄を隠さず全10株の利益を併記。
5. Leave-one-stock-outは各1株を外した9独立sleeve/90万円、資金再配分なし。10通りのPF・純損益・最大終値DDと最悪/黒字組数。最良集合を選ばず診断のみ。
6. 費用損益分岐は株ごとに `100000 * product(exit/entry) * ((1-c)/(1+c))**trade_count` を合算。通常/2倍費用の保存最終資金と先に照合する。c=0〜片道1%で単調性確認後に二分探索。0でも赤字なら非負費用での解なし、1%でも黒字なら>1%。約定経路に費用が影響しない本モデル限定の式。税・配当・100株単元は対象外。

探索のしすぎが見かけの好成績を生み得るという注意は [Sullivan, Timmermann, Whiteの研究](https://www.fmg.ac.uk/publications/discussion-papers/data-snooping-technical-trading-rule-performance-and-bootstrap) と [Baileyほかの研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf) を参照した。本診断はこれらのReality Check/CSCVそのものの実装ではなく、探索数制限と不確実性の可視化を目的とする。
