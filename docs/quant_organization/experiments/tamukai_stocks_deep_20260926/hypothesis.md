# 日足押し目の要因別深掘り、6候補限定

前研究訓練2017–2019のno_dowは166件/PF1.074、通常黒字だがstress赤字。Dow維持の早い突破、SMA63整列は赤字。これを踏まえno_dowを共通土台に下記6候補を計算前固定する。これは既閲覧訓練データからの探索であり、独立未使用データの発見ではない。

共通:日足ロング/上位足なし。close>SMA21、SMA21が2日前より上、直前3日のいずれかlow<=その日のSMA21、close>直前3日high最大。信号引け確認、翌観測営業日openで買い、SL=信号前3日low最小、TP=open+(open-SL)、全決済RR1。stop以上の窓寄付・同日決済・SL優先・期末清算・費用/資金は旧simulateと完全共通。

|ID|追加条件|仮説と反証条件|
|---|---|---|
|trend_strength|A=(SMA21[t]-SMA21[t-5])/ATR14[t]>=0.25|横ばいの押しを避ける。転換を遅れて追い損失増なら反証|
|shallow_pullback|B=min j=t-3..t-1 ((low[j]-SMA21[j])/ATR14[j])>=-1|浅い押しは需要維持。深い押しの復帰を除外し期待値低下なら反証|
|strong_rejection|C=(close-low)/(high-low)>=0.75|突破日引けの買い圧力。翌窓・反落で優位なしなら反証。range0は不成立|
|risk_band|D=0.02<=(close[t]-stop)/close[t]<=0.04|狭すぎる値幅の費用負担と広すぎる不安定な押しを避ける。件数減/隣接期間悪化なら反証|
|trend_shallow|AかつB|強度と浅さの限定的な組合せ効果。単体より悪化なら反証|
|trend_risk|AかつD|強度と費用余裕の限定的な組合せ効果。単体より悪化なら反証|

Dの2–4%は責任者の訓練取引事後部分集合診断（実始値risk2–4%53件/PF1.531、4%以上97件/PF0.988、2%未満16件赤字）を見て定義した探索仮説である。新戦略成績として扱わない。実装条件は未来の始値でなく信号終値幅。翌窓により実際のrisk幅は異なりうる。ATRは既存Wilder14。SMA21の5日前値が必要なAは26本目以降、他は直前3日の有効SMA21が揃う24本目以降。ATR正値必須。各閾値は1つ、総当り/感度探索なし。

訓練2017–2019:通常50件以上/PF>=1.1/純益>0/引けMTM DD<=20%かつstress純益>0。全適格のみ2020–2022検証:通常100件以上/PF>=1.1/純益>0/DD<=20%かつstress純益>0。通過中の通常PF最大、同率は追加条件数少→ID昇順で最大1選抜を保存後、2023–2025最終評価。同100件/PF1.1/黒字/DD20/stress黒字と通常黒字6/10銘柄を要求する。全滅なら採用なし、打切り理由を記録。訓練/検証/選抜/最終は順にJSON保存し、各期間末で入力を切ってから信号計算。

別枠事前reference=no_dowは選抜に関係なく、候補選抜を保存した後だけ2020–2022/2023–2025/2017–2025連続を記述追跡する。baseline/buyholdも同期間対照。referenceは採用候補に昇格しない。全期間既閲覧、全データ限界（Yahoo後方調整/Sony spin-off/2修復/生存選択/配当非再投資）を継承。10/9/7銘柄品質集約も旧定義、後者をclean扱いしない。

資金は各銘柄10万円独立、通常片道0.1%/stress0.2%、端株研究モデル。DDは初期残高込み引けMTM。年別純益はMTM差、PF/勝率は決済年別である。売買AI/API/再DL/Pineなし。開発者は採用承認をしない。
