# YTT突破候補の収益性と目標実現性

2026-10-09。研究責任者: 主エージェント。

ユーザー指定は運用資金1,000,000円、月間利益3,000,000円、損失100,000円で停止。税引前/手取りは未確定のため、研究では費用後・税引前を扱う。月間利益目標は元金の300%であり、目標値を実績や期待値と扱わない。

## 必要性と工程

現在のYTTは価格候補を表示するindicatorで、注文・出口・実績計算を持たない。表示改善では利益発生の証拠にならない。既存の表示を変更する前に、出口と約定条件を固定したPython検証が必要。

1. データ担当が保存済みUSDJPY/EURUSD/GBPUSDの入力と品質を確認。
2. 研究担当が現在のH1/H4一致・M15確定ピボット突破を1戦略に固定し、上位足フィルターなしの1比較と評価。protocol凍結後のみ実走。
3. 独立検証担当が信号時刻、費用、明細集計、円試算を照合。
4. 品質監査担当が証拠と引渡し可否を確認。後期成績不適格なら不採用で終了。
5. 適格かつ追加の未使用データで確認できた場合だけPine移植へ進む。研究データは既閲覧であり、今回の良好な成績だけで実運用採用にはしない。

担当所有: data_inventory.md=データ担当、hypothesis.md/protocol.json/新研究runner/新tests/研究成果物=研究担当、validation.md/独立成果物=検証担当、audit.md=監査担当、plan.md/report.md/board.md=主担当。共有ファイルを同時編集しない。既存Pineの表示・既存不採用結果を保存する。

## 資金と停止条件

10万円停止は元金からの口座純資産損失として解釈し、残高だけでなく含み損を含め90万円以下で停止する。高値からの最大ドローダウンは別の尺度として報告する。停止後の再開・追加入金・倍掛けは仮定しない。ギャップ、費用、約定遅延により停止時損失が10万円を超える可能性を明示する。

研究用1取引リスク0.5%は検証の仮定であり、実口座への推奨や実注文の許可ではない。異なる通貨のpipsやRの合算を円利益と呼ばない。円試算をUSDJPY単独で行う場合は、3通貨合算口座の実績と区別する。

## 外部根拠と限界

[金融庁のFX説明](https://www.fsa.go.jp/ordinary/iwagai/)は、個人店頭FXの証拠金率4%以上（レバレッジ25倍以下）と、証拠金を超える損失の可能性を示す。研究の25倍上限は国内個人店頭FXを仮定したモデル。利用業者・価格Bid/Ask・時刻基準・スワップ・実スリッページ・税額は未確定であり、実運用利益保証に使用しない。

実注文、口座接続、有料API、外部公開、常時監視、Git公開は開始しない。
