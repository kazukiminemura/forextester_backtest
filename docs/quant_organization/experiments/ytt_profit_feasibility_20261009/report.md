# 月300万円目標とYTT突破候補の収益性

## ユーザー条件

元金100万円、月利益300万円、元金から損失10万円で停止。研究は税引前の目標と仮定する。月利益300万円は元金の300%で、月末資産400万円に相当する。翌月に利益を引き出すか複利で運用するかは未指定。

1取引0.5%リスク・RR1で毎回全勝・費用ゼロ・数量制限なしという仮想上限でも、資産を4倍にするには `ceil(log(4) / log(1.005)) = 278` 回の利確が必要。固定5,000円の利益なら600回分の純利益が必要。この計算は戦略成績・達成確率・推奨リスクではない。実試算は数量刻み・25倍上限・費用・損失を反映する。

国内個人店頭FXには証拠金率4%以上の規定があり、相場急変時には証拠金を超える損失もあり得る。[金融庁の説明](https://www.fsa.go.jp/ordinary/iwagai/)。10万円停止はその額で必ず約定する保証にはならない。

## 固定した検証

現在のYTT分析補助のH1/H4方向一致＋M15確定ピボット突破を、次足始値エントリー、反対側既知ピボットの1tick外側SL、1R全利確、source日付日内強制清算のルールで評価。上位足条件なしを固定比較とする。候補2件、費用通常/2倍、3通貨、2020–2025の既閲覧データ。結果を見て条件を追加しない。

3通貨の等R集計は研究指標。円口座試算はUSDJPY単独で、初期100万円、費用込み予定SLリスク0.5%、数量1,000通貨刻み、25倍上限、含み損込み90万円停止。連続2020–2025口座を主評価とし、期間ごとの独立口座は参考。停止後の追加入金・再開を仮定しない。

PFは各取引の費用後Rを用いた研究統計であり、円換算ポートフォリオPFではない。後期の各期間で3通貨とも赤字、費用2倍でも赤字、上位足なし比較より平均Rが低く、取引数以外の事前基準は全不通過。

USDJPY継続口座の通常費用試算は74取引後、source時計2020-02-14 18:30に資産90万円へ達し停止。元金損失は10万円。終値基準の最大ドローダウンは101,566円で、ピークからの低下と元金損失は異なる。月300万円達成は対象72か月中0か月、停止後は再開していない。期間ごとの新規100万円参考口座でも各期間に90万円停止が発生した。これらは実口座の実績ではない。

最初の試算は不完全M5の始値時刻をbucket開始と扱う不備があり、`first_run_before_m1_open_fix/` に無効として保存。原M1の実始値時刻へ修正し、固定条件を変えず再走した上記の数値だけを主結果に使う。

主担当は `python -m pytest tests/test_ytt_profit_feasibility.py tests/test_yosuga_ytt_assistant.py -q` を実行し、週足対応後の最新状態で24件成功（終了コード0）。14件は本研究の実行挙動、10件はPineのソース構造チェックでありTradingView売買実績や実機検証とは異なる。独立検証と監査の最終所見は各担当文書を参照する。本研究の条件はH1/H4で凍結しており、後続のD/W候補表示へこの損益を流用しない。
