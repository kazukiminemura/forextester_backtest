# YTT＋BB3σ反転の表示統合

ユーザー依頼: BB3σ反転を統合する。

既存 `bb3_reversal_confirmation_indicator.pine` のBBタッチ→反転確認→次足以降の厳密な突破、取消優先・中央線幅・仮想RR1集計を利用し、YTT統合版へ合成する。新規利益戦略の選抜やYTTとの売買条件ANDは行わない。

1. Pine担当: generatorと生成Pineのみ。元3インジケーターは保持。
2. 主担当: 合成テスト・導入説明・TradingView実コンパイル/表示/一覧切替。
3. BBの描画は主価格チャート、一覧は同じ8通貨を共有してYTT/BBの表示選択にする。BB仮想成績はYTTパネルと重ならない位置にする。
4. 旧5分限定は設定ONで復帰でき、統合既定では表示時間足で判定する。15分での収益検証をした意味ではない。
5. 確定値参照・状態順序・価格刻み・RR1計算を維持し、request上限とtable競合を実機で確認する。実注文/外部公開/アラート作成なし。
