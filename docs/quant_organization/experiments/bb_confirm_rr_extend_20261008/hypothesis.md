# BB confirmation: fixed center-distance risk, extended target

The current FX BB confirmation rule's RR1 virtual ledger uses the signal-close center as a fixed TP and a mirrored SL; the broader original indicator description also distinguishes this from actual broker execution. This experiment changes only the exit contract: at the actual next available M5 open, freeze the absolute distance to the tick-rounded signal-close SMA20 as risk R, put a fixed stop that distance away (rounded outward to one native tick), and place a fixed TP at gross RR 1.0, 1.25, or 1.5. The center is no longer a TP after entry. This is not an edit to or exact reproduction of the current Pine RR1 ledger.

Hypothesis: If the signal's center-distance stop identifies a meaningful local risk unit, extending reward while holding that stop fixed may raise average net R. It is falsified if the lower hit rate yields lower average net R/PF_R than RR1, if stressed net-plus-open R is nonpositive, or if effects do not repeat in the predeclared validation period and across pairs.

The comparison is one finite three-arm descriptive experiment on saved Forex Tester M5 features from nine FX pairs, both directions. Signal generation uses the current BB3 preparation, directional confirmation, strict later breakout and existing cancellations/exclusions. Entry semantics remain the current research timing runner's next available M5 open (including gaps) and its >=3-pip candidate-reference room test. One position per symbol; while occupied, later candidates are ignored. The entry-center risk can be below three pips because the existing 3-pip check is measured from the candidate reference, not from the next open; this distinction is retained and reported. No new entry filter, parameter search or symbol-specific selection is permitted.

For each trade, compute R_ticks=max(1,ceil(abs(entry-signal_center)/tick)); fixed SL is entry-side*R_ticks*tick. TP is entry+side*ceil(RR*R_ticks)*tick. Brackets activate on the entry candle; opening gaps use actual open, and intrabar dual touches resolve stop-first. Full exits only. Deduct fixed round-trip 1.0 and 1.2 pip hypothetical costs once per closed/open position. No swap, variable spread, extra slippage, account sizing or currency conversion is modeled. Period books start flat, with feature warmup available before period start; no forced close, but open marks are reported.

All periods have been previously viewed in BB studies; none is a true holdout. The 2023-09-08 to 2024-09-08 period is a descriptive development segment, 2024-09-08 to 2025-09-08 is a locked descriptive comparison, and 2025-09-08 to 2026-09-08 plus the continuous period are report-only. No candidate selection or later fallback. This experiment cannot approve Pine changes or live trading. Existing Pine, runners, protocols, results and original history remain unchanged.
