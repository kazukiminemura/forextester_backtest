# J LawのVCPを日経平均採用銘柄に拡大

固定したVCP条件を日本大型株10銘柄から日経平均採用銘柄へ広げる。上昇中の値幅と出来高の縮小が、出来高を伴う高値突破後の買いの平均Rを改善するかを、同じ高値突破・初期ストップ・3R全決済の条件と比較する。

1. 元の大型株10銘柄研究と同じ日足のトレンド、52週高値近辺、10日高値突破、出来高、翌営業日始値、8%の損切り上限を使う。
2. 押し幅と平均出来高が20日・10日・10日の窓で順に縮む条件を加える。最初の押し幅は厳格版20〜35%、緩和版10〜35%で固定する。
3. 2017〜19年、2020〜22年、2023〜25年の各期と9年連続で集計する。通常・費用ストレスでの成績を出し、取引された銘柄の広がり、利益集中、1銘柄除外の影響を調べる。

現行の公式採用銘柄リストを過去に適用するため、当時の指数構成による検定ではない。途中上場には252本の履歴を要求し、上場前を補完しない。画像の押し目買い、財務、地合い、業種、追加購入、移動平均手仕舞いは価格・出来高による今回の対象外。ロジックは元の10銘柄研究で既に評価済みであり、今回の銘柄拡張は時系列上の新しい未使用データを作らない。
