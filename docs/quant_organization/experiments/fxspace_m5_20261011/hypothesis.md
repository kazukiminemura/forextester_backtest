# M5シナリオによる頻度拡張近似

2026-10-11。SPEC_FROZEN。公式FX SPACE手法の限定的な数値近似。ユーザーはM5での取引と取引数の増加を指定した。旧`fxspace_proxy_20261011`は結果・条件・ファイルを保持する。

## 仮説

前回はM5で約定していたが、M15シナリオとH1合意に制限されていた。シナリオ生成と構造SLをM5へ移せば、短期の新しい転換と初回押し戻りを拾い、取引数を増やせる可能性がある。ただし費用が損切り幅に対して大きくなるため、頻度だけで合格にしない。

M15方向一致あり/なしの2設定を固定し、各最低許容RR1.5/2の4主候補。対応対照も各設定・RRに1つの計4。対照は同じ新M5シナリオのTP/SLを使った転換直後の次足Entry。前回のM15シナリオdirectは対応対照ではない。最終選抜は主候補から最大1件。

## 公開説明との関係と非再現項目

公開講座の「成立後に押し戻りで有利位置を待つ」「構造SLと次ラインTPを事前に決める」を研究仮説へ使う。今回のM5シナリオ、H1除外、2本の逆色足、pivot2/2、余白などはユーザーの頻度要望に応じた研究者の固定仮定。原典の全裁量・チャネル・転換前型・72局面・分割Entryを再現したと表示しない。出典は`../fxspace_source_20261011/source_rules.md`と`gap_audit.md`、前回仕様の公式シナリオ講座時刻を継承。

## 指標と固定価格

データは旧監査済み3通貨M5 NPZをそのまま読取再利用。各足利用可能時刻は終端。M15は完全連続M5を3本だけ集約。H1は計算しない。

高安、M5方向、M15方向、ATR、ライン失効、cluster、丸めは前回`research_fxspace_proxy_20261011.py`の凍結済み `Frame` / `aggregate` / `nearest_obstacle` / `round_level` を再利用する。具体的には以下を固定する。

1. 左右2本の厳密pivot、同値極値は不成立、右2本終端から利用。新pivotを追加して最新水準へ終値を比較しM5方向を更新（前終値のcross条件は不要）。高安両突破は0、どちらでもなければ前状態を保持。M15は最新2高値と2安値の双方上昇/下降、その他0。
2. 完全連続21本から20TrueRange単純平均。欠損で足列/ATRをリセット、既知pivotとM15方向を保持、M5方向は0。ATR準備前のpivotは方向判断だけに利用する。
3. ラインはM5/M15の既知pivot、8暦日超・対応足終値による帯幅超の逆抜けで失効、64本/方向/時間足まで。帯幅は作成時ATR×0.10と1tickの大きい方。M5強度1/M15強度2は同時刻tieと記録のみに使い、近い線を飛ばさない。
4. ターゲット選択時のcluster幅はM5 ATR×0.10。進行先にある線を価格昇順で隣接差以内なら推移結合し、確認時刻が最新→強度大→低価格の代表を選ぶ。最も近い代表がTPの障害。初期SL/TP余白=max(1tick,M5 ATR×0.10)。SLは最新M5逆pivotの外、TPは障害の手前へtick単位で保守的丸め。

## M5シナリオと状態順序

各設定は独立した1シナリオと使用済みsupport ID集合を持つ。方向dのM5終値反転（前状態−d→今状態d）だけで新規シナリオを作る。欠損後0→dや同方向の再突破は新規転換にしない。必要な最新逆pivotがあり、M5 ATR準備済み、終値がSL/TPの内側であること。M15一致設定は、その時点で確定済みM15方向もdであること。M5単独設定はM15方向を問わないがM15障害ラインは使う。

成立終値でSL/TP/帯幅/support時刻/突破閾値を固定。各support確認時刻×方向は各設定で期間内1回だけ。対照directだけはこの成立をsignalとし、次の連続M5実始値で判定する。主pullbackは成立足の色を数えず、次の足以降に連続2本以上の逆色足を待つ。その後の初回方向足が前足の高値（買い）/安値（売り）を終値で越えた場合だけsignal。次の連続M5実始値で入る。2本揃う前の方向足や同値足はrunを0へ戻す。2本以上の後の初回方向足が極値を越えなければシナリオ終了。

成立から12本ちょうどまで有効。13本目で失効。別足のSL/TP接触、M5逆方向転換、欠損/不完全M5、M15一致設定でM15方向不一致になったら取消。M5単独設定はM15不一致で取消しない。既存シナリオを処理した足では、取消しになっても同足に新シナリオを作らない。価格到達取消を復帰signalより先に判定する。次の場面は新support IDと新しい方向反転が必要で、同じ場面の連続再Entryをしない。

## 期間・ゲート・停止
