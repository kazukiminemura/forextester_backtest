# 指定動画のバリ式検証計画

対象一次資料：https://www.youtube.com/watch?v=jbl2DALIEWw 。2026-10-16開始。

1. 指定動画のタイトル・投稿者・説明・字幕または画面から、手法と各ルールの根拠時刻を確認。見つからない条件を一般論で埋めて公式手法と呼ばない。
2. データ担当が保存済み履歴の対応銘柄・時間足・期間・時計・品質を確定。原データは上書きせず、既存キャッシュの再利用を優先する。
3. 再現可能な最小条件・裁量の近似・比較対象・候補数・コスト・約定と終了条件を、結果を見る前にprotocolとして凍結。入力と実装のSHA、凍結時刻を保存。
4. 確定足だけで信号を作り、信号後の実際の始値、SL優先の同足判定、欠損・ギャップ、通常と増加費用を扱う。複数期間・複数通貨を評価し、既閲覧データを未使用holdoutと呼ばない。
5. 別担当がルール・未来参照・会計・結果を独立確認。採用できない結果も保存する。未確認の仕様・入力で数値のバックテストを開始しない。

資金100万円・損失10万円で停止という既存条件を円口座診断に引き継ぐ。異なる通貨のpipsやRを円損益として合算しない。動画に資金・決済条件が明記されていれば、動画仕様とユーザー条件を分けて報告する。

一次資料はsource担当がYouTube字幕と本人Canva資料を照合して確認済み（source.md）。元動画は23:20、2025-02-10公開。EMA方式の機械近似を今回の範囲とし、三角持合い方式は別方式として未検証にする。

主検証はH1方向一致・M15/M5の順次転換・M5 EMA25の順逆順クロス。クロスは終値確定・別々の足とする保守近似。H4は参考で、一致を必須にしない。損切りは確定M15反対側ピボットの1tick外を代理とし、動画の裁量ライン全体を再現したと呼ばない。RR1を主とし、RR1.5/2を固定参考診断、EMAを待たない転換直後を対照にする。

独立資料照合による凍結前修正：動画15:31–15:37の実例に合わせ、M5転換と最初の順crossは同じ足で可、残る2crossは別足とする。転換時に既に順側という位置だけではcrossを代用しない。Entry足が後に完全だったかを始値判定に使わない。不完全足のOHLCで事前SL/TPを判定し、未到達なら判明後の次実観測始値で清算する。末端に次の価格がなければopen markとして別記し、約定決済・勝率の母数には数えない。

2020–2022/2023–2024/2025の全3区分を事前固定して記述評価し、学習で良かったRRだけを後選抜しない。全期間が既閲覧であり、原法の成績や未使用データでの実運用適性を実証するものではない。通常費用と2倍を全ケース報告する。口座の円表示はUSDJPYの連続診断だけに限定する。
