# ユーザー提示BB逆張りルールの検証

USDJPY、5分足、BB20±3σ、中央線への回帰を検証する。2023-09-08〜2026-09-07、主担当のみ。
作者やWEMOFの公式仕様は確認していない。ここでは提示文を明示的な仮定で数値化したモデルとする。
最新依頼は中央線利確であり、以前の固定RR・円クロス限定・4時間足フィルターを引き継がない。

BBは終値20本のSMAと母標準偏差。5分足確定後に高安の±3σタッチを判定し、次の隣接5分足始値で逆張り。
両バンド接触足は見送り。1建玉、ナンピンなし。エントリー時点で費用を考慮した中央線が不利な側なら見送り。
中央線は各足の直前に確定したSMAへ更新する。進行中の足の終値でターゲットを先読みしない。
基準ケースは損切り未指定のためなし。補助ケースの5/10pips損切りは本来の手法と主張しない。
固定スプレッド・片道0.1pip滑り。売り決済はask、BB中央線タッチはbidチャートで判定する。
窓開けは実際の始値で決済。SL/中央線同時タッチはSL優先。期間末の建玉も強制決済して損失を除外しない。
年別はエントリー群。PF・勝率・平均勝敗・最悪損失・保有時間・決済DD・終値時価DD・最大逆行幅を示す。
逆行幅は出口足全体の高安を含む保守的上限であり、実際の約定までの正確なMAEではない。時価DDも5分終値ベースでティック最大値ではない。
スワップ・変動スプレッド・証拠金強制決済は未モデル化。利益を確実と仮定しない。結果によるパラメータ調整は行わない。
