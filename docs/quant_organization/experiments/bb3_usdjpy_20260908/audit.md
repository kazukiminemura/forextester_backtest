# 提示BB逆張りモデルの単独担当照合

正式実走v2はexit0、DESCRIPTIVE_COMPLETE。初回は集計値JSON保存の型エラーで失敗、旧フォルダを保存して再実行。
5テスト通過。14,435明細の価格経路上の参照点と別式集計をscripts/verify_bb3_mean_reversion.pyで確認した。
母標準偏差を用いたシグナル、直前確定SMA中央線、次5分足エントリー、売りaskと費用、期間境界、非重複、PF・勝率・年別損益・決済DDを照合。
時価DD・高安MAE上限は独立リプレイ未実施。元履歴実行前後属性と凍結コード指紋一致。
主担当のみであり独立した担当者による監査ではない。

3ケースともPF1未満で不採用。中央線決済が利益とは限らず、損切りなしの高勝率だけを評価しない。
公式手法のエントリー時機・損切り・除外条件は提示されていない。今回のモデルと原手法の優位性判断を混同しない。
