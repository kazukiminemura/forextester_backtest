# エントリータイミング改善の引渡し条件

依頼対象: `scripts/tradingview/bb3_context_pf_indicator.pine`。確定損益がプラスになるよう、エントリータイミングを改善する。追加指示によりUSDストレートも対象とする。

## 対象と変更境界

- USDJPY、EURUSD、GBPUSD、AUDUSD、NZDUSD、USDCHF、USDCAD、EURJPY、GBPJPYの5分足。ローカル履歴の終端は全て2026-09-07 23:59（2026-09-09読取確認）。
- 主比較期間は2023-09-08から2026-09-08未満。全期間は過去の研究で閲覧済みであり、真の未使用期間ではない。
- 現在のBB準備、長ヒゲ除外、突破の勢い除外を保持し、確定情報によるエントリー条件のみを比較する。既定の損切りなし・中央線全決済を今回勝手に別戦略へ変えない。
- コスト控除の削除、損失取引の集計除外、現在足の未来情報での過去約定、都合のよい銘柄・期間だけの提示は改善と認めない。
- 複数ペアのpips集計は等pip重みの研究スコアであり、口座通貨換算したポートフォリオ損益ではない。各ペアの成績を併記する。

## 完了を立証する証拠

1. 現Pineの基準ロジックを再現した結果、設定・データの識別子、実行終了を保存する。
2. 事前凍結した有限候補を比較し、選抜期間と判定期間を分ける。採用条件の詳細は同フォルダーのprotocol.jsonで結果閲覧前に固定する。
3. 確定損益に加え、最後の含み損益、末尾清算評価、件数、年別・通貨別成績、コスト感度を示す。損失を保有したまま確定損益だけを正にするものを採用しない。
4. 独立検証者がシミュレーターのPine対応、明細からの損益再集計、時間順序、選抜手順を確認する。
5. 採用できた条件だけを依頼されたPineへ反映し、対応テストと仕様説明を更新する。不採用なら既存Pineの設定を根拠なく変更しない。
6. TradingView上のコンパイル・表示・対象期間の成績を確認する。ローカル参照テストのみならTV_UNVERIFIEDとし、ユーザーのチャートでプラスになったとは主張しない。

現時点では検証開始段階。将来利益や全銘柄・全期間の利益を保証するものではない。今回の依頼はgit公開や実注文を含まない。
