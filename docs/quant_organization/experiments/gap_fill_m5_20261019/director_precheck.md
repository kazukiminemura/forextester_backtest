# 指揮官スモークチェック（凍結前・判断には使わない）

実施: 2026-10-19、責任者（主エージェント）。対象は **USDJPY の 2026-01-01〜2026-09-07 のみ**（1通貨・8か月）。
これは Stage A の測定ではなく、**凍結前の実現可能性確認**である。以下の理由により、この数値を
採用判定・ゲート判定・基準変更に使わない。

- 1通貨・8か月の部分集合であり、事前固定した3期間・11通貨の母集団ではない。
- Stage A/B の結果を置き換えない。観測後にゲートや閾値を変更しない。
- 実行主体も表現も研究担当の実装（`scripts/research_gap_fill_m5.py`）とは別の即席コードであり、
  成果物ではない。独立検証の対象でもない。

## 目的

事前固定した Stage A の母集団ゲート（X=10.0pipsで全11通貨合計300件以上）が、
そもそも到達可能かを凍結前に確認する。到達不能なら、実行前に設計を見直す必要がある。

## 実測結果

| 項目 | 値 |
|---|---|
| M1バー数 / M5バー数 | 249,757 / 50,168 |
| 時刻差≥120分のギャップ | 39件（約5件/月） |
| ギャップ幅 pips | min 1.6 / p25 6.7 / 中央値 12.2 / p75 24.5 / max 99.9 |
| X≥10.0pips | 22件、全埋め先行 9、ストップ先行 6、48本未解決 7（全埋め先行率 0.409） |
| X≥25.0pips | 9件、全埋め先行 2、ストップ先行 1、48本未解決 6（全埋め先行率 0.222） |

（規則は protocol.json と同一: フェード方向、ターゲット=直前終値、ストップ=始値から逆行方向へギャップ幅、
最大48本、同一バー両到達はストップ先行。）

## この観測から言えること／言えないこと

- 言える: 対象11通貨のうち1通貨・8か月で X≥10pips が22件あり、母集団300件というゲートは
  桁が合わない水準ではない（到達可能性は高い）。ギャップ幅の中央値は往復費用1.2pipsに対して十分大きい。
- 言える: この部分集合では、全埋め先行率 0.409 は PF1.15 に必要な 0.594（X=10pips、費用1倍）を
  大きく下回る。SL=ギャップ全幅という構造が厳しい可能性がある。
- 言えない: 11通貨17年での比率。通貨・期間で構造が変わる可能性。48本未解決（7/22）は
  Stage Bでは期間末決済になり、部分的な含み損益を持つため、この比率だけで最終損益は決まらない。
- 言えない: 本観測をもって不採用とすること。不採用判定は Stage A/B の事前ゲートで行う。

## 凍結への影響

母集団ゲートは維持する（変更不要）。Stage A は予定どおり実行する。
もし Stage A が「全埋め先行率」で落ちた場合、その事実と、部分埋め率・未解決率の分布を
不採用理由として保存する。出口契約を変えた再試行（例: 部分埋めをターゲットにする）は
**新しい実験ID**で、結果を見る前に基準を固定して行う。本実験の基準は変更しない。
