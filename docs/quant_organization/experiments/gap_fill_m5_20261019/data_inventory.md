## 2. M5集約の手順と検証

- **集約規則（本台帳と `src/forextester_backtest/data.py::_aggregate_bars` で同一）**: M1の時刻を OLE基準秒に直し `bucket = floor(秒 / 300)`。バケット開始時刻＝`1899-12-30 00:00` + bucket×300秒。Open=バケット先頭M1の始値、High=max、Low=min、Close=バケット末尾M1の終値、Volume=合計。**新しい足種は作らず、保存M1のみから決定的に生成**。
- **M1が5本未満の部分足**: 破棄も補間もしない。持っているM1だけで集約し、そのままM5バーとして返す（`data.py` と同じ）。11通貨の部分足（n_m1=1〜4）は 0.65%（GBPCHF）〜6.42%（CHFJPY）、実数は `data_ledger_tables.md`「M5 buckets and partial buckets」。ギャップバー自身が部分足である件数は合計 4,532件。
- **欠損バケット**: 補間しない。M5時刻列に穴が残り、その穴が本実験のギャップ検出対象になる。M1の1分欠損（`t[i]-t[i-1] > 60秒`）は通貨別に 12,955〜144,994件あり、5分区間内の欠損として部分足に現れる。M5の時刻差 30〜119分の段（日次メンテ等）は通貨別 31〜1,044件。
- **`data.py` の他挙動（実測確認）**: `bars(start,end,timeframe)` は M1 を `start` 以上・`end` **包含**で読んでから集約する（`end` と同時刻のバーが1本返ることを実測）。OLE日時はタイムゾーンなし naive datetime に変換され、UTC/JST/ブローカー時刻の識別は無い。価格はファイル内 Open, Close, High, Low 順。
- **等価性検証（サンプル窓、全件ではない）**: 2024-01-01 00:00〜2024-03-31 23:59 の3通貨で、本スクリプトの集約結果と `HistoryRepository.bars(sym, start, end, "5m")` を要素比較。USDJPY 18,467本 / EURUSD 18,468本 / GBPJPY 18,333本で**時刻不一致0・価格不一致0・出来高不一致0・本数差0**、部分足も 148/148・297/297・6/6 が一致。11通貨・全期間での要素比較は未実施（同一コード経路だが未確認）。
- 再現: `python -B scripts/data_gap_fill_m5_ledger.py --symbols USDJPY EURUSD GBPJPY --limit 400000`（スモーク）／本番は引数なし。

## 6. 制約・未確認事項

1. **時刻基準が不明**。保存時刻は naive で、UTC/JST/ブローカー時刻のいずれかを本台帳は断定しない。日曜始値が21時/22時に分かれる米国DST様の分布は「UTC相当＋NY17時オープン」と整合するが、USDCHF/CHFJPY/GBPJPY で2020-2024に1〜2時間の規約変化が見えるため、全期間を単一のタイムゾーンとして扱えない。**根拠なくUTC扱いしない。** 日次メンテ穴も EURUSD の 2003-2007 に16時台で1,012日分あり、通貨・年代で異なる。
2. **真の未使用期間は存在しない**。これらの M1/M5 は 2010-2018 を学習側、2020-2026-07 を複数研究で既閲覧。`final_confirmation`（2022-01-01以降）を未使用 holdout と呼ばない。本台帳のギャップ母集団の記述自体は損益を見ないが、期間の既閲覧性は解消しない。
3. **未使用期間の区別は不能**。「既に閲覧された期間」と「真に未使用の期間」を分離する記録は組織内に無く、不明なものは未使用と保証しない。
4. **tick 未検証**。tick は件数・端点のみ。Bars.dat と tick の整合、tick 由来のスプレッド変動・約定順序は未確認。M1とtickの開始年が違う通貨（USDCHF/CHFJPY/GBPJPY等はM1 2001年〜、tick 2003年〜）があるため期間を同一視しない。
5. **費用はメタデータ固定値のみ**。時間変動スプレッド・実スリッページ・スワップは未モデル化（Swap は設定上0.0000、実勢の根拠ではない）。commission_per_lot=0 も実費用0の証明ではない。
6. **出来高は使用不可**（負値41件・ゼロ20件）。**負出来高の「2009-10-01以降 in-scope 件数」を分けて数える監査キーが本スクリプトに無い**（記録は全ファイル通算のみ）。当戦略は出来高を使わないため対策不要だが未確認として残す。
7. `NZDJPY` は保存が 2018-04 の1か月のみ（旧台帳記載。今回は再読取していない）で長期間比較に使えない。`CADJPY` は `HistoryRepository.symbols()`（30銘柄）に**存在しない**。この除外はデータ側の制約。
8. 幅の閾値 10.0/25.0pips ちょうどには浮動小数点の境界事例が 86件 / 15件ある（3章）。どちらの丸めを採るか研究実装で固定すること。
