### 3.1 判定を動かし得る論点（すべて併記し、適用は凍結文言の最も素直な読み）

1. **同一足両到達の扱い**: 凍結どおりストップ優先で数えた（ambiguous は X10 で5件、X25 で0件）。仮にこの5件を全埋め先行に数えても pooled 0.5143 / training 0.4411 / validation 0.5043 で、依然として不足する。判定は tie-break に依存しない。
2. **「比率」の分母が凍結文言に明記されていない**（分子＝「ストップより先に全埋めへ到達」は定義済み）。適用したのは母集団全体を分母とする読み（研究実装と同一）で、未決着も分母に入る。参考として他2 readings を機械計算した（`gate_evaluation.json` の `fill_first_denominator_sensitivity`）:

| 対象 | 適用（全事象が分母） | 決着済みのみが分母 | 未決着を全埋め扱い |
|---|---:|---:|---:|
| pooled X10 | **0.5132（不合格）** | 0.7473 | 0.8265 |
| training X10 | **0.4397（不合格）** | 0.6711 | 0.7845 |
| validation X10 | **0.5024（不合格）** | 0.7579 | 0.8395 |
| pooled X25 | **0.2935（不合格）** | 0.7163 | 0.8838 |

   決着済みのみを分母にすると合格する。したがって**このゲートの成否は分母の解釈に依存する**。ただし (a) 凍結文言は分母を限定しておらず、母集団に対する比率という素直な読みは全事象分母である、(b) 結果を見た後に有利な分母を選ぶのは規約違反（charter「結果を見た条件変更」禁止）である、(c) 決着済み分母は Stage B の勝率とも一致しない（未決着は `period_end` で部分損益として決済される）ため、いずれにせよ収益性の証明にはならない。**本検証は全事象分母で不合格と判定し、分母の定義漏れを仕様欠陥として記録する（§7-1）。**
3. **通貨一貫性の「全埋め先行率」がどの期間か明記されていない**。適用は通貨ごとに全期間を pooled した1つの比率（11通貨＝11比率という素直な読み）で 2/11。代替 readings は training のみ 0/11、validation のみ 4/11、final のみ 8/11、3期間すべて 0/11（`gate_evaluation.json` の `alternative_readings`）。final のみを選べば通るが、それは期間を事後選択する行為であり凍結仕様に無い。**適用値 2/11 で不合格**、文言の曖昧さを仕様欠陥として記録する。
4. **`stage_a_vs_baseline` は情報量がほぼ無い**。継続アームは同一事象・同一価格水準の鏡像なので `fade.stop_first = continuation.target_first + ambiguous`（実測: X10 pooled 771 = 766 + 5 / X25 181 = 181 + 0）。つまりこのゲートは「全埋め先行率 > ストップ先行率」とほぼ同義であり、`stage_a_fill_first` を通過しない母集団で単独合格しても追加の証拠にならない（研究側 hypothesis.md §3 も同じ注意を書いている）。合格ではあるが、採用判断の材料として水増ししない。

### 4.1 証拠の同一性（code identifier）— 重大な記録不備と、その解消

- `stage_a/`（v1）の `run_manifest.json` が記録するコードSHAは `scripts/research_gap_fill_m5.py = 18be1e49…` / `tests/test_gap_fill_m5.py = 50cb3f92…` だが、**ディスク上の現ファイルは `289c0081…` / `377c5abe…` で一致しない**（検証実測）。ファイル更新時刻は研究コード 2026-10-19 09:39:44、テスト 09:36:16 で、いずれも v1 出力の生成時刻 09:34:37 より後。つまり **v1 の証拠は現行コードからは再生成できない**。
- `stage_a_v2/` の manifest はコードSHA `289c0081…` / `377c5abe…` を記録し、**現ファイルと一致する（3ファイルすべて match）**。
- 研究側の統合報告 `docs/gap_fill_m5_20261019.md` §10.3 は「初回実装の対照バー対応に構造的欠陥があり、±60分帯へ修正して v2 を再実行した。フェード／継続／母集団の数値は v1 と完全一致する」と主張している。**この主張は検証側で機械確認した**: v1 と v2 の全リーフ差分は 1,591経路で、**すべて `control.*` 配下。`control` 以外の差分は 0**、入力指紋（`input_sha256`）も完全一致、ゲート判定ブロックも一致（`research_target_consistency.json`）。
- したがって、数値の独立再現は v1・v2 の両方で成立し、**証拠とコードの対応は v2 によって満たされる**。ただし v1 ディレクトリを「現在のコードで再現できる証拠」として引用してはならない。凍結仕様の `code_identifier` は実験ID単位でコードを指しており、v1/v2 のどちらが正規の証拠かの記録が台帳側に無い点は不備である（§7-5）。
