# 独立検証

現行Pineのスイープ後上抜け買い・下抜け売りを、別実装で2015年から連続再生した。2017〜2025年エントリーの全30,854取引が研究実装と一致した。M15は28,853件・往復1pip後の勝率44.48%・PF_R 0.426、H4は2,001件・48.78%・0.800だった。記述的な成績を再現確認した。両時間足の合計期待値は費用前後とも負だった。

## 入力と照合

対象は凍結済み `protocol.json`、`scripts/tradingview/sweep_breakdown_levels_m15.pine`、ローカルForex Tester M1のUSDJPY・EURUSD・GBPUSD・AUDUSD・USDCHF。独立実装は `scripts/validate_sweep_breakout_m15_h4.py`。研究側の読取・集約・ピボット・シグナル・決済関数を呼ばず、Bars.datの読取からM1約定まで別に実装した。

入力スライスSHA256は5通貨すべて一致した。取引識別子は通貨、時間足、方向、エントリー時刻。全30,854件で欠落0、余剰0、重複0。phase、決済理由、スイープ時刻、シグナル時刻、シグナル足の最終実在M1、決済時刻、Entry・SL・TP・trigger・Exit、費用前後Rを照合し、不一致0だった。数値差の最大値は3.552713678800501e-15。元のPineと仕様のSHA256も研究結果記録と一致した。

## 検証した状態遷移と限界

1. 左右5本のピボットを5本後に確定。同値の極値は最新を採用した。高値スイープ後にその足の高値を終値で上抜くと買い、安値スイープ後にその足の安値を終値で下抜くと売り。SLは掃かれた元ピボット。複数ピボットの同時スイープはPineと同じmin/maxで選択した。
2. 同方向の新規スイープはセットアップを置換し、その足では旧セットアップのブレイク判定を行わない。ブレイクはポジション保有中も消費する。買い・売りは独立し、両方向の同時保有を許す。セットアップの時間期限はPineに存在しない。
3. 2015年から売買状態を連続処理し、2017年以降のエントリーだけを集計。3年の境界では建玉とセットアップを引き継いだ。保存時計の0時を基準とする非空M15/H4足を利用。次足の最初の実在M1始値でエントリーし、SL側へ不利な始値なら見送った。
4. TPは価格桁に丸めた全決済1R。M1始値のSLギャップ1,440件は始値約定、TPギャップ1,164件は指値約定。同一M1内で両到達した340件はSL優先。最終M1の終値清算1件を含む。M1内部の真の到達順や未記録時間中の値動きは確認できない。
5. 全期間は過去に研究で閲覧された履歴。タイムゾーン、Bid/Ask種別、TradingViewと保存履歴の一致は未確認。往復1pipへ追加の変動spread・滑り・手数料・資金調達費は加えていない。初期リスク1Rで比較し、クオート通貨の金額や口座資金曲線は合算していない。
