# 当日進行を使う有限12候補研究

2026-09-08、追加研究の成績閲覧前に仕様を固定。初回24候補の不採用は保存し、今回を別実験とする。2019–2022等は過去に閲覧済みであり、未使用の検証期間と呼ばない。

## 仮説と反証

4H方向だけでは同じ足形でも、その日の開始位置・既に進んだ距離・残りの通常変動余地が異なる。当日状態を加えることで、順方向の押し目、逆方向の失敗、初動後の再確認を区別する。ADRは価格が到達すると保証された目標ではない。日中にその日全体を「トレンド日」と確定分類しない。

1. `day_pullback`: 当日始値から4H方向に一定距離進んだ日のEMA20再交差は、方向の定まらない再交差より継続しやすい。買いは前足終値<=前足EMA20、現終値>EMA20、終値>始値かつ方向変位>=ADR20×閾値。売りは対称。変位閾値0.20/0.40、レンジ消費上限0.70/0.90の4候補。
2. `previous_day_failed_break`: 上位方向に逆らった前日レンジ外への動きが失敗すると戻りが続く。買いは安値<前日安値−ATR×侵入幅、前日安値<終値<前日高値、足終値位置>=70%、現終値<当日始値、当日始値−当日安値>=ADR20×0.20。売りは対称。侵入幅0/0.10ATR、レンジ消費上限0.70/0.90の4候補。
3. `opening_range_retest`: 当日00:00–04:00の固定レンジを終値で突破し、その水準を再確認した足は初回突破より継続しやすい。買いは直前1–4本のどこかで終値が上辺を下から上へ横切り、それ以降の終値は全て上辺より上。現足安値<=上辺+接触許容幅、安値>=上辺−0.25ATR、終値>上辺かつ終値>足始値。さらに終値>当日始値。売りは対称。接触許容幅0/0.10ATR、レンジ消費上限0.70/0.90の4候補。ブレイク足自体でのリテスト発注は禁止、日付またぎの持越しは禁止。複数の連続した有効リテスト足はシグナルになり得るが、実行器は同一通貨1ポジションを守る。

レンジ消費=(その時点までの当日高値−当日安値)/ADR20。全候補で02:00以上20:00未満、序盤レンジ系は04:00以降。時刻はシグナル足の開始時刻、判断はその足の確定後。

12候補それぞれに`comparison_of`で対応する比較を1つ用意し、`selectable=False`として選抜から除外する。比較では当日始値方向・方向変位・逆行変位・レンジ消費ゲートを外す。前日高安/序盤レンジという足形の基準、欠損ゲート、時間帯、4H方向、決済条件は同じ。これは追加した当日状態ゲートの効果を測る比較であり、日付情報を全て除去した比較ではない。2候補が同一の比較シグナルになる場合も対応関係を明示して保存する。

反証条件は、学習と検証の両方で、対応比較よりコスト後勝率と平均損益Rが厳密に上昇しない場合。また勝率70%、取引数、PF、通貨横断等の既存採用ゲートは主担当のprotocolに固定し、そのどれかに不合格なら採用しない。比較との差は記述的な追加ゲートであり、有意差や因果効果の証明とは呼ばない。全12候補で終了し、確認期間の成績を見た再調整は禁止。

## 因果性・データ・約定

- 15分確定足、既存`_prepare`の確定4H方向と一致するシグナルのみ。最初の208本は無効。EMA20、ATR14は既存の因果的実装を使う。
- 日境界はnaiveなソース時刻の00:00。UTC、日本時間、NY17時、実市場の開場時刻とは断定しない。「序盤」はこの便宜的なデータ日付の序盤である。
- 当日高安は現確定足まで。00:00足がない日、15分間隔に欠損が生じた後の当日は無効。OHLC不正足後も当日は無効。入力時刻の重複・逆順・timezone付き・15分未整列はエラー。
- 前日高安は直前暦日の00:00〜23:45の96本が全て有効な場合のみ。それ以外に以前の取引日を代用しない。従って週明け等では前日系を見送る。
- ADR20は過去に完了した有効96本暦日の直近20日レンジの単純平均。週末等の空白暦日は観測日数に含めず、当日データは含めない。20観測日未満は全候補・対応比較とも無効。
- 序盤レンジは00:00〜03:45の16本から計算し04:00足以降のみ利用可能。未来の同日足から全日高安や日足終値を取得しない。出来高/VWAPを生成しない。
- シグナル確定後の連続した次足始値で約定。SLはシグナル終値から2ATR、発注時リスクと等距離のTPでRR1全決済。スプレッド・滑り・ギャップ・同時到達時SL優先・期間末強制決済は既存`simulate`を再利用し、ここでは変更しない。詳細値はprotocol。
- ポジションが日をまたぐことは禁止していない。日付でリセットするのは当日コンテキストと序盤ブレイク状態であり、決済は既存RR1実行器に従う。

## 境界テスト

合成系列で全12候補と12比較についてprefix invarianceと未来の同日足変更不変を確認。各系統の成立例・売買対称性・4H不一致・翌日リセット・欠損・未完了前日・ADRの当日除外・序盤レンジの利用可能時刻を検証する。利益成績で単体テストの期待値を調整しない。
