1. **入力と判定時点。** 16通貨のBars.datとinfo.datのSHA256が既存マニフェストの32値と一致した。事前仕様・実行コード・共通リプレイ・週次VA計算のSHA256を結果JSONと照合し、元M1からカレンダーUTC週別のVAを再計算した。候補の全約定で、08:00 JSTの判定時点までに完了した直近2週のVAの中心差と実際の逆方向の売買が一致した。月曜日08:15 JSTはUTCの日曜日で処理される。現在週のVAや約定分の高値・安値は新条件に使わない。
2. **約定・費用・資金。** 64台帳の5,250決済を元M1と照合した。基準32台帳は従来の全17列と一致。15分の連続性、順行幅、逆行幅、選択したVA内の価格、費用10%上限、TP・SLの方向、セットアップ再利用と保有重複の有無を確認した。決済の1,044件は期限、239件は始値でのSL、401件は始値でのTP、1,347件は足内SL、2,219件は足内TP。同時到達はSLが先となる順序をコードで確認した。費用後R、資金量、損益・残高は再計算と一致した。
3. **集計と独立検証。** 通貨別320行・合算20行の勝率、PF、平均R、合計R、通貨数、通貨別決済ドローダウンを再計算した。独立検証ではH4特徴を共有し、その他を別実装で再生して64台帳の全17列が完全に一致した。監査の照合は `python -B - value_migration` に検査コードを渡して終了コード0。新規ランナーと専用テストのruffは指摘0、専用pytestは10件通過。

期間は2017年1月から2025年末と、2026年1月5日以上8月28日未満の追加診断。GBPJPYの既知の価格異常を避けるため元M1は8月31日未満までを使用した。各取引を等リスクで集計し、共通の口座残高や同時保有による資金制約は評価していない。TradingView移植・実運用への引き渡しは不採用とした。[データ台帳](data_inventory.md)・[通貨別結果](../../../../agent_runs/patrick_vp_value_migration_20261118/summary.csv)
