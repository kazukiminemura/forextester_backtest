# Patrick VPの週次バリューエリアの移動

前週のバリューエリア（VA）の中心が前々週より高いときは買い、低いときは売りだけを許す。取引が集中した価格帯の移動と、08:00〜08:15 JSTの順行が一致すれば、現行の短期シグナルの費用後期待値が改善する、という仮説を検証する。中心はVA上限と下限の中点で、出来高最大の価格（POC）とは計算方法が異なる。

基準は国内朝の現行研究版「逆方向・費用10%以下・VA内・直前15分の最大逆行半分以内」。エントリー、利確、損切り、期限、通貨、費用仮定を揃える。長い連続分足を追加要求した過去の条件は2026年の保存データで評価対象がほぼ消えたため、今回は既に算出している確定週のVAを使う。

比較条件は [事前仕様](protocol.json) に固定した。過去3区分と2費用のいずれかで基準を満たせなければ終了する。総Rの変化は、取引を減らして1回当たりの成績だけが改善した場合を見分けるために併記する。
