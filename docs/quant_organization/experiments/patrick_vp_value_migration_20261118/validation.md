## 再現と照合

1. Forex Tester 6の原Bars.datを直接読み、UTC月曜00:00を基準に過去の確定週を独立集計した。M1典型価格を100ビンへ割り当て、70%のVAH/VALを再計算した。全16通貨の14,055週が既存特徴と完全一致した。選択した週次VAと、過去2週の中心差によるフィルター判定を区別した。月曜08:15 JSTは日曜23:15 UTCの週に属する。
2. 既存H4特徴を入力に、日次の独立実装で候補選択、08:15の連続15分、小さい逆行、費用10%制限、実約定の逆方向、ギャップ、TP・SL・期限、損益と数量を再現した。棄却時は当日の次候補を探さず、後続日を独立に再生した。64台帳5,250決済の全17列は最大絶対差0。候補の現行未出キーは41件。現行の32台帳は以前の小さい逆行版と全列一致。未決済・非正資産は0。
3. 通貨別320集計と合算20集計を再計算し、通貨別の最大決済ドローダウンも照合した。16通貨のBars.datとinfo.dat、凍結仕様、ランナー、リプレイ、特徴生成、プロファイル実装と結果のSHA256を照合した。

主実行は `python scripts/backtest_patrick_vp_value_migration.py`。独立実行は `python -u (Join-Path $env:TEMP "codex_patrick_value_migration_independent.py") agent_runs/patrick_vp_value_migration_20261118_independent`、照合は `python (Join-Path $env:TEMP "codex_patrick_value_migration_reconcile.py")`。両独立工程は終了コード0。独立用Python 2本のruff checkは通過。結果JSONのSHA256は `421cfd28a3b20393480c30d2bcf1159fe0c9b08e1f10fd5a4871dd4d37771cda`。

保存時刻をUTC、価格をBid、保存出来高を代理値と仮定した。スプレッド、滑り、保有費用は凍結モデルに従う。実測変動スプレッド、個別手数料、実測スワップは未検証。同一分でTPとSLの双方に届く場合はSL優先。
