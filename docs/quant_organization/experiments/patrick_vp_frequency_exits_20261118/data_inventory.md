# Patrick VPの取引数維持実験に使うデータ

実験 `patrick_vp_frequency_exits_20261118` は、既存のFX16通貨のM1と現行K10の32台帳で再現可能。調査日は2026年11月18日 JST、担当はデータ品質、引き継ぎ先は研究責任者。

## 原データと基準台帳

- `C:/ForexTester6/data/History` の16通貨を `HistoryRepository.summary()` で確認した。すべてに揃う保存日時は2009-10-01 00:00〜2026-09-07 23:59。保存された全135,117,663本のうち、現行再生の読込範囲である2009-10-01以上2026-08-31未満を切り出し、100,321,403本を `load_minutes` で全件検査した。時刻の分境界からのずれ、分に丸めた後の重複・逆順、非有限・非正価格、OHLCの上下不整合は0本。非有限・ゼロ出来高は0本、負出来高は45本。従来の週次VPは負出来高を含む週を無効とする。保存volumeをVPの代理として扱う。
- 16通貨のBars.dat・info.datのSHA256は[元のマニフェスト](../../../../agent_runs/patrick_h4_7d_reverse_20261107/result.json)と[前回のマニフェスト](../../../../agent_runs/patrick_vp_reversal_endpoints_20261118/result.json)の両方で32/32一致した。[現行32台帳](../../../../agent_runs/patrick_cost10_va_preentry_shape/)と前回の対照32台帳のSHA256は前回のマニフェストに一致し、全3,654行の17列すべてで一致した。始値または足内決済に対応する原M1も全行で確認した。
- 2017〜2025年の集計対象は通常2,529件、厳しめ939件。2026年追加期間はUTC 1月5日以上8月28日未満で通常137件、厳しめ47件。残る2件はUTC 1月4日のAUDUSDとEURCHFの通常費用で、連続再生に含まれるが、報告する区分の外にある。2026年8月31日以降はGBPJPYの既知の価格スケール異常を避けるため、今回のM1読込範囲から外れる。[異常の調査](../patrick_h4_7d_winrate_20261107/data_inventory.md)
- 保存時刻にはタイムゾーンがなく、M1価格がBidかもファイル構造だけでは確定しない。今回も保存時刻をUTC、M1価格をBidとしてモデル化する。EURHKDのtick記録は0件。過去の照合では一部の足の始終値がtickのBidと一致しなかった。info.datのlotは全16通貨で100,000、通貨桁はJPY建て3・その他5で、1 pipをそれぞれ0.01・0.0001とする。設定spreadは通貨別1.1〜4.3 pipsで、固定費用として1・2 pipsを置く今回の仮定とは別。設定上の手数料・スワップはゼロだが、当時の実約定費用は未確認。[時刻・価格種別の制約](../patrick_vp_value_migration_20261118/data_inventory.md)

## 17:00 JSTの足と元の決済時刻

次の件数は原台帳の取引が17:00 JSTを過ぎるまで残っていた場合を母数にして、保存時刻08:00のM1始値が得られるかを確認した。通常・厳しめの同一取引は別々に数えた。

| エントリーのUTC期間 | 通常費用 17:00足あり／保有継続 | 厳しめ費用 17:00足あり／保有継続 |
|---|---:|---:|
| 2017〜2019年 | 604 / 606 | 163 / 164 |
| 2020〜2022年 | 688 / 688 | 270 / 270 |
| 2023〜2025年 | 665 / 665 | 278 / 278 |
| 2026年1〜8月 | 99 / 99 | 28 / 28 |
| 合計 | 2,056 / 2,058 | 739 / 740 |

17:00の足がない3レコードはいずれも、次の観測が翌日だった。EURJPY通常の2018年4月30日は翌09:00（16時間後）、NZDUSD通常・厳しめの2018年12月25日は翌07:03（14時間03分後）。凍結仕様は当日中の最初の保存始値だけを使うため、これらはB・Cで部分決済しない。他の保有継続取引はすべて17:00の足があった。[事前仕様](protocol.json)

公表期間の3,652取引の元決済は、期限748件、始値でSL 171件・TP 269件、足内でSL 929件・TP 1,535件。同一足にSL・TPの双方があった元決済は0件。開始から元決済までに未記録の分を挟む取引は1,718件で、休場を含む。始値決済の記録時刻は該当足の開始時刻で、足内決済は該当足の開始時刻に60秒を加えて記録する。この区別を使うと、同じ分の始値での部分決済と足内での元決済の前後を再現できる。保存されなかった分の高安・約定は仮定しない。

## 追加期間と再現手順

2010〜2016年には16通貨合計41,580,307本のM1がある。2009年10〜12月をウォームアップとして、同じ条件の別時期比較を組める。2017年以前のM1は以前のPatrick実験の特徴量生成や別のFX研究で参照したため、未使用の最終確認期間として扱えない。2017〜2026年の試験区分も既閲覧。16通貨の共通原M1は2026年9月7日まで。[過去の参照範囲](../patrick_vp_value_migration_20261118/data_inventory.md)

照合は `python -B -` に読取専用コードを渡して実行した（終了コード0）。`sys.path` に `src` と `scripts` を加え、`HistoryRepository().summary(symbol)`、`backtest_patrick_vp_jst.load_minutes(repository, symbol, stamp("2009-10-01"), stamp("2026-08-31"))`、`hashlib.file_digest(..., "sha256")` を使った。台帳の照合は `numpy.array_equal`、17:00足は台帳のエントリー時刻に31,500秒を足し `numpy.searchsorted(times, scheduled)` で最初の保存M1を求めた。元手法の保有継続は元決済の記録時刻が予定時刻より後の行を抽出した。手仕舞い条件の損益・採否は研究実行と独立検証で扱う。
