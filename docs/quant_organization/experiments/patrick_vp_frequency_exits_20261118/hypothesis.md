# 現行Patrick VPの全エントリーを維持する比較

現行の全取引に同じ時刻・方向・初期ストップで入る。小さな順行を途中で利確する、または東京時間の夕方にリスクを半減することで、勝ちの取り逃しや保有費用を減らせるかを比較する。途中で利確すると大きな勝ちも小さくなるため、費用後PFの上昇は保証されない。

部分決済は各案1回・半分だけ。元のポジションが終わるまで半分が残るため、次のエントリー機会は現行どおりになる。元のエントリー1件に対し部分と残りを合わせて1件として数える。

前回の反転条件は取引を約88%減らした。比較用の第4案は、その条件をポジション量にだけ使用する。すべての取引に入るが、通常サイズで入る回数と平均ポジション量も報告し、サイズ配分による成果を区別する。未使用データによる確認がない限り、結果は研究用に扱う。[事前仕様](protocol.json)
