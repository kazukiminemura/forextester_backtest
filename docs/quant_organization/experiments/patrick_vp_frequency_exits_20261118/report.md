# 現行Patrick VPの取引数を維持するPF改善試験

**4案すべてで元のエントリーを100%維持した。検証した期間を通じて費用後PFの改善が再現した案はなかった。** 2017〜2025年の3期間・2費用すべてでPFが上昇したのは、過去に検証した反転の形に応じて取引量を変える案だけだった。この案は2026年の追加期間でも改善したが、同じルールを2010〜2016年に適用すると通常・厳しめの両費用で現行を下回った。

## 1. 取引機会と費用後PF

基準はFX16通貨、JST 08:15の逆方向Patrick VP。VA内、費用10%以下、直前15分の最大逆行が順行幅の半分以内という現行条件を全案で使用した。各案で通貨・方向・エントリー時刻・エントリー価格が一致。2017〜2025年の108か月で、通常費用2,529件（月23.42回）、厳しめ費用939件（月8.69回）だった。分割した決済は元のエントリーに合算して1件に数えた。

| 取引方法 | 通常PF | 厳しめPF | 通常 合計R | 厳しめ 合計R | PF改善区分 |
|---|---:|---:|---:|---:|---:|
| 現行 | 1.032 | 1.117 | +28.99 | +30.80 | 基準 |
| 元の利確幅の半分で50%利確 | 1.055 | 1.076 | +38.38 | +16.49 | 2/6 |
| 当日17:00 JSTに保有分の50%を決済 | 1.042 | 1.118 | +24.36 | +20.34 | 4/6 |
| 当日17:00 JSTに費用後損益がゼロ以下なら50%決済 | 1.037 | 1.140 | +26.63 | +29.36 | 4/6 |
| 反転条件が成立したときは通常量、その他は半分 | 1.061 | 1.155 | +29.67 | +22.23 | 6/6 |

改善区分は2017〜2019年、2020〜2022年、2023〜2025年のそれぞれを通常・厳しめ費用で再生し、費用後PFが現行を上回った区分数。通貨をまたぐ損益は元の通常量での初期想定リスクを1Rとして集計した。部分決済3案は残り50%を元のTP・SL・期限まで維持し、費用と保有時間は数量に比例して配賦した。

## 2. 取引量の変更でPFが上がった理由と限界

08:15までの3つの75分区間が売買方向に対し「逆行→順行→順行」のときだけ通常量、それ以外や必要な6本の価格が欠ける日は半分で入った。2017〜2025年に通常量だったのは、通常費用273/2,529件、厳しめ106/939件。平均サイズは現行の55.4%・55.6%になった。

この案のPFは共通の1R枠で集計した配分後PFである。個々の取引を実際に取ったリスクで割り直したPFと勝率は現行と同じ。たとえば全取引を一律半分にした場合、総利益と総損失がともに半分となりPFは変わらない。ここでのPF差は取引ごとに配分を変えたことから発生する。厳しめ費用では勝敗が同じでも、費用後の合計損益は+30.80Rから+22.23Rに減った。

| 比較期間 | 通常 件数・現行PF → 配分後PF | 厳しめ 件数・現行PF → 配分後PF |
|---|---:|---:|
| 2010〜2016年（追加の過去検証） | 1,961件・0.968 → 0.966 | 807件・0.801 → 0.790 |
| 2017〜2019年 | 766件・1.071 → 1.123 | 215件・0.842 → 0.881 |
| 2020〜2022年 | 879件・1.048 → 1.071 | 347件・1.366 → 1.422 |
| 2023〜2025年 | 884件・0.984 → 0.998 | 377件・1.075 → 1.099 |
| 2026年1月5日以上、8月28日未満（UTC） | 137件・1.232 → 1.316 | 47件・1.059 → 1.097 |

2010〜2016年の合計Rは、通常費用が−24.30Rから−14.81R、厳しめ費用が−57.99Rから−34.45Rだった。平均サイズの縮小で損失額は小さくなったが、損益の比率は改善しなかった。2026年の通常費用でも+10.12Rから+7.13R、厳しめでも+0.90Rから+0.74Rと、配分後の合計Rは現行を下回る。

2017〜2025年の配分後PFと現行PFの差について、暦の13週をまとめて再抽出した参考95%区間は通常+0.003〜+0.056、厳しめ−0.016〜+0.100。各エントリーをUTC月曜始まりの週にまとめ、2016年12月26日を先頭とする471週に利益Rと損失Rを集計した。全通貨・全案で同じ連続13週を循環復元抽出し、471週分に切り詰めた1万回のPF差の2.5・97.5パーセンタイルを使用した（NumPyの `default_rng(20261118)`）。この補助分析は事後の不確実性評価で、採用基準は変更していない。

## 3. 判断の範囲と検証記録

同じ初期サイズで入る部分決済3案のうち、通常費用の合計Rが増えたのは中間価格で半分利確する案だけだった。2026年の厳しめ費用では現行PF 1.059に対し、中間利確0.965、17時決済0.866、17時損益条件付き0.949。取引サイズの変更も含め、現時点で現行を切り替える根拠は得られなかった。

M1は保存時刻UTC・価格Bidを仮定し、通常／厳しめのスプレッドを1／2 pips、片道スリッページを0.1／0.2 pip、経過1日当たりの保有費用を0.2／1 pipとした。約定ごとの最低手数料はモデルに含めていない。2017〜2026年は既に参照済み。2010〜2016年も他研究で使われており、完全な未使用データによる将来成績の確認には至っていない。
