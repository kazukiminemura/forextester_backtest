# J LawのVCPを日本大型株の日足で検証

上昇トレンド中に下落幅と出来高が順に減少する銘柄では、出来高を伴う高値突破後に上昇が続きやすいと仮定する。同じ上昇条件、突破条件、損切り、利確を使う基準と比較し、二つの収縮条件を加えたときの増分を調べる。

1. 画像の「押しが段階的に浅くなる」を、確定日足の20日、10日、10日の連続した区間内の最大押し率で近似する。第一収縮20〜35%を画像寄りの条件、10〜35%を日本大型株でも調べる緩和条件とする。
2. 同じ三区間の平均出来高が順に減少し、突破日は直前50日平均の1.5倍以上とする。
3. 突破確認後の翌営業日始値で、突破水準より上かつ損切り幅8%以内なら買う。最終区間の安値で損切り、損切り幅の3倍で全利確する。

画像には突破後の押し目買い、10日・20日線による手仕舞い、売上加速や市場・業種の判断もある。今回の検定対象は突破買いの価格・出来高条件と固定3R決済である。52週騰落率の市場内順位、価格・流動性の米ドル下限、決算・売上、業種の同時上昇、地合い、追加購入は対象外。画像の選別・執行をすべて再現するには、時点整合の取れた幅広い銘柄・財務・業種データが必要になる。

費用後の平均Rが各評価期で基準を上回るかを調べる。3区分と費用ストレスで黒字が再現せず、黒字が少数銘柄に偏る場合は採用を支持しない。約定数が不足する場合は証拠不足とする。現在の大型株の固定集合を昔に適用する記述検証で、生存者・銘柄選定バイアスを含む。期別の集計は再現性の参考で、独立した未使用データによる確認には使わない。
