# PF1.5を目的とする固定時間帯探索

今回のユーザー指定ではPF1.5を目的とし、勝率70%を必須条件から外す。RR1全決済、直近3か月、円クロス5通貨は維持。
サブエージェント不使用。新しいアプリではなく既存売買処理を再利用する。

既存36候補に、保存時刻の全時間・00–08・08–16・16–24・00–12・12–24を組み合わせ216条件を一度だけ評価。
仮説: 流動性・値動きの異なる時間帯でシグナルの期待値が異なる可能性。結果から細かい時間帯を追加しない。
時刻はシグナル足の開始時刻。次15分足で入るため境界後のエントリーがあり得る。窓外で決済せずRR1を維持。

既存の候補抽出条件から勝率条件のみ除外: PF1.5、期待値正、決済DD10%以下、合算75件/個別30件以上、各月10件以上かつ利益。
合算は各通貨10件以上・4/5通貨利益も要求。後から基準を緩めない。
36候補×5通貨の既存結果は閲覧済み、今回さらに時間帯を比較する。既閲覧の3か月内の記述的探索であり未使用ホールドアウトではない。
通過しても実運用承認ではなく追加検証候補。母数不足の高PFを別掲する。

実行前にagent_runs/quant_pf15_jpy_recent3m_20260908/protocol.jsonとコード指紋を保存。
直近範囲へデータを切り出すのは全履歴で因果的な指標・シグナルを算出した後。全時間の結果が前回36候補と一致することを要求。
