# BTC現物買い・4h上昇中の1h押し目突破・全決済RR1

状態：結果前仕様。採用候補は1案、比較1案、費用2条件で固定。値の調整や後期結果からの再探索を行わない。

## 反証可能な仮説

上位足で持続的な買いがあるとき、一時的なEMA20への押し目後に直前3本の高値を終値で上回る現象は、短期売りの終了と買い再開を表す可能性がある。構造安値外側までの損失幅と同幅の利確が、費用を埋める頻度で成立するか検証する。これは説明仮説であり、需要や注文フローを直接観測した証明ではない。

トレンドの反転局面、横ばい中の繰返し突破、急落によるストップギャップ、押し目なしの上昇、細い値幅に対して大きい費用で崩れる。固定4h条件が費用後成績を改善しない場合、上位足の複雑化を正当化できない。

## 固定ルール

1. BTCUSD、現物相当のUSD資金・買いのみ。4h最新確定close>EMA200、EMA50>EMA200、EMA50>3本前。確定後4h以上経過した上位足を使用しない。
2. 完全で隣接する1h4本を使う。過去3本のいずれかが当時のEMA20にタッチ、現確定終値が過去3本最高値とEMA20を超える。
3. SLは4本最低値−0.1×1h Wilder ATR14。次1h開始時のM1始値を市場約定モデルにする。開始M1欠損なら失効。数量と費用フィルターはシグナル確定時に計算する。
4. 実買値基準TP=2×買値−SL、全決済RR1。買値にはspreadと買いslippageを含む。売りslippageと売買feeで純利益/損失は厳密な±1Rにならない。固定SL/TP以外の取引中変更なし。
5. 比較は4h条件だけを外す。同時1保有、決済した同1h内に再入場しない。期間末強制清算は別集計。

EMAは初回N本のSMAをseedとして通常EMAへ、ATRは初回14TRのSMAをseedとしてWilder再帰へ移行する。完全足のみ指標を更新し、欠けた足を補完しない。未来の4h終値、未確定1h足、ピボットを使用しない。Python/Pineの将来照合ではこの初期化と利用可能時刻を共通仕様にする。
