# 日足押し目の3候補とJevによる訓練結果評価

前実験は高安切上げ条件が遅れ、短期突破条件が厳しく機会を減らす可能性がある。3候補だけを結果前に固定する。baselineは前実験の同一関数を比較専用として実行し、選抜対象に含めない。

1. `no_dow`: baselineから確定ピボットの高安切上げ要求だけを取り除く。21SMA上向きと終値>SMA21、直前3日SMAタッチ、直前3日高値を終値で突破は維持。遅延低下と取引数増加を仮説とし、持合い損失増加で反証される。
2. `prior_day_breakout`: baselineの確定Dow、上向きSMA21、直前3日SMAタッチを維持し、終値>直前3日高値最大を終値>前日高値へ緩和。SLは直前3日安値のまま。早い再開の捕捉を仮説とし、未完成の押し目への早過ぎる参入で崩れる。
3. `sma63_trend`: baselineのDow条件だけをSMA21>SMA63へ置換し、他の条件は同一。平滑な中期方向が押し目の局面判定に役立つ仮説。転換時の遅れ・持合いで崩れる。SMA63が有効になる63本目以降に限定。

全候補はロング日足、上位足なし。確定日引け信号、翌観測営業日始値、SL=信号前3本安値、TP=始値+(始値-SL)、RR1全決済。旧simulateを再利用し、費用/窓/同足両hit/期末清算/ポジション/資金を変更しない。2016-07-12以降ウォームアップ。通常片道0.1%、ストレス0.2%。各銘柄10万円全額、端株の調整株数モデルで100株単位を再現しない。

訓練は2017–2019のみ、2020以降の信号も計算しない。訓練10銘柄通常費用でtrades>=50、netPF>=1.1、純益>0、引けMTM DD<=20%の全条件を満たす候補だけが選抜可。訓練年別/銘柄別/品質診断/stressをJevへ渡して最大1候補またはnoneを選ぶ。Jevの確率は将来勝率ではなく、選択肢間判断の確率である。全候補不適格なら後続計算なしで停止。

selection.jsonにはexperiment_id、training_sha256、selected_candidate（3候補IDまたはnone）、selector=jevを必須とする。後続runnerは訓練ファイルhash一致、候補enum、訓練数値条件、仕様/ソース/データhash不変を確認してから選抜1候補のみ2020–2022、2023–2025、2017–2025連続を計算する。baseline/buyholdは対照。年別は連続MTM差、PF/勝率は決済年の取引損益であり、持越しにより一致しない。

データは旧キャッシュを固定再利用し、全期間すでに閲覧された期間である。独立未使用holdoutではない。DATA_LIMITED後方調整価格、Sonyスピンオフ、2銘柄の包絡修復、現在大型株の選択/生存バイアス、配当/税/金利除外など旧制約をすべて引き継ぐ。主10銘柄100万円、Sony除外9銘柄90万円、既知問題3銘柄除外7銘柄70万円の集約診断は候補追加ではない。

最終基準は旧基準を維持し、検証/最終各100件・PF>=1.1・純益>0・DD<=20%、最終黒字6/10・stress最終純益>0。選抜/検証不合格は保存して終了。成績を見た再調整、実注文、Pine移植をしない。

再現: `python -m unittest discover -s tests -p test_tamukai_stocks_jev.py -v`、`python scripts/research_tamukai_stocks_jev.py --phase training`。選抜後のみ `python scripts/research_tamukai_stocks_jev.py --phase evaluation --selection agent_runs/tamukai_stocks_jev_20260926/selection.json`。数値結果と各CSVは新実験resultsへ保存し、独立検証担当へ引き継ぐ。
