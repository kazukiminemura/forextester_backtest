# BB代替手法・事前仮説

2026-09-25、成績計算前に protocol.json を固定。新規2案のみ、全決済 RR1:1。

1. **±2σ終値復帰**：バンド外から内へ終値が戻ると短期の行き過ぎが弱まる可能性。従来3段階確認より早く入るため中央線までの余地を残せるかを反証する。強いトレンド中の一時的復帰、薄い利幅、連続損切りで崩れる。
2. **W底/M天井**：2度目の終値極値は価格を更新してもバンド内に残り、戻り高値/安値を終値突破すれば勢いの変化を表す可能性。ピボットの右2本確定遅延を厳守する。突破が遅く損切り幅が広い、急反転、レンジ内のだましで崩れる。

単純比較は現行BB3逆張りRR1。2案を現行に追加するのでなく別の状態機械として比較する。W/Mの目標は中央線でなく実約定から1R（中央線を突破済みの場合に不正な買いTPを置かない）。M5のみ、上位足なし、パラメータ探索なし。

公開資料は [BB公式スクリーナー](https://bollingerbands.us/help-screening.php) と [公式ルール](https://www.bollingerbands.com/bollinger-band-rules)。機械化に必要な60本有効期間・ピボット2/2・RR1・3pips最小幅などは研究者の事前仕様であり、公式の完成戦略とは称さない。

2023–2025年は既閲覧。全案・全年・全通貨を報告し、その結果を見て再調整しない。元履歴はForex Testerの凍結キャッシュ、時刻帯未確定、価格はチャートOHLC。1pipは仮定コストでGMO実測ではない。利益保証、実注文、Pine採用はしない。Jevは必要ならコードレビューだけで、売買判断には使わない。

再現コマンド：`python scripts/research_bb_alternatives.py`

担当成果物：新runner・挙動テスト・run_manifest・全明細/MTM/集計。独立検証担当は別実装または独立計算により未来参照、RR1、コスト、期間境界、全案の合否を照合する。
