## 失敗理由と解釈制限

1. 全案で学習・検証の net>0、PF>=1.2、stress>0、DD<=20% が不通過。完全日率の不足とは別に、この費用モデル上の採算も不合格である。結果後に閾値・候補・費用を選び直していない。
2. 小さい価格RR1幅に spread が重なると入場M1 openの反対quoteが既にSLを越え、即時stop_gapになる。0.25%は予定stopの数量基準にすぎず、funding/gap込み実損失の上限ではない。通常の予算超過はBB 723/361/298、レンジ334/118/117、H1 5,810/1,485/1,774件。実装エラーとして後から除外していない。
3. 実最小BTC数量/数量刻み・実維持証拠金/強制清算は未実装。通常H1学習には入場資産USD1未満が6,265件、最小数量約2.068e-10 BTCを含む。費用増加は7,181件、約3.407e-15 BTC。微小正資産でもfractional注文が続く仮定のため、これらの件数はGMOの実注文機会数ではない。表示上の学習損失-10,000/DD100%は丸めで、原数値の微小正資産は保持する。
4. BTCUSD bid仮定・合成ask・静的USD spread・仮slip・未知source時計のfunding代理はGMO BTCJPY実履歴ではない。通常0.04%/日も歴史料率/実JST6時跨ぎの復元ではない。板、約定拒否、実数量刻み、実margin、通貨換算、動的spread、実slippageは未検証。採用falseを維持する。
5. DDは観測M1終値ベースの清算価値と実決済値であり、未観測分・足内全経路は復元しない。通常BB学習の最長保有19,256分など欠測跨ぎがある。単一BTC銘柄・全期間既閲覧で、別商品や未使用期間への頑健性は未証明。

## 事前確認

1. ユーザーが CFD の買い・売り両方向と GMO コイン暗号資産 FX を指定したため、暫定現物買い限定を撤回。BTCUSD 保存 bid 仮定履歴と合成 ask による proxy 研究であり、GMO BTCJPY の実成績再現ではない。現物購入現金会計や FT の lot100000 を流用しない。
2. 完全 5 M1 の M5、完全 12 M5 の H1、signal 終了時点までに確定した最新暦 H1 だけを使用する。H1 は 25 連続時間を要求し、不完全直近時間から過去の有効時間へ遡らない。BB20/Wilder ATR14 は観測済み完全 M5 の順で gap を越えて更新する仕様を明示している。origin→確認と効率計算は別途連続性を要求する。
3. 次の予定 M1 open が存在する時だけ入場。BB は signal 中央線を固定し、long は bid TP、short は中央線+spread の ask TP、actual fill を中心に SL を対称配置。トレンド案は signal 時点の prior ATR×1.5。正の値幅以外の FX 3 pips や旧 cost/risk0.15 条件を導入しない。M1 同足両到達は SL 優先、stop gap は観測 open、TP gap は TP まで、期末は別理由で強制決済する。
4. CFD 初期 USD10,000、actual fill 時の資産×0.25% を exit slip/fee 込み stop リスクで数量化し、notional を資産 1x 以下に制限する。funding/gap によるリスク超過は別診断。long/short の入口・出口 quote side と不利な slip を分ける。通常/増加/zero の 27 ケースは独立再生し、最良条件を選抜しない。
5. funding は実 JST6 時ではなく正の経過24時間ブロック数×rate×その時点までの最大 synthetic ask high×数量。MTM に未来の全取引高値を使わない。ただし exit 分足内高値は決済後に生じた可能性があり、同じ timestamp の入退場は elapsed0 となる。これは M1 OHLC と開始 timestamp に基づく保守的仮定で、実課金上限を証明しない。
