# 日足3×3 Double Repo・ダウトレンド決済の固定仕様

実験ID: `dinapoli_3x3_daily_dow_exit_20260910`。ユーザーの「ダウトレンドが転換するまで保有」に基づき1R利確を廃止し、初期構造SLを残す。実走前に仕様を保存する。これは機械的ダウ定義の研究であり、裁量手法そのものではない。

## 仮説・比較・反証

Double Repoによる推進失敗後の反転が持続するなら、1R利確を廃止し日足の高値・安値の反転まで保有することで少数の大きい利益を捕捉でき、初期リスクで正規化したコスト後平均Rが改善する。遅い反転確認による利益返上、レンジでの小損、片方向の初期SL、スワップ、価格ギャップにより崩れる。初期SLが広い場合、ダウ決済が損失側で先に起こる可能性もある。勝率改善を約束しない。

比較は前回と同じ `double_repo_8`、`double_repo_10` の1R全決済を学習期間で再計算する。エントリー・構造SLは固定し、変更は出口だけ。保有時間の変化により1通貨1ポジション制約下で採用されるエントリー集合は変わる。結果を見て出口を再調整しない。

買いはDMA下側の推進N日後、上抜け→下側復帰→再上抜け、売りは対称。N=8/10、初回からN日以内。構造SLは推進開始からシグナルまでの安値−0.1ATR（買い）、高値+0.1ATR（売り）。次始値でSLを既に越えたら取消。

## 新出口: 確定スイングによるダウ状態

候補は左右本数が同じ厳密pivotの2/2、3/3の2出口×DR8/DR10=4。比較専用1R出口は2、合計6ルール。追加探索なし。

日足kのhighが左右p本のhighすべてを厳密に上回ればpivot high、lowが左右p本のlowすべてを厳密に下回ればpivot low。同値は不成立。k+p日の引けで初めて利用可能で、日付をkへ戻して取引判定しない。同日にhigh/low両pivotが確定したら双方を同時更新する。連続した同種pivotも各々採用し、交互性の追加選別はしない。

直近2つの確定highと直近2つの確定lowがともに切上がればup、ともに切下がればdown。混合・同値では前回の確定状態を維持、必要なpivotがまだ揃わない初期状態は0。状態は評価区分より前の観測情報でウォームアップするが、取引・Double Repo準備は区分開始でリセット。

各ポジションは `dow_armed=false` で開始する。エントリー後の日足引け（エントリー当日を含む）で、買いならup、売りならdownを観測したら `dow_armed=true` にする。armed後の別の日に、買いならup→down、売りならdown→upの新しい確定状態遷移を確認したら翌日足の実始値で全決済。エントリー前から続く逆状態だけでは出口を発火しない。保有方向の状態が一度も成立しなければ初期SLまたは区分末まで保有する。エントリーをダウ条件で制限しない。TPなし、分割・建値移動・トレール・時間上限なし。

時系列は、(1)始値で初期SL超過なら始値SL、(2)前日ダウ決済予定があれば始値全決済、(3)その日の日中に初期SL接触ならSL、(4)保有が残れば引けダウ判定。このためダウ確認日に初期SLに触れればSLが先。翌日始値でダウ決済済みなら同日後刻SLは無関係。始値SLと予定ダウ決済が同時ならSL理由を優先する。

1通貨1ポジション。保有中・決済当日のシグナルは捨てる。最終日のダウシグナルは翌区分へ持ち越さず、未決済・未実行ダウ出口として含み損益を別計上する。区分末含みを正式PF/勝率から除外し、時価清算した感度指標を別記する。
