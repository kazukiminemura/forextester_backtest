# 15分足のヒゲによるスイープと反転

確定スイングの高値または安値を抜いた後、その水準の内側に終値が戻ると、次の足以降で反転が続くかを調べる。損切りをヒゲ先、全利確を1Rに固定し、費用前後で利益が残った割合を数える。理想的な等幅約定では費用前50%が損益分岐。ギャップや期間末決済があるため実際の損益はPFでも確認する。

売買条件は今回の検証用。設定値探索は行わず、公式のOnly Wicksモードを対象にする。[作者による説明](https://jp.tradingview.com/script/JRqryeJ5-Liquidity-Sweeps-LuxAlgo/) / [照合用Pine掲載元](https://indie-script.github.io/indicators/Liquidity%20Sweeps/)
