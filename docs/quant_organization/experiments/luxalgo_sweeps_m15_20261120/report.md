# Liquidity Sweeps [LuxAlgo] の15分足勝率

Forex Testerの5通貨ペア、2017年1月〜2025年12月の48,436取引。費用前勝率49.76%、往復1 pip控除後の勝率46.28%、費用後建値を勝ちに含めると47.19%。利益22,418件、損失25,579件、建値439件。各取引の初期リスクを1Rとする費用後PFは0.450、平均損益は−0.402R。

LuxAlgoの初期設定（Only Wicks、Swings 5）をPythonで再現し、確定した安値を下ヒゲで割り終値で戻したら買い、高値を上ヒゲで抜き終値で戻したら売りとした。左右5本で確定したスイングを使用。今回の追加売買ルールは、次の実在15分足始値でエントリー、シグナル足のヒゲ先を損切り、等幅の1Rで全利確。1通貨1建玉で、同じ足に売買両方が出た場合は見送り。期間内の最終足で残存建玉を清算した。[作者の説明](https://jp.tradingview.com/script/JRqryeJ5-Liquidity-Sweeps-LuxAlgo/) / [設定・再現仕様](protocol.json)

1分足で約定順序を判定。始値で決着せず同じ1分内に双方へ達した590件は損切りを先とした。損切りを飛び越えた場合は始値で約定。費用後の建値には浮動小数点誤差（絶対値1e-10R以内）を含む。損切り幅の中央値は4.0 pipsで、往復費用1 pipはこの幅の25%に当たる。変動スプレッドやスワップは再現していない。

USDCHFでは対象の1分足の61.66%で始値・高値・安値・終値が等しく、細かな値動きの再現に制約がある。事後の感度確認として同通貨を除いた4通貨41,293件の費用前勝率は49.82%、費用後46.24%、費用後PFは0.446。両集計とも費用後の損失が利益を上回った。TradingView実チャートとの全シグナル一致は未確認。
