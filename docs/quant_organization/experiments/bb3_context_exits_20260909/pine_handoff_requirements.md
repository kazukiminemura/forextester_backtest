# 損切り・利確拡張のPine対応要件

2026-09-09ユーザーがエントリーだけでなく損切り・利確の変更も承認。対象は既存 `scripts/tradingview/bb3_context_pf_indicator.pine`。従来2実験は不採用のまま保持し、本実験を別の有限探索とする。

主担当はPineを現時点で変更しない。研究担当はprotocol、実装、結果を所有し、独立担当はauditを所有する。

採用候補が得られた場合の対応:

- 研究と同じBB準備・突破・長ヒゲ除外・確定足判断を保持する。
- 成行なら信号翌足の始値、指値なら発注後の有効期間・取消・約定順序を研究と一致させる。指値候補を成行に置き換えない。
- 固定SLはエントリー基準。ATR基準の場合は注文作成時点で知り得たATRから距離を保存し、エントリー足や以後のATRで遡及変更しない。
- RR利確はSLとの価格距離比で全決済、往復コストは別控除。中央線だけが確定足ごとに動き、固定RRのTPは移動させない。
- entry足からSLを有効にし、曖昧な足内順序で利益を優先しない。ギャップ損失を指定SL価格に押し戻して小さくしない。
- Entry/SL/TPの区別と価格、実際の使用設定、コスト控除後PF、含み損益を表示する。表示を正にするための取引除外はしない。
- 研究設定とPine設定の一致をテストし、TradingView上でのコンパイルと対象期間の成績を別途確認する。未実行ならTV_UNVERIFIEDと明記する。

候補は19種類まで。選抜や採用の詳細基準は同フォルダーのprotocol.jsonを参照。結果が不採用ならPineへの既定採用はしない。研究過程で閲覧した期間を未使用と称さず、利益を保証しない。
