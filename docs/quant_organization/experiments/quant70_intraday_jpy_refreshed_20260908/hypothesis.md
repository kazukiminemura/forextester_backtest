# 更新履歴による円クロス再点検

ユーザー指示により主担当のみで実施し、サブエージェントは使用しない。
新しい戦略アプリは不要。既存の当日状態12候補と監査済みRR1全決済エンジンを変更せず再利用する。

## 実行前の計画

- AUDJPY、CHFJPY、EURJPY、GBPJPYに、全期間の履歴が更新されたNZDJPYを追加。USDJPYは除外。
- 学習2010–2018、検証2019–2022を維持し、2023–2024、2025–2026-09-07も全候補について記述的に再点検する。
- 後半期間を見ない旧選抜実験とは目的を分ける。今回は選抜を行わず、後半期間を未使用ホールドアウトと呼ばない。
- 元の12候補、対応する当日状態なし比較12件、単純基準1件。パラメータ変更や追加探索は行わない。
- 利益通貨数だけ対象数に合わせ3/4から4/5にする。勝率70%、PF1.5、RR1、コスト、その他の絶対基準を維持。
- 保存明細から別計算式で集計・RR1・約定順序・通貨期間別ゲートを照合する。独立した担当者による監査ではない。
- 元ファイルのサイズ・更新日時を実行前後に比較し、更新中なら失敗とする。

実行時に `agent_runs/quant70_intraday_jpy_refreshed_20260908/` に protocol.json、コードハッシュ、候補、比較条件、履歴一覧を成績計算前に凍結する。
根拠コードは `scripts/revalidate_quant70_jpy.py`。データソースはローカルForex Testerのみ。
