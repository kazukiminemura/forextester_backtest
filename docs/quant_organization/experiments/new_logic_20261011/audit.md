## 重大度付き所見

1. **高・採用を妨げる証拠不足**：新Aは各RR2取引（USDJPY 0 / EURUSD 1 / GBPUSD 1）、新Bは各RR15取引（3 / 5 / 7）。全6構成が合計200件・各通貨50件、通貨分散条件に不合格。AのRR1.5だけを選ぶ事後的な例外は認めない。他5構成の観測赤字も、この小標本で一般的な価格構造の不利益を確定するものではない。通常USDJPYの停止なしは、新A0件・新B3件しかないため安全性の証明ではない。
2. **中・研究上の残存制約**：2020–2025は既閲覧。source時計・OHLC価格side・実spread/slippage・swap・broker数量条件は未確認。M15同一足の順序を復元できない。固定仮定費用とSL優先を用いた記述研究に限定する。閉鎖取引DD_Rは報告値であり、事前の数値DD_R採用閾値はない。採用不合格後にその閾値を追加していない。
3. **中・結果前に解消**：旧研究の共通月次関数に月300万円の `goal_met` が残っていた。監査指摘後、研究担当が `cash_monthly` で旧キーを除き、月初残高比 `monthly_return` と `reaches_5_percent` に変更してから凍結・初回実行した。売買条件や採否の変更ではない。全864月セルで旧キー不在、比率と真偽を再計算確認。
4. **低・結果前に解消**：protocolの入力台帳参照 `data_inventory.md` が実在しなかった。監査指摘後、実在する `data.md` 参照へ修正してから凍結した。
5. **情報・表示単位**：`usdjpy_accounts[*].pf` は共通関数由来のPF_Rであり、円損益のPFではない。統合報告はPF_Rと円口座残高を区別している。3通貨のR合算はポートフォリオ円利益ではない。

未解消の重大な実装・会計不整合は、今回確認した範囲では検出していない。上記の採用不可は正常な事前基準の適用である。
