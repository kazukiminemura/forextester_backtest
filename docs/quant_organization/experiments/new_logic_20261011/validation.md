## 因果・執行・漏洩監査

1. 前24本のbox・前20TR・前25本closeだけで測定、現足は確定してからsignal。HTFなし。3通貨各3時点のprefix打切りで過去signal/SL/ATR/room/thresholdに変更なし。実走は学習期末以降の全配列を除去して計算。
2. 次の連続M15かつ実M1始値ありでentry。開始前signal不可、entry足の後続OHLCによる入口選別なし。cost floorは通常費用に固定し、費用2倍で入口基準を都合よく変えない。
3. 同一足SL優先、逆行gap始値、順行gapはTP上限、欠損跨ぎ次の観測始値、途中欠損は保護注文確認後close。16本またはsource23:45、期末close。目標RRは全決済で、時間決済・費用込み実現payoffを別計算。
4. USDJPYのみ100万円/0.5%risk/25倍上限/1,000単位/90万円停止を再生。gap時は停止水準超過可能。全足極値によるTP/time-exit足DDは保守的境界で、tick内の正確な順序を示さない。
5. 6候補＋6同RR対照を学習内で比較、最大1選抜、後期落選後の次点繰上げなし。全期間既閲覧で真のholdoutなし。選抜0のため後期承認ファイルを作らず停止。

## 失敗理由・未検証・引継ぎ

- 入口の通常費用10倍以上risk制限でA40件/B1,506件のsignalが除外され、Bではroom不足111件も除外。これらは結果後に緩めない。除外理由は初期RR1通常の3通貨合計、全RRを重複加算していない。
- RR1/1.5/2の出口感度と費用2倍感度は完了。他のパラメータ感度・近隣box/ATR/待機本数の頑健性は未実施。結果を見た追加探索は別実験IDで扱う。
- 未実装コストは実spread変動、実slippage、swap、broker手数料/数量stepの実証。OHLC価格側とsource timezone/DSTも未確定。価格側未確定の固定費用近似で実口座成績を主張しない。
- 研究合格・月利5%達成・実運用承認はいずれもなし。旧不採用資料・現在Pineは保持。次担当は品質監査：本書と独立JSON、凍結SHA、件数不足判定を照合して主担当へ引渡し。
