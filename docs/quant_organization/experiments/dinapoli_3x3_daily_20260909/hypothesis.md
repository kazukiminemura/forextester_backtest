# 日足 3×3 DMA Double Repo 研究仕様

実験 ID: `dinapoli_3x3_daily_20260909`。数値結果を閲覧する前に固定する。
ユーザー依頼はディナポリ3×3を用いた日足トレードの考案。公開された条件を
機械化した研究モデルであり、Joe DiNapoli の裁量手法や書籍を完全再現したものではない。

## 仮説と反証

終値が3×3 DMAの片側に連続する推進相場の後、DMAを一度逆抜けし、元の側へ
復帰してからもう一度逆抜けすると、推進方向への再試行が失敗した情報が加わる。
その後の反転方向への価格変化が、構造的な損切り幅と等しい利益幅に先着する確率が
コスト控除後の損益分岐点を超える、という反証可能な仮説を置く。
単純DMAクロスと比べ、条件を追加することで取引数は減るが平均net Rが改善すると予想する。
推進が継続する市場、DMA付近の往復、急な窓開け、構造SLが広すぎる場面で崩れる。
「DMAから離れたから必ず平均回帰する」という主張はしない。

## 指標・日足・時点

- 日足は原履歴保存時刻のcalendar dateを基本とし、日曜を翌月曜のtrading dateへ併合する。
  実在する5分足のOHLCを集約し、価格や欠損を補間しない。UTC/JST/NY終値とは未同定。
  区分の帰属はtrading date、約定時刻は実際の最初の5分足時刻。日曜開始なら月曜日付の足に入る。
  実装はOHLCが同値になるM1→日足の直接集約を使用する。raw first/lastはM1始値時刻、
  シグナル利用可能時刻は最終M1始値+60秒であり、翌日最初のM1始値以下を検査する。
- `DMA[t] = (close[t-3] + close[t-4] + close[t-5]) / 3`。
  SMAを3本右に表示した時の当日値であり、未来終値は使わない。
- ATR14はTRのWilder平均。初回は最初の14本のTRの単純平均、以降 `(13*ATRprev+TR)/14`。
  初日のTRはhigh-low。全戦略は最低30観測日足のウォームアップ後にだけシグナル可能。
- 日足確定後だけ判定し、次の存在する日足の始値で入る。上位足条件・ピボットは使用しない。
  指標は区分開始前からウォームアップするが、セットアップは区分開始時にリセットする。

## 事前固定3ルール

採用候補は2個、比較専用は1個。追加探索しない。買いと売りは厳密対称。

`double_repo_8`: 推進8本、初回抜けから2回目抜けまで最大8観測日足。
`double_repo_10`: 推進10本、初回抜けから2回目抜けまで最大10観測日足。

売りの場合:

1. 当日を除く直前N本の各終値がそれぞれのDMAを厳密に上回る。
2. 当日終値がDMAを厳密に下回れば初回抜け。推進開始日からの高値を記録する。
3. 初回より後の終値がDMAを厳密に上回れば、一度の復帰を記録する。
4. 復帰より後の終値がDMAを厳密に下回れば2回目抜けとして売りシグナル。
   初回からN本以内であること。期限超過後はキャンセルし、同じ日足で再準備可能。
5. 同値は上側/下側のどちらでもなく、復帰にも抜けにも使わない。
   両方向の準備は独立して検出し、両方向同時シグナルの場合は双方キャンセルする。

買いは全不等号・高安を逆にする。局所高安の後日確定を待たないためピボット遅延はない。

`dma_cross_baseline`: 前日終値<=前日DMA、当日終値>当日DMAで買い、売りは逆。
SL構造範囲は直近10本（当日含む）。これは比較専用で選抜しない。

## エントリー・全決済

シグナル日の確定ATR14の0.1倍を、推進開始日〜シグナル日の最高値に足した値を
売りSL、最低値から引いた値を買いSLとする。翌日始値が既にSLを越えていたら取消。
リスク幅が0以下/非有限なら取消。最低・最大幅の探索フィルターは加えない。
TPは実際の翌日始値からSLまでの距離と同じ距離（gross価格RR1:1）。全量を1回で決済。
建値移動・分割・トレーリング・シグナル反転決済・時間決済はしない。
準備の期限8/10日と、ポジションの保有期限なしは別の概念。
1通貨1ポジション、ポジション中のシグナルは捨て、決済当日も再シグナルしない。
検出器の準備状態はポジション中も価格だけで更新されるがシグナルは保存しない。

日足始値がSLを越えていれば始値で損切りし1Rを超える損失を認める。
始値がTPを越えていれば有利な窓幅を取らずTPで利確する。
窓条件を先に判定し、それ以外の同日SL/TP両接触はSLを先とする。
5分足の順序推定を用いず日足全体にSL優先を適用する、保守的なOHLC近似である。

各評価区分はフラットから開始する。区分末の未決済はPF/勝率に含めず、
最終終値で費用控除後の含みRを別計上する。将来区分まで追跡して選抜へ入れない。
取引の帰属はエントリー区分。翌日エントリーが区分外なら未約定として取消。

## コストと集計

往復固定1.4pipsとmetadataの固定spreadの2ケースを計算する。
slippage・commission・swapは0。日足の長期保有で実スワップが無視できるとの主張はせず、
実運用適否には別途、価格配信・日足境界・実行スプレッド・スワップ等の確認が必要。
metadata commissionが有効かつ非0ならこのモデルでは実行を停止する。
net R = (方向*(決済価格-始値)/pip - roundtrip_cost)/初期risk_pips。
固定1Rリスク単位で通貨を比較し、通貨別pipsも保存する。口座換算・複利・実ロットは未定。
同時保有の相関や証拠金を含むポートフォリオ収益を主張しない。

## 選抜・終了

ゲートと期間はprotocol.json。まずtrainingだけ計算・保存。通過候補のvalidationだけ開示し、
両期間通過候補を事前固定の2ルールそれぞれ独立判定する。
選抜ファイルを保存してから、通過候補だけのfinal_confirmationを一度だけ計算する。
候補不通過ならそこで終了して不採用を保存。評価損益を受け取って再調整しない。
比較ルールの損益はtrainingだけ計算する。
過去の研究で同期間は閲覧済み。今回条件での時間順分離は真の未使用holdoutを作らない。
研究者は自分の戦略を採用承認しない。独立検証担当へコード・取引・指紋を渡す。

各区分の全通貨集計closed-net-R最大DDは20R以下、個別通貨は10R以下を要求する。
同時刻決済は合計してからequityへ反映。区分末に時価決済した場合の取引数/PF/平均Rも
感度情報として別掲するが、正式ゲートの未決済除外方式を置換しない。
