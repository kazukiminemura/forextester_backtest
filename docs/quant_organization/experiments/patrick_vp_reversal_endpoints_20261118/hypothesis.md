# 反転条件を実測できる日に判定する

既存の反転条件は04:30〜08:15 JSTの値動きを75分ずつ3区間に分け、売買方向に対して「逆行→順行→順行」かを調べる。各区間の始値と終値だけで式が決まるが、従来は225本の1分足すべての存在を要求した。2026年の現行取引でこの条件を満たすものは通常3/137件、厳しめ1/47件だった。

本試験は計算に必要な6本の時刻を厳密に照合する。欠けた端点の代用は認めず、途中の高値・安値を必要とする現行ルールの直前15分の連続性も維持する。同じ6本を観測できた日だけに限定して方向を問わない対照も設け、記録のある日を選んだだけで生じる差を調べる。候補、時刻、判定基準は [事前仕様](protocol.json) に記録した。
