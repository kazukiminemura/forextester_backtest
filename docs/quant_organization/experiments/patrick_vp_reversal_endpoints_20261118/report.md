# Patrick VP改善案の比較（2026年11月18日）

**研究を続けるなら、3つの75分区間で「逆行→順行→順行」を確認する案を優先する。** 2017〜2025年は3期間・2費用の全6区分で、費用後PFと1取引の平均Rが改善した。現行ルールとの比較でも、6本が観測できた日に絞った対照との比較でも同じ結果だった。2026年追加期間は通常9件、厳しめ3件。現行ルールを置き換えるだけの再現性と取引数は確認できていない。

対象はForex TesterのFX16通貨と、JST 08:15の研究用Patrick VP（逆方向、想定費用は損切り幅の10%以下、VA内、直前15分の最大逆行は順行幅の半分以内）。候補ごとに保有状態を再生し、見送りによって後から可能になる取引も含めた。

## 1取引当たりの改善幅はどこまで絞れるか

6本反転案は通常費用で、現行との平均R差が+0.099R（参考95%区間 +0.015〜+0.186R）。一方、同じ6本を観測できる対照との差は+0.083R（−0.004〜+0.173R）。厳しめ費用でも、この対照との差は+0.062R（−0.080〜+0.216R）。固定した比較期間では反転の向きを見る方が1回当たりの期待値は高かったが、同じ6本を観測できる日に絞った対照との比較では、通常・厳しめともに改善幅の参考区間がゼロを含む。条件ごとに保有状態が異なるため、これは各売買ルールを運用した場合の比較である。

区間は結果確認後の補助分析。2017〜2025年の全16通貨の決済済み取引をエントリー時刻のUTC月曜週で束ね、通貨・条件間で同じ週を同時に再抽出した。取引のない週を含む471週から、連続13週を循環式・復元抽出して471週に切り詰める。NumPyの `default_rng(20261118)` で開始週を10,000組抽出し、取引数で加重した平均R差の2.5・97.5パーセンタイルを求めた。期間端の部分週はそのまま含めた。採用基準は事前仕様のまま。

## 判定の範囲

保存時刻をUTC、1分足価格をBid、保存volumeを週次VPの代理として使った。通常・厳しめのスプレッドは1・2 pips。実際の早朝スプレッドは口座・時刻で変わり、たとえばOANDA証券は原則固定の適用時間を日本時間09:00〜翌04:00と案内している。次の確認に必要なのは、同じ6本反転案を固定して追える未使用期間のBid/Askである。[OANDA証券のスプレッド説明](https://help.oanda.jp/oanda/faq/show/873?site_domain=default)
