# FX SPACE 公開説明からの水平線・押し戻り近似（提案）

状態: SPEC_FROZEN。2026-10-11。損益を見ずに作成した仕様案。
ユーザーは裁量部分の数値化とバックテストを指定し、RR1.5〜2の検証を許可した。
これは公式手法・YTT内部実装の再現ではなく、公開説明の一部を決定的にした新しい研究モデルである。

## 仮説と比較

H1の上昇・下降構造と同方向にM15で事前計画を作り、M5の逆行からの転換後、最初の押し戻りで入る。転換直後よりEntryがSLに近くなれば、次の障害ラインまでのTPを動かさず費用後の利益幅/損失幅を改善できる、という反証可能な仮説。

弱点は押し戻りがそのまま構造崩壊する局面、押し戻りなしの急進、水平線抽出の誤り、値幅に対して費用が大きい相場。取引数が減っただけ・同じRR条件の直後エントリーより期待値が下がった場合も優位性なしとする。

候補は `pullback` の最低許容RR1.5/2.0の2件。対照は同じ環境・同じ事前SL/TPの `direct` を各RRで2件、計4構成。対照は選抜しない。パラメータ探索・失敗後の閾値緩和はしない。固定RRのTPを遠ざける研究ではなく、障害までの事前TPに対する最低RRを判定する。

## データと因果関係

USDJPY/EURUSD/GBPUSDの保存原M1からM5 OHLCを使う。M15/H1はM5から3/12本の完全連続bucketだけで作る。各足の利用可能時刻は足開始+秒数。H1/M15の終端とM5終端が一致するときは、確定したH1/M15をそのM5終端で利用できる。足開始で利用しない。

全足のpivotは左右2本の厳密高値/安値。中心が同値ならpivotなし。右2本の終値時点から利用可能。窓5本が完全かつ連続であること。新しい同側pivotは別の極値として保持し、直近3つの高値・安値を記録する。H1/M15方向は最新2高値・2安値の双方切上げ=+1、双方切下げ=-1、それ以外0。M5方向は既知pivot高値上への終値突破で+1、pivot安値下への終値突破で-1、間では前状態維持。同一足に両条件が成立し得る不整合では0。

判定順は同終端で確定した新pivotを先に追加し、その最新価格と終値を比較する。M5方向更新には前終値が線の反対側だった条件を追加しない。転換イベントだけは前状態−d→現在dを要求する。欠損時はローリング足列とATRをリセットするが、過去の既知pivot・ライン・H1/M15方向は保持し、M5方向のみ0へ戻す。

ATRは完全連続の直近20本TrueRange単純平均。ギャップ直後は前終値を跨ぐTRを使わず、21本連続になるまで未準備。M15帯幅はその時点ATR×0.10、外側余白はmax(1tick,帯幅)。シナリオ成立時の値を凍結する。

ライン台帳は確定M15/H1のpivot水準。8暦日経過・対応足の確定終値が高値線より帯幅上/安値線より帯幅下になれば失効。新規線の帯幅はその足のATR×0.10、最大直近64本/側/時間足。近接（シナリオM15帯幅以内）の同用途線は最新確定時刻を代表とし、強度は群内の最上位足とする。強度はH1=2/M15=1という独自順序で、価格の近さを優先する。ターゲットは進行方向の最近傍障害であり、近い弱線を飛ばして遠い強線を選ばない。

8日expiry起点はpivot確認時刻（known）で、8日ちょうどは有効。各線bandは作成時に固定。近接群は価格昇順で隣接差<=bandなら推移的に結合する。代表tieは確認時刻→上位足強度→低価格を優先する。ATR準備前のpivotは方向履歴に使うがライン台帳に追加しない。

加減速の参考値はH1の同側直近3極値の更新幅の差。上昇は高値差分の差、下降は安値差分の絶対幅の差。ゼロより大/小/等を加速/減速/横ばいとして記録するが取引の追加除外条件にはしない。更新幅の微差閾値=1tick。OHLCからの代理であり注文フローの測定ではない。

## 事前シナリオ

1. M15確定ごとにH1/M15方向が同じ非ゼロで、M15 ATR準備済みなら検討。方向d、最新確定M15逆側pivotをsupportとする（買い=安値、売り=高値）。supportの確定IDは期間内に1回だけシナリオへ使う。
2. SLはsupportの外へM15余白。現在M15終値から進行方向に存在する、未失効M15/H1ラインの最近傍を障害とする。買いTP=障害−余白、売りTP=障害+余白。終値がSL/TPの間にない場合は作らない。障害・SL/TP・余白を固定し、後から遠方TPへ変更しない。
3. 同時シナリオは各通貨1件。作成後24本の連続M5（2時間）まで。作成時刻と同じM5足では成立を認めない。欠損/不完全M5、H1方向不一致、足内のSL到達、TP到達で取消。作成前の条件を遡って成立させない。
4. シナリオ作成後、M5方向が−dからdへ確定終値で変わった足を成立足とする。対照directはその足だけsignal。主案pullbackは成立後最初の連続2本以上の逆色足（d×(close−open)<0）を待ち、その直後の最初の方向足が前足の極値も終値で越えればsignal（買いclose>前high、売りclose<前low）。同値足はrunを0に戻す。最初の方向足で極値更新がなければそのシナリオの主案は失効。成立から12本以内、全体24本以内。逆方向M5転換でも取消。
5. 各armはシナリオ1件につき最大1signal。両armが終了したらシナリオ終了。同足で新規作成や再利用しない。保有制限は約定器で各構成・各通貨1ポジション、保有開始足の再Entryは認めない。

期限境界は作成から24本・成立から12本ちょうどを許可し、それより後で取消。逆色1本の後の方向足はrunを0に戻すだけで待機継続し、連続2本以上の逆色が揃った後の初回方向足だけを判定する。既存シナリオを処理した足では、取消になっても新規シナリオを作らない。

## 約定と全決済

signalの次の連続M5の実始値でだけ入る。signal以前・期間開始以前の待機持越しなし。約定時点で `risk=d*(open−SL)>0`, `reward=d*(TP−open)>0`, `reward/risk >= minimumRR`、通常往復費用/risk<=0.20を再判定。不成立ならそのsignalを失効させ、後続価格を都合よく待たない。費用2倍ケースも機会選択は通常費用基準で固定。

SL/TPは全量・固定。同足両到達はSL優先。飛越し不利は観測始値、TP有利飛越しはTPで頭打ち。保有中のデータ欠損では次の観測始値で強制清算し、TPより有利ならTPまで。不完全足でも観測OHLCでSL/TPを処理し、その後の足終値で清算、観測できない足中経路は不明として記録。最大48本M5の終値、source時計23:55を開始時刻とする最終足の終値、期間最終足終値でも清算。新規Entryは23:55開始足では禁止。実際のブローカー日付/rolloverと同一とは主張しない。

通常往復費用 USDJPY1.6/EURUSD1.5/GBPUSD1.8pips。ストレス2倍。別手数料0はこの合成費用に含める仮定、swapは未計上。tick=0.001/0.00001/0.00001、pip=0.01/0.0001/0.0001。価格水準はtickに保守的丸め（SL外側、TP手前）。

USDJPYだけ円口座補助診断: 初期100万円、各Entryで現在実現残高の0.5%を費用込みrisk予算、25倍notional上限、1000通貨切捨て。含み損益と清算費用込み純資産90万円に対応するstopを通常SLより優先し到達後停止。gapでは90万円以下へ滑り得る。各期間のみリセット、期間内入金なし。他通貨はnetR診断で円合算しない。

期間別口座は各々独立した診断であり、期間resetを跨ぐ成績を100万円の継続運用と呼ばない。最終確認まで通過した選抜1件だけ、別途2020–2025の連続口座を追加し、期間境界で資金リセット・追加入金をしない。学習段階で失敗した場合は後期と連続口座を実行しない。

## 検証と実行規模

学習2020–2022→検証2023–2024→最終2025。全期間は他研究で既閲覧、真の未使用holdoutではない。指標warmupは過去を読めるが、phase先頭でシナリオ・使用support・保有・口座を初期化。学習を通過したpullback候補から最大1件をPF、平均netR、件数の降順、最後はminimumRR昇順で選抜する。検証失敗で別候補へ繰上げしない。

各期間で候補は通常各通貨50件以上・合計200件以上、合計PF_R>=1.15・平均netR>0、費用2倍PF_R>1・平均netR>0、通常2通貨以上が黒字、黒字通貨寄与の最大が70%以下、同RR対照より平均netRが高い、USDJPY通常口座停止なしを満たすこと。勝率はgateに使わない。全通過でも記述的研究であり自動実運用承認ではない。

見込み: 3通貨×約40万M5本/6年、指標計算は通貨ごと1回、学習取引集計は4構成×2費用×3通貨=24runとUSDJPY8口座。各runは線形走査。初期学習だけで終了し得る。実データ件数/manifestとコード・spec SHA固定後に研究責任者が実行可否を判断する。
