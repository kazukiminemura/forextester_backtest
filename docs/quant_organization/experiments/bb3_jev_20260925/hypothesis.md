# Jevによる反転候補の採否研究

仮説：反転候補が出ても、直近の足列・移動平均の傾き・ボラティリティから、持続する逆方向の勢いと回復をJevが区別できる可能性がある。数値データを読む能力や将来の利益は保証されないため、AIなしの同一遅延条件と比較する。

現行のタッチ→反転足→後続足の高安突破は変更しない。Jevは候補を採用/見送り/不明の3択で評価し、採用かつその確率0.5以上のみ通す。確率は勝率ではない。直近12本の正規化OHLC、確定M5の中心線傾き、60本平均からの距離、ATR比を送る。日付・通貨名・未来の足・損益は送らない。判断待ちのため次の次の連続足始値を仮定する。

RR変更は利確を遠ざけず、固定中央線TPに対するSL距離を短くする。RR1の全決済を元の比較対象とする。通知・一覧・文字サイズ・現行Pineは維持する。

500円は上限であり使い切らない。公式価格0.042 USD/100万入力token、出力無料を確認。1試行ごとモデル最大文脈65,536token分を事前引当し失敗でも戻さない。累計2.30 USDで停止（200円/USDで460円、残り40円余裕）。推論結果を保存して再利用し、自動再試行しない。実際の請求・税・換算手数料はサービス側の明細で最終確認する。

2023〜2025年は既に他の研究で閲覧済み。2023年のみでRRを1つ選び、2024/2025を確認するが、独立した未使用期間とは呼ばない。勝率だけ改善し件数や利益が悪化した案は採用しない。不合格で探索を終了し、条件を後付けして合格を作らない。
