# Jev × BB反転確認：2023–2025比較

## 結論

**採用しない。Jevの全候補判定は未完了で、確認済み範囲でも収益改善を立証できなかった。現行Pineは変更していない。**

828候補中811件へ実際にJev APIを呼び出した。808件が応答検証を通過、562件を採用候補と判定、246件を見送り。残り3件の応答が固定した検証ルールに合わず、事前の3失敗停止条件で追加送信を停止。17件は未送信。失敗と未送信はエントリー不可として以下を集計したため、完全なJev比較ではなく部分結果である。

失敗3件は通信失敗ではない。1件は選択されたacceptの確率0.45に対してskipが0.46で最大確率との不一致。2件は小数2桁の確率合計が0.99となり、固定許容誤差0.001を超えた。この2件は丸めによる可能性がある。元応答を保存し、成績を見て許容条件を緩めたり再送信したりしていない。

未送信17件はすべてNZDJPYの処理末尾に偏る。ランダムな欠測ではなく、部分結果から完全実行時の成績を推定しない。
