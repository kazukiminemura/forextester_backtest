# 円クロス限定の追試

ユーザー依頼により対象通貨だけを変更する。直前実験quant70_intraday_20260908の12候補・12比較と単純基準をそのまま使用し、シグナル、日付定義、RR1全決済、約定、コスト、期間は変えない。仮説は同一JPYクオートの通貨群では当日状態ゲートの有効性が異なる可能性。反証条件は学習・検証の絶対ゲートまたは対応比較ゲートの不合格。

対象はAUDJPY・CHFJPY・EURJPY・GBPJPY。USDJPYはドル円として除外。NZDJPYはローカル履歴が2018年4月だけなので期間不足で除外。CADJPYはローカルにない。銘柄の成績を見て選別しない。

利益通貨数条件のみ旧8/11と同等以上の割合としてceil(8/11×4)=3/4へ変更する。勝率70%、PF1.5、正の期待値、母数・頻度・DD・対応比較に対する改善などは維持。円クロス間の相関があるため4通貨を独立な検証4回とは扱わない。

詳細ロジックは ../quant70_intraday_20260908/hypothesis.md、固定実装は scripts/quant70_intraday_signals.py。完了済み前日・ADR20・序盤レンジと、その時点までの当日情報だけを利用する。閲覧済み履歴であり真の未使用評価とは呼ばない。合格なしの場合は2023年以降の確認期間評価やPine移植に進まない。
