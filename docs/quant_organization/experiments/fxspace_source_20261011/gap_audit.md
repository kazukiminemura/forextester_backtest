## 再現前に固定する5項目

1. **ライン**: 極値抽出・確定遅延、複数時間足、近接線の統合と失効、チャネルの起点・平行位置。Web説明には内部アルゴリズムがないため不明。
2. **シナリオ**: どの時間足・ラインを根拠に方向を選ぶか、上位の逆圧力への見送り、無効化価格。D/W一致を必須とする証拠は今回の公開ページでは得られない。
3. **押し目**: 予約前の順序付き到達条件と、構造判定の押し目triggerを別定義にする。価格到達と終値確定は同一にしない。
4. **trigger**: 転換または押し目の認識時点・時間足、RR判定との組合せ、同一足で複数条件を満たす順序。原典の不明部分は追加仮定として凍結する。
5. **SL/TPと費用**: 根拠ライン外・次ライン手前の具体余白、成行時RR再計算、無効化、保有中の変更、gap・同足TP/SL・費用。固定RRは公式ツールの選択機能であり、全取引1Rの強制ではない。[RR比固定](https://fx-space.com/intro/ytt-web-f-trade.html)
