## 実装前に必要な確定事項

1. 波形の高安と方向転換: 対象波の大きさ、判定価格、確定時刻、同値、ピボット遅延。
2. 注目ラインと環境: アンカー選択・削除・帯幅、上位足組合せ、方向不一致と到達時の判断。
3. エントリー: タイミング足、転換と押し目の使い分け、確定後か足中か、期限と崩壊条件。
4. 決済: 具体的なTP/SLの置き方、ライン到達と転換の優先度、部分決済・建値・時間決済の採否。
5. 検証: 公開説明と機械化の仮定を別項目にして事前固定。RR1/1.5/2を比較する場合はユーザー指定の検証候補であり、公式の固定決済規則とは表示しない。
