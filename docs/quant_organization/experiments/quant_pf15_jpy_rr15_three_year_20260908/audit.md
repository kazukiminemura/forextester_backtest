# RR1.5の単独担当照合

実走exit0、DESCRIPTIVE_COMPLETE。70テスト通過。286,042保存明細を別計算式で全条件・通貨・月・年にわたり照合済み。
1.5R目標の幾何、コスト後R、時計窓、次足、期間境界、非重複、候補抽出判定を確認。
新エンジンをRR=1へ戻した旧処理との一致テスト10シード、買い/売りのRR変更による出口反転テスト、無効RR拒否を含む。
凍結コード指紋・文書プロトコル・元履歴実行前後属性一致。候補・時間帯・日時・スクリーニング条件は前回と一致。
サブエージェント不使用。独立担当者による監査とは呼ばない。

個別30件以上PF1.5達成はEURJPY3条件。各年損益正だが、3年53〜77件で取引頻度基準未達。
数値達成と実運用採用を区別する。限界・詳細・再現手順はvalidation.md参照。
