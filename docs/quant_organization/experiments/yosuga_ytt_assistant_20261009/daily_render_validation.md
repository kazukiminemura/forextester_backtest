2. 候補監視線も翌バー番号からその次のバー番号へ、候補ラベルも同じ起点へ変更。確定前の過去バーへ戻して描く変更ではない。価格値・確定終値cross・上位2足合意・消費済みpivot管理は前回の確認条件を維持する。
3. チャネルの現在基準価格は `p2 + slope * (time_close - t2)` を維持。翌描画点は `nowBase + slope * timeframe.in_seconds() * 1000` で、将来1バーを標準時間幅として近似する。平行線は両端へ同じwidthを加えるため平行。休場・休日を含む実際の将来経過時間との同一性は保証されず、その制約はtooltipに明記されている。
4. 自動描画の将来座標は+1/+2だけ。配列保持上限・描画オブジェクト上限を増やす変更はない。価格描画の全constructorに `force_overlay=true` が維持される。
5. 手動シナリオの `scenarioTime` / `time_close` による時刻座標、手動算術・入力、成立イベントの時刻ラベルは従来どおり。確定上位足の全成分 `[1]` と `lookahead_on`、異なる2足を現足より厳密に長くするガードも維持。
