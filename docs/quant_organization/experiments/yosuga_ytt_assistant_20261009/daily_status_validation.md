## 独立確認

1. `dailyAutoContext` は既定ON。`timeframe.isdaily` かつONのとき実効足を1W/1Mへ変更し、OFFまたは日足以外なら手動指定を維持する。取得・秒換算の厳密な上位足／異なる2足の判定・候補見出しが同じ `effectiveCandidateTf1/2` を参照する。日足以外の既定値は1D/1W。
2. 月足も既存 `f_context` を使用。上位足取得は全成分 `[1]` と `lookahead_on`、同足は確定値、下位足は無効。形成中の月足を新たに判断へ使う経路はない。
3. 方向2つと高安4つが揃わなければ候補成立を抑制し、「データ不足」「上位足の確定高安データ不足」を表示する。高安が揃っていても方向0、方向不一致では「見送り」。上位2足の方向が両方+1または両方-1のときだけ方向合意となる。
4. 事前の確定pivotを使う終値cross、確定足限定、上位足不一致でも突破済みを記録する消費処理、同価格を含む新pivotでの更新、候補配列上限20、描画位置・削除処理は維持。高安4値の準備条件は追加されたため、以前は方向が±1でも片側pivot不足の初期履歴で成立し得た候補は、現在抑制される。したがって候補集合が完全不変とはしない。
5. 左下表は4列12行、使用行0〜11。月足row1、週足row2、日足row3、末尾注記row11で容量内。候補表は2列6行のまま。月足名は「月足」で、数値の分足表記と区別される。
