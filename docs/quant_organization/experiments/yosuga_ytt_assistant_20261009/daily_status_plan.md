# 日足の状態確認

2026-10-09。ユーザー依頼「日足時に状態を確認できるように」。日足でD/W既定はstrict上位条件に反するため設定不正になっていた。

1. 日足では週足・月足へ自動切替する設定を既定ONで追加。OFFなら既存の指定足を使用。日足以外は指定足を維持。
2. 月足の確定状態を左下へ追加。候補の取得・妥当性・表示には同じ実効時間足を用いる。候補の終値突破・再追随防止は維持。
3. 主担当が構造テスト、SMR日足の最終TradingView本文照合・表示、15分で既定D/W維持を確認。Pine担当はPineのみ、独立検証担当はdaily_status_validation.mdのみ編集。

上位足が不一致なら見送り、履歴不足ならデータ不足と表示する。成立を無理に作らない。既存描画修正・未採用研究結果を保持する。
