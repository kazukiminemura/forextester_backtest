# 突破候補表示の追加計画

2026-10-09。ユーザーが最重視するのは「どの価格を突破すればトレードチャンスになるか」。上位足の方向が揃った場合のみ候補を表示する案をユーザーが選択した。

目的は既存分析補助の価格表示を使いやすくすること。新しい収益性研究や自動発注は行わない。公式YTTの数値ルール未取得という制約を維持し、2上位足の一致条件は今回の補助フィルターと明記する。

## 固定仕様

1. 上位足の既定はH1/H4。両方が現足より長く、互いに異なる設定を必須とする。上位確定値のみを使用し、途中足は方向判定へ入れない。
2. 両上位足が上昇なら買いだけ、下降なら売りだけを監視。不一致・未判定・データ不足・無効な時間足設定では成立させない。
3. 現足の直近確定ピボット高値が買いの突破価格、安値が売りの突破価格。現在の足の終値が厳密に上回る/下回ることを要求し、等値・ヒゲ・未確定足では成立させない。
4. イベントには現足の更新前の確定高安を使用。同足で新ピボットが確定しても突破対象を取り違えない。突破済みピボットは使用済みとして記録し、戻って同価格を再突破しても候補を繰り返さない。上位合意がない間の突破も使用済みにする。新しい確定ピボットが出た場合だけ解除する（価格が同じでも検出時刻が異なれば別ピボット）。
5. 価格付き監視線・ラベル、右上の状態表、確定候補成立ラベルとアラート条件を追加。すべての価格描画でforce_overlay=trueを維持。表示された候補は売買推奨や検証済みの優位性を意味しない。

## 分担

主：仕様・統合・TradingView実UI確認・記録。Pine：Pineとガイドの追加仕様。独立検証：境界条件の独立検算、ソース監査、検証記録。品質監査：最終証拠レビュー。関連外の既存変更を保持。
