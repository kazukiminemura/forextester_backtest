# Sniper VIP 機能再現・独自ロジック

対象はSNIPER-AI作者の [SNIPER AI VIP PRO](https://www.tradingview.com/script/iWYyOBPG/)。公開説明を参考にした独立実装であり、元のソース、パラメーター、学習済みAIモデル、売買判定の複製ではない。作者との提携はない。

実装ファイル：[`sniper_vip_pro_reconstruction.pine`](../scripts/tradingview/sniper_vip_pro_reconstruction.pine)

## 実装前の方針

目的はTradingView上で公開機能に近い分析表示を使えるようにすること。新しいWebアプリや外部AIサービスは不要と判断し、既存の戦略を変更せず、独立したPine v6インジケーターにする。

1. 判定を共通関数に分離し、チャートと時間足別パネルで利用する。
2. 価格追跡と描画を分離し、過去に提示した目標を残す。
3. 需給ゾーンとFVGの生成・終了を管理し、描画数を制限する。
4. 未来データの参照、同一足の曖昧なTP/SL、下位足の扱いを点検する。

## 機能と再現範囲

| 公開されている機能 | 独自版の実装 |
| --- | --- |
| トレンドとフィルターによる売買サイン | Supertrend・EMA・RSI・DI/ADXの条件成立時 |
| ATRによるSLと3つのTP | サイン確定終値を基準に価格ライン・ラベルを表示 |
| TP到達後の目標再計算 | 設定で有効化。到達した旧目標と確定終値から3目標を前進 |
| 需給ゾーン | 確定ピボットとATR厚みによる近似。実注文の分析ではない |
| FVG | 3本の足の高安間ギャップ。全埋めで終了 |
| トレンドライン | 最新2つの確定高値・安値を接続 |
| 時間足別方向・最新サイン・高安 | 5分・15分・1時間・4時間・日足の方向、最新候補と価格・時刻、確定高安 |
| 高安接近の青いマーク | 現在値が各時間足ATRの設定幅以内なら青い● |
| 逆方向の警告 | 追跡中の反対候補、採用サインとEMA方向の不一致を表示 |
| 強いサインの紫色ローソク足 | 採用サイン、方向一致、ADX強度、実体のATR比で判定 |

元と同じサイン・外観・成績を保証するものではない。時間足別の支持・抵抗価格はパネル表示であり、全時間足の水平線はチャートに描かない。元の「AI」の具体的な方式は公開説明から確認できないため、学習やAI確率を装う表示は設けていない。

## 使い方

1. TradingViewにログインし、時間ベースの通常ローソク足チャートを開く。
2. Pineエディターで新しいインジケーターを作り、実装ファイル全文を貼り付ける。
3. 「チャートに追加」を実行する。初回の表示確認には15分足を使用できる。
4. 設定の「1. 売買判定」「2. Entry・SL・TP」「3. 描画」で調整する。
5. 必要ならアラートでBUY、SELL、TP到達、SL到達、方向警告を選び、「バーの終値ごとに1回」に設定する。

平均足・練行足などは実価格と異なるため、このスクリプトは通常チャート以外でエラーを表示する。推奨パラメーターを実績検証したものではない。

## 売買判定

買い候補は次の条件がすべて成立し、その条件の組み合わせが前の足では成立していなかった場合。売りは上下を反転し、RSIを48以下とする。

- Supertrendが上昇方向（ATR 14、倍率3）。
- EMA方向フィルターが有効なら終値がEMA 100より上。
- RSI 14が52以上。
- ADX 14が18以上、DI+がDI−より大きい。

チャート上の採用サインは足確定時のみ、追跡がない状態で発生する。採用サイン同士は既定で5本以上離す。追跡終了足での再エントリーはしない。追跡中や間隔制限で見送った候補を後から採用し直すことはない。反対候補で現在の追跡を反転させない。

紫色は採用サインの足で、EMAとSupertrendの方向が一致し、ADXが下限+7以上、ローソク足実体がATRの0.5倍以上の場合。

## Entry・TP・SLの意味

これは注文を出すストラテジーではなく、価格到達を追跡するインジケーター。Entryはサイン足の終値で、約定価格ではない。スプレッド、滑り、手数料、分割決済数量、損益・勝率は計算していない。

既定はSL=1.5 ATR、TP1=1 ATR、TP2=2 ATR、TP3=3 ATR。買いは上にTP・下にSL、売りは逆。最小ティックへ丸め、TPの順序と最低1ティック間隔を確保する。倍率がTP1 < TP2 < TP3でなければ明示的にエラーを出す。

- **固定モード（既定）**：サイン時ATRで全目標を固定。TP1/TP2は到達記録で、TP3またはSLで追跡終了。
- **目標前進モード**：「TP到達後に3目標を前進」を有効にする。到達した最も遠い旧目標と確定終値のうち利益方向に進んだ価格を起点に、その足のATRで新しいTP1～3を作る。新目標は次の足から判定。SLは元の値に固定し、SL到達まで追跡を継続する。元製品の非公開更新式とは一致を保証しない。

サイン足の高安を後付けで利確・損切り判定に使わない。判定は次の足から開始。同じ足がSLとTPの両方に触れた場合、OHLCだけでは順番が確定できないためSLを優先し、その足のTP到達を記録しない。窓開け時もラベルは参照水準を表示し、約定価格を表さない。

価格ラインは既定25セット、最大60セットを保持する。前進モードの目標更新も1セットとして数える。売買・到達イベントラベルは直近75件を保持。保存上限を超えた古い描画は削除する。

## ゾーンと時間足別データ

ピボットは既定で左右5本。需要は確定安値から上へ0.4 ATR、供給は確定高値から下へ0.4 ATRの厚みを持つ。ATRはピボット足の値を使う。ゾーンは確認できた足から描く。トレンドラインだけは確定後に実際のピボット位置へ接続するので、ピボット当時から見えていた線ではない。

需要の下端／供給の上端を終値で突破すると終了。FVGは上昇なら現在安値 > 2本前高値、下降なら現在高値 < 2本前安値で生成し、最小幅は0.1 ATR。ヒゲが遠い側の端まで達すると全埋め終了。途中まで埋まったFVGの幅は縮めない。終了したゾーンは灰色で残し、既定300本で期限終了。生成直後のゾーンは次の足から終了判定する。需給/FVGは表示専用で売買条件に含めない。

上位足は全フィールドを1本遅らせた`request.security(..., lookahead=barmerge.lookahead_on)`で確定済みデータを取得。同一足は現在足の確定値、未確定なら前足の値を表示。チャートより下位の時間足は「下位足・対象外」と表示する。例えば15分足では5分行は対象外。全5行を見るには5分足以下の時間ベースチャートを使う。

パネルの「最新候補」は各時間足のフィルター成立を記録したもの。チャートの追跡状態と間隔制限を適用した「採用サイン」とは異なるため、そのままエントリー一覧や成績として使わない。候補確定時刻は銘柄の取引所タイムゾーンで表示する。青い接近マークは現在値に追随するため、足の途中でも変化する。
