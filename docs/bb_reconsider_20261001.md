# BBトレード再検討：頻度とコストの診断

2026-10-01。対象は保存されている `bb3_reversal_confirmation_indicator.pine` の既定値。ユーザーが実際に使用中の別スクリプトや変更した入力設定の診断とは区別する。Forex Tester由来の保存済み2020–2025年・7通貨・5分足を再利用した記述分析で、条件変更や新戦略の採用は行っていない。

## 分かったこと

±3σタッチは105,845足あり、全3,139,023足の3.37%。連続するタッチは独立した取引機会ではないが、「3σタッチ自体が極端に少ない」だけでは低頻度を説明できない。

|段階|7通貨・6年の件数|
|---|---:|
|±3σにタッチした足|105,845|
|待機中ではなく準備判定まで進んだタッチ|99,645|
|見送り条件を通過して準備開始|18,182|
|後続の陽線・陰線でバンド内回帰を確認|10,269|
|取消条件を通過し、後続の厳密突破まで到達|7,610|
|参考価格から前足中央線まで3pip以上の候補|1,658|
|次足始値で約定し、決済した仮想取引|1,225|

準備判定時の排他的除外は勢い70,996・長いヒゲ9,981・両側タッチ486。準備後取消は10,572件で、高安更新9,167件（86.7%）、期限切れ120件。優先順で分類した原因なので、あるフィルターを外せば同数の取引が増えるという意味ではない。報告期間境界をまたぐ準備とイベント数にも注意する。

突破判定に到達した7,610件のうち5,952件（78.2%）が参考価格の中央線幅不足で消える。候補1,658件の後にも保有中1件、次足欠損2件、実際の次足始値で幅不足430件があり、最終的に1,225決済になる。1通貨当たり平均月2.43回、7通貨合計月17.01回。

## 収益の問題

既存の全決済RR1・仮定の往復1pipを再計算すると、勝率50.20%、費用後PF_R0.708、確定損益−212.28R。費用前は+14.92R、PF_R1.024に留まり、費用負担227.20Rが上回る。平均の費用前値幅は+0.2815pip、費用後−0.7185pip/取引。R換算の平均費用は約0.1855R/取引。

中央線まで3pipの取引では往復1pipは予定利益幅の1/3。対称の±3pip決済だけを仮定すると費用後は勝ち+2pip・負け−4pipで、損益分岐勝率は66.7%。これは説明例であり、この履歴全体の必要勝率や実約定成績ではない。

## 次の比較案（いずれも未実装・未検証）

以下は確定した次実験仕様ではなく、主担当が整理した設計候補。優先順位は反転確認後の前倒し比較を第一とする。勢い解除を初期準備だけへ適用する独立担当案と、準備中の取消にも適用する研究担当案は異なるため、次実験を凍結するときに適用段階を明示し、混同しない。M15は別の時間足比較候補で、今回の診断では実走していない。

1. **反転陽線・陰線の確定で次足始値へ進む案。** BB3準備・既存文脈除外・高安取消は保ち、追加の高安突破待ちだけを除く。残りの中央線幅を確認する。確認の遅れで利幅を失う仮説を一要因で検証する。
2. **勢い除外だけを外して効用を比較する案。** 他の見送り・高安取消・反転確認・突破条件は保ち、高安/節目突破の勢い条件だけを外す。戻る局面を余計に除外しているか、強いトレンド中の逆張り損失を防いでいるかを比較する。見送りの多さはフィルターの無効性を証明しない。
3. **15分足へ変更し、同じ反転確認骨格を比較する案。** 元M1から足とBB・ATRを新規集計する。予定利幅に対する費用割合を下げられるか調べる。時間足を上げるとタッチ回数は減る可能性があるため、取引数増加を保証しない。

新しい比較は別ID・事前固定の仕様で行い、費用後PF、平均R、月間件数、期間別・通貨別収益を同時に見る。既閲覧の2020–2025年を真の未使用検証と呼ばない。±2σに広げるだけの旧案は六年PF_R0.770で不採用だったので、同じ案の再探索は優先しない。
