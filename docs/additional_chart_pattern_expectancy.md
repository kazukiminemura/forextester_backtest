# その他の既知チャートパターンの期待値検証

## 結論

三角持ち合い、長方形、ウェッジ、フラッグ、トリプルトップ／ボトムを
一般的な構造と終値ブレイクで検出し、14銘柄・15分足・RR 1:1で検証した。
学習期と検証期の両方で期待値がプラスになった共通候補は0件だった。

## 一般定義の実装

- 上昇三角: 水平な上値抵抗と切り上がる安値。上値終値突破で買い
- 下降三角: 水平な下値支持と切り下がる高値。下値終値突破で売り
- 対称三角: 切り下がる高値と切り上がる安値。先行トレンド方向へ終値突破
- 長方形: 平行で水平な支持・抵抗。先行トレンド方向へ終値突破
- 上昇ウェッジ: 上向きで収束する2境界。下値終値突破で売り
- 下降ウェッジ: 下向きで収束する2境界。上値終値突破で買い
- ブル／ベアフラッグ: 2～3 ATR以上の旗竿後、短い逆向きまたは水平の平行チャネルを旗竿方向へ終値突破
- トリプルトップ／ボトム: 近い価格帯の3頂点・底と2つの谷・山。ネックライン終値突破

三角形、長方形、ウェッジの構造とブレイク待ちは
[IG Academy](https://www.ig.com/en/ig-academy/the-basics-of-technical-analysis/basic-chart-patterns-part-two)に、
旗竿と短い平行チャネルからなるフラッグは
[CMC Markets](https://www.cmcmarkets.com/en-gb/technical-analysis/flags-and-pennants-in-trading)に沿っている。

## 共通検証条件

- 各境界線は最低3つの確定スイングで作成
- ヒゲ突破ではなく終値突破後の次足始値でEntry
- SLはパターン反対側の境界または否定位置の外側0.10 ATR
- TPはSLと同距離の1Rで全量決済
- 同一足でTP・SL双方へ到達した場合は損失
- スプレッド込み、1銘柄1ポジション
- 数値候補は2010–2018と2019–2022だけで選択
- 2025–2026の終端は2026-07-31
