# 日足FXアルゴリズムの再設計結果

依頼: 「今までの考えを捨ててもいいので勝てるアルゴリズムを考案」。3x3、Double Repo、ダウ決済、固定RR1の前提を解除して研究した。

現時点で、安定して勝てるアルゴリズムは確立できていない。基本の順張り押戻りは学習合計が黒字になったが、期間別安定性・保有費用への耐性が不足した。第一の9候補と第二の3候補をすべて保存し、不合格の候補を後の期間に進めていない。

## 設計した最良候補: 長期方向に沿った押戻り回復

確定日足を使う。ロングは終値がSMA200より上、かつSMA200が20本前より高いことを条件に、前日の終値がSMA20−0.5ATR20以下から当日の終値がその水準より上へ回復したら翌日足の始値で買う。ショートは対称。

- 初期SL: 約定始値から2×シグナル日のWilder ATR20。
- TP: 初期リスクの3倍の値幅で全決済。
- 保有期限: エントリー足を1として30本目の終値で決済を予約し、31本目の始値で全決済。
- 1通貨1ポジション。日足内でSL/TP両方に触れればSL優先。不利なSL窓開けは始値約定。

これは採用候補ではなく、今回最も良かった研究用の仕様である。

## 数値による判定

15通貨、2010–2018年。2009Q4から250観測足の共通ウォームアップ。往復1.8pips（滑り0.4pipsを含む）と仮定の保有費用0.2pip/暦日を控除。Rは各取引の初期損切り距離による正規化値で、実口座の利回りではない。

|方式|取引数|コスト後PF|損益R|日次含み込み最大DD R|
|---|---:|---:|---:|---:|
|中期ブレイクの最良 trend55|603|0.8830|−39.94|61.47|
|順張り押戻りの最良 pullback05|706|1.0652|+25.71|43.48|
|レンジ回復の最良 range15|553|0.8834|−21.64|24.98|
|過去60か月で毎月通貨を選ぶ追試|212|0.9536|−5.79|19.74|

押戻り基本の勝率は40.23%。学習3区分の損益は2010–2012年 +4.42R、2013–2015年 +27.37R、2016–2018年 −6.08R。最後の区分は含み込みでも−9.57R。保有費用を仮に1pip/暦日へ増やすと全期間PF0.8570、−62.47Rとなる。

比較用SMA200クロスを含む第一実験は10ルール（採用対象9）。押戻りの深さ0.5/1/1.5ATRの3設定はいずれも学習合計黒字だったが、事前のPF・通貨横断・DD・3区分黒字基準を満たさない。

第二実験は第一学習結果から設計した追試。仮想売買の過去確定成績から毎月最多5通貨を選び、最大5ポジション・同じ構成通貨を含むポジション最大3本に制限した。参照期間24/36/60か月の全3設定が赤字となった。月次順位に将来成績を入れない実装でも、第一の学習結果を見て基本ルールを選んだ設計上の選択バイアスは残る。

第一protocolの追加探索禁止に従い、第一の候補・基準・凍結結果は変更していない。第二はユーザーの全面再設計依頼の範囲で、第一の結果を受けて別ID・別事前仕様として開始した追試である。第二の3候補を最後の追加予算と定めたため、今回の探索はここで終了する。研究手順の終了は、依頼された収益性の目標達成を意味しない。

両実験とも選抜0。2019–2022年の検証、2023年以降の最終確認は、事前の段階的選抜手順に従って未評価。後半の収益性について結論は出していない。12候補の不採用は、すべてのアルゴリズムが不可能という証明でもない。
