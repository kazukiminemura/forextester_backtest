# 夜間の取引頻度とRR1収益性

2026-10-07。目的はForex Tester由来の保存データでロジックを吟味し、「日本時間の夜に全通貨合計2〜3回」の利用条件との適合を確かめること。状態は `VERIFIED_REJECTED_CONDITIONAL_CLOCK / AUDITED_REJECTED_DESCRIPTIVE_CONDITIONAL_CLOCK`。結果前に仕様を凍結し、全630ケースと独立参照実行が終了コード0で完了した。主担当の関連46テストも成功。条件付き研究として引渡し可能、全案不採用。実際の日本時間への適合は時計証拠不足で未確定。

## 結果の要点

主仮定では条件の少ないBB反転で夜平均約2.5〜2.7回を作れたが、勝率約48〜50%、費用後PF約0.68〜0.72と赤字だった。レンジ条件は頻度を下げるだけで明確な採算改善なし。H1順行の中央線回復は約10回と多いが赤字。今回の固定2候補と比較対象は、全4時差仮定で学習・検証の同時screen不通過。採用はしない。

これはGMT0をsource時計と仮定した結果であり、実際のJST夜間成績の確定ではない。実時計・DSTと19〜24時の利用枠は未確認。

### 回数と利用しやすさ

主仮定のM5完全観測夜は765/783、510/522、257/261（順に前期・中期・2025）。比較対象BBの0件夜率は8.89%/12.94%/7.39%、2件以上の夜は71.11%/65.29%/67.32%。毎夜2〜3回を保証する結果ではない。

同じ5分開始時刻に複数通貨の約定が重なる。同時刻を一つの監視機会にまとめると比較対象BBの平均は2.17/1.97/1.97回まで減る。これはリスクの独立性を証明する集計ではない。

比較対象は10/3 Stage Bの文脈・ヒゲ除外なし反転足方式であり、現在の厳格なPineの頻度ではない。条件を減らして回数を増やせることと、利益が残ることを混同しない。H1案は週末欠損後に25連続完全H1を要求するため月曜などの無取引夜があり、平均約10回を毎夜10回と解釈しない。

GMT0では全方式、学習・検証の双方で利益通貨0/7。別の固定時差仮定で一部微益があっても、頻度/観測率/PFの固定screenを通過せず、時計を利益で選んで採用しない。

### 費用だけの問題ではない

学習・検証の費用前Rは、比較対象BBで−67.67/−56.75、レンジBBで−20.48/−28.16、H1順行で−150.36/−202.76だった。主仮定ではスプレッドを下げるだけで両期間を黒字にできるという根拠も得られなかった。2025レンジBBの費用前+7Rだけを選んで採用しない。

完全観測夜はM5開始時刻がそろったことを表す。構成M1まで全通貨完全な夜は596/406/229に減る。OHLCだけの検証であり、実際のtick経路やGMO約定を確認した結果ではない。

夜は新規エントリー時間だけを制限し、決済は夜外も継続した。検証期の0時後保有率は比較対象BB8.50%（境界不確実を含め10.06%）、レンジBB6.30%（7.64%）、H1順行5.41%（7.43%）。夜中に必ず終了するルールではない。主仮定の最長保有は1,139観測M5本、スワップ未実測。

既存FX7通貨の2020–2025年M5を使用。既不採用のBB反転確認を比較対象に、レンジ限定BB反転と、確定H1方向に沿うM5中央線回復の2候補を事前固定する。全決済RR1、通常往復1pip・ストレス1.2pipは仮定であり、GMOの歴史的実費用ではない。

夜窓は19:00以上24:00未満を暫定値とする。保存時計は未確定のためGMT0主仮定、GMT+2/+3/+9の固定感度、時刻制限なし参照を別々に示す。時差を好成績から選ばず、条件付き結果を日本時間実測と呼ばない。実際の時差・DSTと利用時間の確認は別の未完了要件。

## 今回の判断

この固定2候補の研究は不採用として終了する。平均機会数だけなら増やせるが、頻度と費用後利益を両立した戦略は得られなかった。現在のPineを未合格案へ変更しない。
