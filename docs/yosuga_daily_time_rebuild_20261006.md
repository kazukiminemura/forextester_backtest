# よすが機械近似：日と時間の取引休止

日・時間の休止を追加したPython研究ロジックを実装。29テスト成功、168ケース実走は終了コード0。学習期間の選抜0で、運用採用・Pine移植は行わない。独立全再計算はALL_MATCH・終了コード0。

## 取引する日

前カレンダー日の方向効率（始値から終値までの変化の絶対値 / 高値−安値）が0.30以上の場合、前日の上昇なら買い、下落なら売りだけを許可する。弱い方向性・同値・値幅0・前日のデータ品質不足は新規取引を休止する。週末を飛ばして金曜を月曜の前日として使わない。

品質条件は保存M5で観測270本以上、完全260本以上、最初の足開始00:30以内、最後の足開始23:25以降、開始時刻間隔30分以下。全足完備ではなく、欠損値動きが日高安を歪める可能性が残る。

## 取引する時間

シグナル確定までの直近12本M5が連続・完全であり、同じ方向効率が0.30以上、シグナル方向と一致するときだけ新規取引を許可する。往復費用 / 初期SL幅が20%を超える候補は見送る。費用比は確定終値でまず判定し、次始値でも再判定する。

特定の曜日・時計の枠を過去成績から選んでいない。時間の許可は直近1時間の状態に応じて変わる。

## エントリーと決済

10/3モデルのM15転換→リテスト→M5転換→確定押し戻り→突破確定→次始値入場を維持する。SLは構造外、TPは実際入場から1R、全決済、建値・追従なし。日次方式ではシグナル足開始日と入場日が異なる23:55→00:00候補を見送る。休止は新規取引だけに適用し、保有中は元SL/TPを維持する。

## 比較と制約

baseline / daily / hourly / combinedを固定比較。2020–2022だけで最大1方式選抜し、2023–2024と2025は条件を変えず記述的診断する。全期間既閲覧であり未使用holdoutではない。通常費用と1.5倍費用では費用比ゲートにより入場集合が変わり得る。

保存時計のUTC/JST対応は未確定。日本時間や東京・ロンドン開始として扱えない。本研究はよすが式全体・最新裁量ルールの再現ではない。

仕様: `docs/quant_organization/experiments/yosuga_daily_time_20261006/protocol.json`。

## 独立確認と表示の範囲

独立担当は新gateを別実装し、168ケース・875取引観測（方式/費用重複）・2,280台帳行・旧baseline42ケースの取引/台帳/MTM・168prefix・24集約/CI/選抜を照合しALL_MATCH。独立信号referenceは10/3に独立検証済みの保存候補を再利用し、今回新たに原典信号を全件再構築したとは扱わない。合成96ケースと29testsでも会計・因果境界を確認した。

新規約定日の数はgate許可日の数ではない。観測日はM5が1本以上ある保存時計の日付で、日曜部分日を含み市場営業日とは違う。休止理由は候補の最初の拒否理由の排他的集計であり、全時間帯の休止割合ではない。

最終監査はAUDITED_REJECTED_DESCRIPTIVE、不採用研究として引渡し可、未解消の重大実装不一致なし。監査担当の集約672数値・baseline42ケース照合も一致。監査詳細は実験ディレクトリの`audit.md`、独立証拠は`agent_runs/yosuga_daily_time_20261006/independent/verification.json`。研究用実装として引き渡し、利益を確認した戦略としては採用しない。
