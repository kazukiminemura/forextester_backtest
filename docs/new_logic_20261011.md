## 今回の計画

1. 15分足の価格圧縮から外へ出た後、初回の押し戻りが境界を維持する構造。
2. 15分足のレンジ境界を一時的に超え、確定足で内側へ戻る失敗突破の構造。

USDJPY・EURUSD・GBPUSDの保存履歴を使用する。ユーザーの明示回答により全決済RR1 / 1.5 / 2を比較する。最大2案×3RRと対応する単純対照を事前固定し、結果後のパラメータ再探索を行わない。

採用前に実現payoff（費用後平均利益÷平均損失の絶対値）、PF、平均純損益R、通貨別件数、費用2倍、最大DDを確認する。資金100万円・元金損失10万円停止は引き継ぐ。円口座はUSDJPYの実価格数量モデルのみで診断し、3通貨の単純R合算を円ポートフォリオと扱わない。

2020–2025は既閲覧。source時計・価格side・実bid/ask・スワップの制約があるため、研究判定を実運用利益や月利5%の証拠にしない。正式仕様・品質・結果・独立検証は `docs/quant_organization/experiments/new_logic_20261011/` に保存する。

## 初回の固定条件結果

最終判定 `AUDITED_REJECTED_DESCRIPTIVE`。独立品質監査で凍結SHAと実行順・価格差損益・円曲線・月別指標が一致。不採用研究として完了し、現行Pineの売買条件へは追加しない。

独立検証は96 CSV・444重複を含む取引観測・9つのprefix・全イベント/会計/選抜判定を再現して一致。`validation.md`に再現方法を記録。低頻度の主因は、費用を損切り幅の10%以下に抑える条件でリテスト44信号中40、失敗突破1,677信号中1,506を除外したこと。狭い構造SLと取引費用が両立しない機会が多く、今回の15分足仕様には頻度上の限界がある。

2020–2022の学習診断は正常終了。6候補の選抜は0件で、事前規則に従い2023–2025への実行を止めた。結果後に条件を緩和していない。

通常の仮定往復費用を控除。PF_Rとpayoff_Rは各取引の初期リスクで正規化した純損益Rから計算し、金額ベースの円口座PFとは区別する。実現payoff_R＝正の純損益Rの平均÷負の純損益R平均の絶対値。設定RR2でも時間決済や費用で実現値は低下する。

圧縮後リテストはUSDJPY0/EURUSD1/GBPUSD1件、失敗突破は3/5/7件。全候補で合計200件・各通貨50件と通貨分散の事前基準を満たさなかった。RR1.5リテストの黒字は2件だけで、収益性の裏付けとして不足する。他5構成の観測赤字も、少数標本で一般的な構造そのものを否定する証拠とは扱わない。この固定実装は採用候補から外す。

USDJPY口座はリテストに取引なし、失敗突破の通常3構成は最終1,003,310 / 1,001,535 / 1,003,790円（各3取引）。口座停止がなかったことだけで安全性や月利5%を証明しない。3年間の極端な低頻度で、ユーザーが求める日常のエントリー機会を提供できない。

実装 `scripts/research_new_logic_20261011.py`、境界テスト `tests/test_new_logic_20261011.py` は11件成功。結果・CSV・凍結SHAは `agent_runs/new_logic_20261011/training/`。公開用には、入力・CSVを含めず凍結SHAを示す `docs/quant_organization/experiments/new_logic_20261011/evidence/training_run_manifest.json` と独立再生要約 `training_independent_validation.json` を保存する。独立再現と監査の最終所見は実験ディレクトリの文書に記録する。
