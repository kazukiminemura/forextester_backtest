# 1時間足固定・代替ロジック比較

## 結論

エントリー時間足を1時間足に固定し、田向式とは異なる3系統、合計56候補を
USDJPY、GBPJPY、AUDJPY、CHFJPYで比較しました。学習・検証の両方で期待値が
プラスだった候補は0件です。未使用期間まで採用条件を通過した候補も0件のため、
現時点では既定プリセットやTradingViewへ追加しません。

## 11通貨ペアへの拡張検証

Forex Tester 6で2025年以降まで連続した履歴を持つ通貨ペアを追加し、
AUDUSD、EURUSD、GBPUSD、NZDUSD、USDCHF、USDJPY、AUDJPY、CHFJPY、
EURCHF、GBPCHF、GBPJPYの11通貨で56候補を再計算しました。AUDUSDが
2009年10月開始のため、共通学習期間は2010～2018年です。

全通貨共通の最良候補は、両方向・48本ドンチャン・EMA100・SL 1.5 ATRでした。
成績は学習21,685件/PF 0.946/期待値 -0.063R、検証10,093件/PF 0.933/
期待値 -0.073R、ホールドアウト4,922件/PF 0.967/期待値 -0.085R、完全未使用
3,697件/PF 0.809/期待値 -0.133Rです。

通貨ペアごとに2010～2022年だけで最良候補を選ぶ監査も実施しましたが、学習と
検証の両方でPF>1・期待値>0を満たすペアは0でした。したがって、通貨ペア不足が
不合格の原因ではありません。

USDCAD、EURCAD、EURGBP、NZDJPYはForex Tester内の履歴が2018年4月の短期間
しかなく、EURJPYは2024年8月で終了するため、完全未使用期間を判定できず除外
しました。全結果は `scripts/alternative_logic_11pair_results.json` に保存します。

## 固定条件

- エントリー判定: 確定1時間足のみ
- 約定: シグナル確定後、次の1時間足始値
- 損切り: シグナル足ATRに対する固定距離
- 利確: 損切り距離と同じ1Rで100%決済
- 同一足でSLとTPへ到達: 保守的にSLを先に処理
- コスト: Forex Testerの固定スプレッドと設定済みコミッション
- ポジション: 同時に1つだけ

エンジンは分が00であることに加え、実データ中に1時間間隔が存在することも確認し、
4時間足などを誤って入力した場合は拒否します。

## 比較ロジック

1. ドンチャンブレイク
   - 過去12・24・48本の高値／安値を初めて終値で突破
   - EMA100・200による方向フィルター
2. EMA押し・戻り再開
   - EMA10・20とEMA50・100でトレンドを判定
   - 短期EMAをまたいでトレンド方向へ戻った足で判定
3. ボリンジャーバンド逆張り
   - 20・40期間、1.5・2.0標準偏差
   - バンド外から内側へ戻った足で逆張り判定

各ロジックで買いのみ／両方向、ATR損切り1.0／1.5倍を比較しました。

## 期間分割と採用条件

- 学習: 2004～2018年
- 検証: 2019～2022年
- ホールドアウト: 2023～2024年
- 完全未使用: 2025～2026-07-17

候補順位は学習・検証だけで決定し、2023年以降を順位付けに使用していません。
学習200件以上、検証40件以上、両期間PF>1・期待値R>0、学習3通貨以上・検証
2通貨以上がプラスを採用前条件としました。

## 再実行

```powershell
$env:PYTHONPATH='src'
python scripts\research_alternative_logics.py --top 56 --output scripts\alternative_logic_results.json
```

特定系統だけ再実行する場合は、`--logic donchian`、`--logic ema-pullback`、
`--logic bollinger-reversion`を指定できます。全候補の設定と通貨別・期間別成績は
`scripts/alternative_logic_results.json`へ保存しています。

11通貨ペアの再実行例:

```powershell
$env:PYTHONPATH='src'
python scripts\research_alternative_logics.py `
  --symbols AUDUSD EURUSD GBPUSD NZDUSD USDCHF USDJPY AUDJPY CHFJPY EURCHF GBPCHF GBPJPY `
  --train-start-year 2010 --top 56 `
  --output scripts\alternative_logic_11pair_results.json
```

## 注意

1時間足OHLC内の約定順序はティック再生ではなく保守的な近似です。今回の結果は
候補の棄却には使えますが、将来別ロジックを採用する場合はティック、可変スプレッド、
スリッページを含む最終確認が必要です。
