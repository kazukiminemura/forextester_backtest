# BB到達の予測力と確認待ちの価値

2026-10-03。ユーザー承認の方針に従い、BBの条件追加に先立って、価格の戻り・コスト・待機の関係を調べた。保存済み2020–2025年、USDJPY/EURUSD/GBPUSD/AUDUSD/NZDUSD/AUDJPY/NZDJPYのM5を使用。全期間は既閲覧であり、将来の収益を確認する未使用検証ではない。

## 結果の要点

BB3到達後に小さな反転方向の平均変化は観察された。しかし、30分後までの反転方向の平均価格変化は仮定1pipの往復コストを下回り、固定RR1の売買へ変換した3方式もすべて費用後赤字だった。確認を増やすほど取引回数と総損失は減った一方、成立した取引群のPFは悪化した。

前回提案した「反転足確定で入り、突破待ちを省く」方式も、この新しい比較条件では黒字化していない。今回の研究で新しい売買方式を採用しない。

## Stage A：価格に何が起きるか

BB20/母標準偏差±3の片側タッチを確定足で検出。起点後12本を予約し、連続タッチを新しい観測として重ねない。これは操作的な非重複定義で、経済的な一つのショックや独立標本を完全に識別する定義ではない。

全56,212起点を保存。次の連続足始値から1/3/6/12本目の終値変化、最大順行/逆行、固定中央線・動く中央線への接触、対称1ATR境界の到達順を記録した。主判定は6本（30分）に固定し、結果を見て他の時間幅へ変更していない。

|起点期間|選択した起点|有効な対応比較|対応比較内の30分平均変化|1pip控除の観察スコア|
|---|---:|---:|---:|---:|
|2020–2022|28,562|27,217|+0.200pip|−0.800pip|
|2023–2025|27,650|26,220|+0.460pip|−0.540pip|

対応比較coverageは96.67%/96.21%。表はBUY/SELLの反転方向へ符号をそろえた等pip平均で、口座金額利益でも実際の戦略損益でもない。欠損や区間末の観測は欠測として残し、将来の欠損有無を使って起点を選び直していない。

### 非BB対照についての重要な限界

同通貨・YYYY-MM・元時計の4時間区分・過去ATR帯が一致する、13本以上前の最新非BB足を対照とした。対照を将来成績で選んではいない。全通貨で同じ月を再標本化する月ブロックbootstrap10,000回により、主6本のATR正規化比較差は両期間で95%区間が正だった（前期[0.0602,0.1664]、後期[0.1610,0.2644]ATR単位）。

ただし、この対照へ後続BB起点のBUY/SELL方向を与えると、起点へ至る直前トレンドを逆向きに評価する構造がある。最短の過去対照の値動きは後続BBの20本算定窓にも重なり得る。そのため差の正値は因果効果でも、実際に取引可能な予測力の独立証明でもない。対照方式は今回の結果を見て変更せず、この制約を保ったまま報告する。

Stage Aの固定screenは両期間を通過したが、これはStage Bへ進む条件にすぎない。実際のBB起点自身の小さい平均値幅と費用後負値を併記する。

### 動く中央線への復帰と価格の戻り

30分以内の固定中央線接触率は32.88%/35.07%、動く中央線接触率は41.19%/43.98%。動く中央線を使うと「復帰」は多く見える。差だけから価格が戻った量を判断できないため、初回接触時の価格変位と中央線変位を別列に保存した。中央線接触率をそのまま勝率と解釈しない。

## Stage B：戻りを取引へ変換できるか

Stage Aと同じ全起点から、次の3方式だけを事前固定して比較した。

1. タッチ足確定後、次の連続足始値。
2. 後続の方向一致陽線/陰線がバンド内で確定した後、次の連続足始値。
3. その反転足の高値/安値を後続の終値で厳密突破した後、次の連続足始値。

各方式のシグナル確定時SMA20を固定TP、実際の始値から鏡像SLで全決済RR1。実約定幅3pip以上、各通貨1保有、同足SL/TP両到達はSL優先、ギャップは始値。後続確認前の準備足極値更新と時間欠損を取消とし、文脈/ヒゲ除外は今回追加していない。したがって、旧Pine既定条件そのものの成績ではない。

各方式でTPを異なるシグナル時点に固定するため、比較は確認待ちとTP更新を含む売買方針の差であり、待機時間だけの因果効果ではない。

2つの3年帳簿はそれぞれフラット開始。下表の取引合計は2帳簿の合計で、6年連続保有の再計算ではない。往復コストは固定仮定1pip、歴史的GMO実測ではない。

|方式|2帳簿合計の決済数|2020–2022勝率|2020–2022 PF_R|2023–2025勝率|2023–2025 PF_R|
|---|---:|---:|---:|---:|---:|
|タッチ後の次始値|41,346|51.84%|0.828|52.45%|0.840|
|反転足確定後の次始値|16,292|50.28%|0.734|52.17%|0.784|
|突破確定後の次始値|4,885|49.43%|0.677|50.11%|0.693|

全方式・両期間で費用後R赤字、利益通貨0/7。1.2pipのストレス費用でも赤字。各方式を個別に判定する事前の次研究screen（100決済/PF_R1.2/含み込み黒字/ストレス黒字/4通貨黒字）はすべて不通過。

## 確認待ちの効果をどう解釈するか

取引にならなかった起点も0Rで残し、全起点当たりの結果を比較した。最後に未決済の起点だけは終値MTMを別記し、閉じた取引の勝率/PFに混ぜていない。

|方式|前期：全起点当たり費用後R|後期：全起点当たり費用後R|
|---|---:|---:|
|タッチ後|−0.0703|−0.0628|
|反転足確定後|−0.0463|−0.0336|
|突破確定後|−0.0178|−0.0149|

待つ方式の全起点当たり損失は小さい。しかし費用前Rを比べると、反転待ち−タッチの差は両期間で負、突破待ち−反転待ちの差も後期で負（前期区間は0をまたぐ）。事前の「費用前・費用後の両方で待機差の95%区間下限が正」という基準は2比較とも不通過。

この比較では、待つことで費用を支払う機会が減り、費用後の総損失は抑えられる一方、反転による利益をより効率よく取り出せたとは確認できない。「損失が減った」「チャンスを絞れた」と「優位性が増えた」を別に評価する必要がある。

## 研究上の判断と次の課題

今回の一つのイベント定義・対照方式・3売買方式による研究は終了する。好成績が出るまで条件を足す探索へ移らない。BBという指標全般や別のコスト環境を否定する結果ではないが、この条件での短期逆張りを採用する根拠は得られなかった。

次に必要なのは、一時的な価格偏りと持続的な価格変化を、判断時点で利用可能な情報により識別できるかという別仮説。対照もBB起点の形成過程と重ならない設計を結果前に検討する。市場状態の名称を事後の利益で付けず、追加情報の予測力の増分と実際の費用条件を検証する必要がある。
