# 田向式を参考にした日本株・日足押し目買い：初回検証

2026-09-26 / 実験 `tamukai_stocks_daily_20260926`

画面で確認する: [検証ダッシュボード](http://127.0.0.1:8769) / [起動・利用方法](stock_dashboard.md)。保存済みデータ・結果を読み込む。

**シンプルな1条件を実装して検証したが、9年間の費用後損益はほぼゼロで、安定した優位性は確認できなかった。**
2017-01-04〜2025-12-30、固定10銘柄、初期100万円の参考モデルで **−980円（−0.10%）**。
165取引、費用後勝率50.30%、PF0.997、日次終値ベース最大ドローダウン7.13%。
直近3年だけでは黒字だが、前の期間では再現しなかった。結果を見たルール調整は行っていない。

## 売買条件

1. 日足の確定した高値・安値が両方切り上がる。山・谷は左右2本との厳密比較で判定し、2営業日後の引けから使う。
2. 終値が21日単純移動平均線より上で、その平均線が2営業日前より上。
3. 直前3日中に安値が21日平均線以下へ押し、当日終値が直前3日の最高値を上抜けたら買い信号。
4. 翌営業日の始値で買う。損切りは信号の直前3日の最安値、利確は買値から損切りまでと同じ値幅（RR1:1）。全決済、1銘柄1保有。

買い始値が損切り以下なら見送る。保有後の窓開けは始値、同じ日足で利確・損切りの両方に触れたら損切りを先に計上。評価最終日の未決済分は終値清算。
日足だけで完結する初期版であり、短時間足によるエントリー判定は使わない。

[田向氏本人の公開説明](https://www.gogojungle.co.jp/finance/navi/articles/21270)には21SMAの利用がある。
今回の3日レンジ・左右2本ピボット・RR1固定は検証のための機械化仮定で、田向式の裁量判断全体を再現したものではない。

## 資金と費用

初期100万円を各銘柄10万円の独立した資金枠に分け、各売買ではその銘柄枠の全残高を手数料込みで投じる。銘柄間の資金移動・借入なし。
通常費用は売買代金の片道0.1%（往復およそ0.2%）、ストレス費用は片道0.2%。手数料・滑りをまとめた仮定で、特定証券会社の実測値ではない。

端株・後方調整価格での比例計算を許容し、100株単元・呼値・ストップ高安時の執行制約は再現しない。配当・税金・金利を含まない。
したがって円額は、この参考資金モデルの計算結果であり、100万円で同じ注文を現実に発注できるという意味ではない。

## 期間別の成績

各3年間は初期100万円へリセットし、前区間の保有を引き継がない。9年連続は保有と残高を引き継ぐので、3区間の円損益の単純合計とは異なる。
PFは費用後の利益合計÷損失合計、勝率は費用後で黒字だった取引の割合。

9年連続の最終資金は999,020円。費用を片道0.2%へ増やすと **−34,049円（−3.40%、PF0.914）**。
2023–2025だけは費用増加後も+27,516円だが、59件と少なく、2020–2022が赤字。
結果前の観察基準（検証・最終各100件以上、PF1.1以上、黒字など）には不通過。将来の収益性を検証済みとはしない。

## 買い持ちとの比較

同じ10銘柄へ各10万円、同じ費用で初日始値に買い最終日終値に売ると、参考収益は **+327.44%（+3,274,385円）、最大DD33.10%**。
押し目戦略の銘柄日ベース保有割合は8.34%、買い持ちは100%。前者は現金で待つ時間が長く、少ないDDと低い収益をこの資金稼働率の差と併せて読む必要がある。
同じリスク量へ調整した比較ではない。配当非再投資と現在の存続銘柄を使う偏り、Sony調整の制約は両方にある。

## データ品質による確認

Yahoo日足の保存スナップショットを使用。古い2営業日の欠損を避けるため、損益計算前に2015開始案を2017開始へ変更した。ウォームアップは2016-07-12から。
2017–2025は10銘柄とも2,198営業日で日程照合の欠損・余剰0。休場日の出来高ゼロ行は除外した。
2022-05-17の三菱UFJ安値・東京エレクトロン高値を、始値と終値を包む範囲へ修復。別の公開価格表と照合し、原値・派生値を保存した。
Sonyの2025年金融子会社分離による遡及価格調整は完全に復元できない。

|同じ売買結果からの除外診断|初期資金|9年損益|収益率|PF|
|---|---:|---:|---:|---:|
|全10銘柄|100万円|−980円|−0.10%|0.997|
|Sony除外9銘柄|90万円|+25,116円|+2.79%|1.075|
|Sony・三菱UFJ・東京エレクトロン除外7銘柄|70万円|−19,708円|−2.82%|0.919|

これはデータ制約の影響を見る診断で、銘柄最適化やデータ完全保証ではない。全10銘柄の数値は **DATA_LIMITEDの参考価格損益** として扱う。
品質確認の根拠・企業行動・出典は[data_inventory.md](quant_organization/experiments/tamukai_stocks_daily_20260926/data_inventory.md)を参照。

## 実装と再現

Ponytail方針で既存SMA関数とPython標準ライブラリを利用し、新規依存・AI売買判断・パラメータ探索を追加しなかった。

```powershell
python scripts/fetch_tamukai_stock_data.py
python -m unittest discover -s tests -p test_tamukai_stocks_daily.py -v
python scripts/research_tamukai_stocks_daily.py
```

取得スクリプトは保存済みraw JSONがある場合それを再利用する。研究runnerは保存CSVのみで動く。
取引明細・日次残高・年別成績・費用増加時成績は[summary.json](../agent_runs/tamukai_stocks_daily_20260926/results/summary.json)と同階層の368 CSV。
実行前の仕様/実装/データSHA256は[run_start_manifest.json](../agent_runs/tamukai_stocks_daily_20260926/results/run_start_manifest.json)に保存。
6件の境界テストと研究実行はexit 0。
独立した計算で160ケース・740取引観測・175,840個別日次残高・48集約曲線・108年別指標が一致。
日足23,140本のピボット状態と261シグナル、420回の将来足切断検査も一致した。
独立検証の結論は、**計算は再現、事前観察基準は不通過、データ制約付きの不採用研究**。
品質監査でも独立参照計算を再実行し一致。判定は`AUDITED_REJECTED_DESCRIPTIVE_DATA_LIMITED`で、制約付きの検証報告として引渡し可。
summaryの`PENDING_INDEPENDENT_VALIDATION`は研究実行時点のラベルで、後続の独立検証・監査は下記文書で記録する。
