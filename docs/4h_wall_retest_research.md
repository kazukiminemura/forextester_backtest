# 4Hトレンド方向・壁ブレイク後リテスト統計

## 結論

4時間足の確定壁をトレンド方向へ抜けた後、15分足で壁への戻りと
支持・抵抗転換を確認してから入るリテスト型を検証した。
ブレイク直後型より損失は少し縮小したが、実践採用できる優位性は
確認できなかった。全48候補で、採用基準を通過した候補は0件だった。

## 検証ルール

- 買い方向: 4H確定高値と確定安値がともに切り上げ
- 売り方向: 4H確定高値と確定安値がともに切り下げ
- 壁: 直近の確定4H高値または安値
- ブレイク: 15分足終値がトレンド方向へ壁を突破
- リテスト買い: 壁付近まで戻り、陽線かつ壁の上で終値確定
- リテスト売り: 壁付近まで戻り、陰線かつ壁の下で終値確定
- 約定: リテスト確認後の次の15分足始値。買いはスプレッドを加算
- 再試行: 同じ壁では最初のリテストだけ
- 同時保有: 1銘柄につき1ポジション
- TP: SLと同距離の1Rで全量決済
- 同一足でTP・SLへ触れた場合: 損失扱い
- 極端な構造SL: 2.5 ATRを超える場合は除外

比較した48条件は、4Hピボット3・5本、ブレイク余白0・0.10 ATR、
戻り待ち8・16・32本（2・4・8時間）、壁への許容幅0.10・0.20 ATR、
SLを「リテスト足の外側0.10 ATR」または「確認足終値から2.0 ATR」とした。

対象はローカルに履歴があるウォッチリスト14銘柄。CADJPY、EURAUD、AUDNZDは
ローカル履歴ファイルがないため対象外とした。

## 全体で最も悪化が小さかった候補

- 4Hピボット: 5本
- ブレイク余白: 0.10 ATR
- 戻り待ち: 最大32本（8時間）
- 壁への許容幅: 0.20 ATR
- SL: 確認足終値から2.0 ATR
- TP: SLと同距離の1R

| 期間 | 取引数 | 勝率 | PF | 期待値(R/回) | 月平均 |
|---|---:|---:|---:|---:|---:|
| 学習 2010–2018 | 2,456 | 47.68% | 0.911 | -0.046 | 22.74 |
| 検証 2019–2022 | 1,040 | 47.69% | 0.912 | -0.046 | 21.67 |
| 未使用 2023–2024 | 581 | 44.23% | 0.793 | -0.115 | 24.21 |
| 真の未使用 2025–2026 | 377 | 43.50% | 0.770 | -0.130 | 19.84 |

ブレイク直後型に比べ、学習・検証のPFは約0.02改善し、2025–2026の期待値も
-0.142Rから-0.130Rへ縮小した。しかし全期間で勝率50%を下回り、
未使用期間では成績が再び悪化したため、改善ではあっても優位性ではない。

## 採用判定

採用基準は各期間でPF 1.15以上、期待値プラス、月3回以上とした。

| 判定対象 | 通過候補数 / 48 |
|---|---:|
| 学習期 | 0 |
| 検証期 | 0 |
| 学習期と検証期の両方 | 0 |
| 未使用期 | 0 |
| 真の未使用期 | 0 |

候補選択には学習期と検証期だけを使用し、2023年以降は選択に使用していない。

## 通貨別監査

全48条件について、学習期と検証期の両方で「各30件以上、PF 1.10以上、
期待値プラス」を満たした通貨別候補はGBPUSDの1件だけだった。

- 条件: 4Hピボット5本、余白0.10 ATR、戻り待ち16本、許容幅0.20 ATR、2 ATR SL
- 学習 2010–2018: 249件、PF 1.110、期待値 +0.052R
- 検証 2019–2022: 90件、PF 1.432、期待値 +0.178R
- 未使用 2023–2024: 53件、PF 0.893、期待値 -0.057R
- 真の未使用 2025–2026: 31件、PF 1.067、期待値 +0.032R

GBPUSDは未使用期間で崩れ、真の未使用期間もPF 1.10に届かなかった。
したがって通貨限定でも採用しない。

XAUUSDは全体選択条件の2023–2024でPF 1.706、2025–2026でPF 1.267だったが、
同じ条件の学習期PF 0.955、検証期PF 0.791である。直近期間だけ良い条件なので、
将来も続く根拠にはできない。

## 判断

「壁ブレイク＋最初の支持・抵抗転換」だけでは不足している。
エントリー表示へ採用せず、現時点では4H確定高値・安値とチャネルラインを
相場の壁として表示する用途に留める。

次に追加検証する場合は、条件を大量に同時追加せず、リテスト確認足の実体比率、
ロンドン・ニューヨーク時間、壁が形成されてからの経過時間のいずれか1要因を
事前固定して比較する必要がある。

生データ集計結果は `scripts/4h_wall_retest_results.json`、再実行コードは
`scripts/research_4h_wall_retest.py` に保存した。
