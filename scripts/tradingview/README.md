# TradingView インジケーター

## よすが式 4H順張り・15分足エントリー

`yosuga_15m_4h_trade_journal.pine`は、確定4Hダウ方向へ15分足の
トレンドラインブレイクまたは押し戻り後の高安ブレイクで入る研究用
インジケーターです。15分足チャートへファイル全体を貼り付けて使用します。

左上に直近トレードの曜日、時間帯、保有分、方向一致、評価、pips、勝敗、
初動/追随、当日回数、前回結果、取引種別、エントリー理由を表示します。
右下には12通貨の狙い目一覧を表示します。RRは1:1の全決済です。

Forex Testerの11通貨・2010–2026年検証では採用基準を通過していないため、
画面上でも研究用として扱ってください。詳細は
[`../../docs/yosuga_15m_4h_trade_journal.md`](../../docs/yosuga_15m_4h_trade_journal.md)を
参照してください。

## 4H順張り・共有ML改善版

`strict_rr_ml_15m_strategy_2026.pine`は、よすが式ルールへ条件を足す方式を止め、
15分足の発火だけを固定11通貨共通モデルへ置き換えた2026年用インジケーターです。
注文は出さず、次足始値からEntry・SL・TPと勝敗を内部追跡します。
確定4時間足ダウ方向と同じ側だけに入り、ML値0.485以上、次の15分足始値、
ATR 2.0基準のSL、全量RR 1:1を使用します。

Forex Testerの11通貨合算では、学習56.43%、検証55.59%、未使用56.62%、
最終未使用73.73%で、全期間のPF・期待値・月平均回数の採用条件を通過しました。
Pineへ固定した2026年モデルの2026年部分は312件、勝率72.76%、PF2.671です。
TradingViewのコンパイル上限へ収めるため、決定木は120本版から20本版へ縮小しています。

黄線がEntry、赤線がSL、緑線がTPです。右側の高コントラスト表には確定4H方向、
買い・売りML値、採用しきい値、チャート勝率を表示します。ML値は校正済み勝率では
なく、現在の優勢度を比較するナウキャスト値です。詳細は
[`../../docs/strict_rr_ml_4h_strategy.md`](../../docs/strict_rr_ml_4h_strategy.md)を
参照してください。2027年には再学習とPine再生成が必要です。

右下の18銘柄一覧では、再検証済み11通貨の完全候補を`BUY`/`SELL`、4H方向だけ
成立した準備状態を
`買い監視`/`売り監視`として表示します。初期値はOANDAですが、設定画面から
利用中のブローカー銘柄へ変更できます。一覧の候補を見つけたら、その通貨の
15分足を開いてメイン判定とEntry・SL・TPを最終確認してください。

XAUUSD、EURJPY、NZDJPY、CADJPY、EURAUD、AUDNZD、EURGBPは、履歴長または
価格特性が固定11通貨の再検証条件と一致しないため、構造分析だけを表示して
MLエントリーは出しません。

## コンパクトMLエントリー

`shared_feature_entry_logic.pine`は、固定11通貨の15分足でBUY/SELL候補だけを
表示する2026年用インジケーターです。注文は出しません。

2010～2025年の決済済みForex Testerデータで年次学習した共通モデルを、
20本の小型決定木へ固定しています。通貨別モデルや通貨除外はありません。
毎時00分に始まる15分足が確定する毎時15分に判定し、勝率閾値0.487以上で
買い・売りの高い方だけを表示します。

シグナルの次の15分足が始まると、その始値へBUYは緑、SELLは赤の
エントリーラインを表示します。右上にはATR 2.0の損切りと同距離の1R利確を
内部追跡した勝率・勝敗数を表示します。同一足でTPとSLの両方へ触れた場合は
負けとして集計します。アラート条件は`コンパクトML BUY`と
`コンパクトML SELL`です。

このPineには2026年モデルだけを入れているため、2025年以前のチャートでは
シグナルを停止します。2027年には前年末までのデータで再生成が必要です。

## 追加方法

1. TradingViewで対象銘柄の15分足チャートを開きます。
2. 画面下部の「Pineエディタ」を開きます。
3. 既存コードを全選択して削除します。
4. `tamukai_pair_signal_indicator.pine`を1行目の`//@version=6`から最終行まで、
   省略せずすべて貼り付けます。
5. 「保存」→「チャートに追加」を押します。

更新版が反映されると、右上テーブルの先頭に`田向式 RR1 15m v4`、利確欄に
`RR 1:1 / 100%`と表示されます。以前の表示が残る場合は、チャート上の旧版を
削除してから保存済みの新版を追加し直してください。

4時間足などへ追加した場合、売買シグナルは停止し、オレンジ色の背景と
「15分足専用」の警告を表示します。上部の時間足を`15m`へ変更してください。

## 表示

- `SET BUY` / `SET SELL`: 条件成立。レンジ外の逆指値候補を待機中
- `BUY` / `SELL`: 確定15分足で待機価格を突破
- 黄線: 待機レンジ
- 白／緑／赤線: Entry・1:1のTP・構造SL
- `TP` / `SL`: インジケーター内の仮想到達判定

設定の`プリセット=Auto`では、JPYクロスにUSDJPY探索値、EURUSDに
`EURUSD研究`、XAUUSD（金）に`XAUUSD研究`を使います。他の銘柄はPine既定値です。
EURUSD研究設定は2023～2024年の最終評価で期待値がマイナスだったため、
テーブルへ警告を表示します。XAUUSD研究設定は2025～2026年の未使用期間で
13取引、PF 1.22でしたが、標本が少ないため研究用として警告色で表示します。

決済は全銘柄・全プリセットで「SLまでの距離＝TPまでの距離」とし、
1R到達時に100%決済します。半分利確と残りの追随は使用しません。
待機シグナル中もEntry、SL、対称位置のTPを同時に表示し、状態テーブルには
価格を数値表示します。

復元した15分足版はレンジ3本、押し探索12本、待機8本を使用します。
従来の1時間足・30分足成績は15分足へ引き継げません。15分足の成績は再検証前です。

XAUUSD研究は「買いのみ・1Rで全量利確」の厳密なRR 1:1設定ですが、以下の成績は
旧1時間足の参考値であり、15分足では未検証です。
4本レンジ、最大1.50 ATR、4H傾き0.06 ATR、最小押し0.25 ATR、参照帯許容幅
0.40 ATR、壁まで1R以上、損切り2.0 ATR以下、待機8本を使用します。
エントリーと損切りバッファはバックテストに合わせて価格差0.40 USDへ固定し、
絶対pipsの最大損切り幅は無効にします。全期間は123取引、勝率62.60%、
PF 1.395でしたが、未使用期間は13取引だけなので研究候補です。

JPYクロス、EURUSD研究、Pine既定、Customも決済だけはRR 1:1へ統一されます。
過去に記載したJPY/EURUSD成績は別の決済条件によるため、RR 1:1変更後の成績として
使用できません。JPYクロスのRR 1:1共通値を再探索しましたが、現在設定は
2023～2024年の4通貨合算で45取引、PF 0.53、最良の代替候補もPF 0.56でした。
ホールドアウトを通過した候補がないため、売買条件は変更せず警告表示にしています。
詳細は[`../../docs/jpy_cross_rr1_optimization.md`](../../docs/jpy_cross_rr1_optimization.md)を
参照してください。

## アラート

インジケーターを追加後、TradingViewの「アラートを作成」で条件欄から次を選べます。

- `田向式 BUY setup` / `SELL setup`
- `田向式 BUY breakout` / `SELL breakout`
- `田向式 Target reached` / `Stop reached`

Pineコードを追加しただけではアラートは稼働しません。TradingView画面でアラートを
作成してください。

## 複数通貨ペアのチャンス一覧

`tamukai_pair_signal_indicator.pine`本体に、設定した10銘柄を確定済み15分足・
4時間足で同時監視する一覧を内蔵しています。別のインジケーターを追加する必要は
ありません。設定の`通貨ペア・チャンス一覧`で表示のON/OFFと監視銘柄を変更できます。

左上の一覧は次の意味です。

- `BUY待ち`（明るい緑）: 買いの全SET条件が成立。表示Entryの上抜け待ち
- `SELL待ち`（明るい赤）: 売りの全SET条件が成立。表示Entryの下抜け待ち
- `上昇監視`（濃い緑）: 4Hは上向きだが、15分足レンジ条件は未成立
- `下降監視`（濃い赤）: 4Hは下向きだが、15分足レンジ条件は未成立
- `なし`（灰色）: 現在は方向条件なし

既定はEURUSD、GBPUSD、USDJPY、EURJPY、GBPJPY、AUDJPY、EURGBP、GBPCHF、
AUDUSD、USDCHFです。インジケーター設定の`監視銘柄`から、利用中のブローカーの
銘柄へ変更できます。`BUY待ち`・`SELL待ち`はエントリー済みではなく、既存の
同じインジケーターを対象チャートで開いてEntry・SL・TPを最終確認してください。

TradingView Pineはウォッチリスト全体を自動取得できないため、このスキャナーは
指定した10銘柄だけを監視します。また、一覧は新しいSET候補を示し、過去バーで
発生して現在も期限内の待機注文状態までは保持しません。

## 制約

このファイルは売買注文を出さない`indicator()`です。TP・SLは確定足OHLCによる
参考表示で、Forex Testerのスプレッド付き約定や同一バー内価格経路とは一致しない
場合があります。勝率・期待値の評価にはPythonバックテストを使用してください。
